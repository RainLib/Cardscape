# 卡牌工坊 0.9 能力检查

本轮目标是以 Photoshop 的工作区方式组织卡牌合成，完成外部 Agent、图像处理和动态资源导出的可验证闭环。不是 Photoshop 的完整功能替代，也没有完成 Snap 逐帧一致性验收。

## 工作区

32 px 菜单、32 px 工具选项、39 px 工具栏；图层独立滚动且可垂直调整高度。右侧“属性 / 调整 / 动作 / Slots / GLSL”按标签切换，次要参数折叠。中央支持 2D、分屏和完整 3D；面板可缩为侧边标签。Tab 在画布焦点时隐藏工具与面板，Shift Tab 折叠右侧；输入、按钮和弹窗保留正常 Tab 导航。工作区布局存本机，图像与动画参数存工程。

0.5.1 统一 Electron / 浏览器快捷键：撤销、两种重做组合、保存、全选 / 取消 / 反选、变换、复制、删除、缩放。输入框使用自身文字历史；全选与取消选区可撤销。右上角 ? / F1 查看快捷键，菜单按钮显示历史状态。历史仍为当前会话 30 步；跨会话历史、分支历史与可配置按键尚未实现。

设计参考：[Adobe 面板折叠](https://helpx.adobe.com/photoshop/desktop/get-started/learn-the-basics/collapse-expand-icons.html)、[隐藏面板](https://helpx.adobe.com/uk/photoshop/desktop/get-started/learn-the-basics/hide-show-panels.html)。这里实现固定停靠区和折叠，不包含任意拖拽浮动窗口。

## 性能设计与验收边界

- Rust `image` / Rayon 承担 PNG 解码、Lanczos 缩放、灰度羽化、颜色连通选区、选区膨胀 / 腐蚀、候选保护合成和调色烘焙。形态学使用可分离滑动极值队列，复杂度随像素数增长，不随半径平方增长。
- MobileSAM 与 OpenCV 使用单独 Python 进程；CPU 按需推理、只缓存最近一张图片的 embedding。安装和模型源码校验信息保存在 `native-ai/source-manifest.json`。当前已验证点提示、负提示、框提示、缓存、坐标校验与 PNG 输出。不是 Matting 或实时磁性追踪。
- 2D 调色使用 256 项查找表与结果缓存；3D 使用 Uniform，不在每帧调用 Rust 或编码 PNG。动作与 Slot 使用已有纹理。人物保持一张连续网格，不增加护腕或手部重叠网格。
- 卡体、背景、框与卡背使用 24 × 24 网格以支持整体弯曲；人物为 40 × 40。未使用全角色 3D 模型。弯曲网格比原四边形增加三角面，需要后续按移动端性能档位降级。
- 当前限制：16 MP 单图、64 MB 工程、64 图层、32 Slot、24 动作，30 步历史。内嵌 PNG 和大 Mask 仍有内存与序列化开销；下一步应采用磁盘资产缓存、ROI 上传和性能档位。
- 单机处理时间与浏览器 GPU 无错误不等于移动端帧率保证。本轮没有低端 GPU、多卡同屏、跨平台笔压或 Godot 实机验收。

4. 资产缓存、纹理通道打包、分辨率 / 网格 / 动效性能档位，以及批量制作。
