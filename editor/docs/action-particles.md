# 动作粒子

在动画时间轴展开「动作粒子事件」，在当前时间添加、修改或删除事件。可直接编辑触发时间、持续时间、外观、颜色、数量、尺寸、寿命、速度、扩散、拉伸、透明度、环绕半径、混合、层级、轨迹、发射坐标、跟随骨骼与模拟空间；爆发可设置持续时间、数量、距离和分批比例。支持单独启停事件和导入事件自己的 PNG（最长边 512px，实际解码后才应用），不用先修改环境粒子。提供剑锋拖光、掌心聚能、冲击爆发和飘散火星四种起始预设。形状、完整爆发参数等仍可通过「使用当前粒子面板设置」复制。修改支持工程撤销、保存和重开。

环境粒子与多个事件可以同时播放。每个动作最多 16 组事件，活动事件与环境粒子平分当前质量档的总预算，关闭的事件不占份额，实际总量不会超过预算。事件以动作局部时间采样，区间为 `[开始, 结束)`；循环动作每轮重播，定位直接重建当前状态，暂停冻结事件，切换动作终止旧事件。事件开始和结束有最长 0.12 秒的淡入淡出。事件须在动作结束前完成；退场效果使用独立退场动作。

发射坐标使用 1024×1536 静止画幅。默认「整体跟随骨骼」对注册后的粒子位置、尺寸、方向和透明度应用当前骨骼姿态，与骨骼、IK 和切入混合一致。新增「出生后留在卡牌空间」：每个粒子按自身出生时刻采样目标动作的骨骼／IK，冻结该次发射的变换，继续自身的扩散运动；发射骨骼随后移动时，旧粒子保留原轨迹。剑锋样例与施法爆发已使用此模式。关闭人物动画时，两种模式均使用静止位置。

出生时刻由固定随机种子、寿命、循环批次和爆发延迟解析计算，包括分组的 krackle／starcore、变寿命 adamantium 与分批射线。初始预热粒子的负出生时刻截到事件开始；没有出生周期的漂浮／粒子场固定使用开始姿态。无需依赖上一帧，也不用从零逐帧模拟，反向定位、重播和预算变动不会重排已有粒子身份。两端缓存最多 512 个骨骼出生姿态，动作／骨架变化时失效，销毁时释放。

勾选「提前停止发射」后，可把发射时长设得短于事件持续时间。截止时不再产生新粒子，已出生粒子保持原身份与运动，按剩余寿命消散；漂浮／粒子场没有循环出生，截止后在一次寿命内淡出。发射时长为 0 时不显示粒子。事件持续时间仍是硬截止，需要完整余辉时应预留寿命，并让整个事件在动作结束前完成。

勾选「连续剑痕」并绑定骨骼，可生成真正连接的带状网格。发射 X/Y 是静止画幅中的剑锋位置，粒子尺寸控制半宽；颜色、透明度、混合、层级和发射面继续生效。留痕可设 0.04–2 秒，网格可设 4–64 段，实际段数服从同一总预算。各截面采样目标动作过去的骨骼／IK 姿态，连接处共享顶点，急转处限制斜接长度。停止发射后，头部留在最后发射位置，尾部继续收拢并消散。该模式使用固定发光材质，忽略普通粒子的外观／PNG、配色方案、速度、扩散、环绕和爆发；模拟空间选 world 时，整卡出生变换也写入剑痕截面。静止发射点不生成有面积的带；关闭人物动画后不会继续画出旧动作轨迹。

「出生后留在世界空间」同时冻结出生时的骨骼与整卡变换。整卡平移、翻转、缩放或淡出后，已发射粒子的中心、尺寸与根透明度保持出生状态；后续出生的粒子使用新的发射位置。普通粒子继续面向相机，连续剑痕保留每个截面的三维出生平面及连接斜接；Cosmic 前后两通道也使用出生尺度与朝向。发射面的判断取出生时的卡牌姿态，翻背不会抹掉此前发出的粒子。

`bone`／`card` 模式及原有剑痕继续随整卡移动，旧工程行为不变。所有模式的历史骨骼及动作根轨道取目标动作本身，不记录切入前动作的混合历史。世界空间只解除空间跟随；事件结束、切换动作、禁用效果、质量策略和卡牌显隐／销毁仍控制其生命周期，销毁卡牌会释放世界粒子。

动作根轨道按时间解析采样。游戏代码或检查视角控制的额外根变换按最多 60 Hz 记录，历史最多 1024 项，暂停的重复绘制和反向观察不会覆盖旧记录；相邻位置插值，未观察或已超出保留窗口的时间保持最近位置。无法凭当前坐标恢复任意外部移动历史。需要任意时间精确定位、很快的非线性移动或离线输出时，游戏应提供确定性的历史采样器；不要把默认的有限记录当成完整的游戏回放。

WebGL 使用 `preview.setParticleWorldSampler(sampler | null)`，嵌入绘制也可传 `drawExternal({ sampleParticleWorld, ... })`。采样器接收 `(actionId, unwrappedActionSeconds, fallback)`，返回完整 `ParticleWorldPose`：`angle: [yaw, pitch]`（弧度），`root: [x, y, z, scale, opacity]`（卡宽单位、非负统一缩放）。`fallback` 已合成动作根轨道与所记录的外部放置；返回值不要再次套当前卡牌变换。Godot 使用 `set_particle_world_sampler(Callable)`，同样接收动作 ID、含循环轮次的动作秒数和 fallback 字典，返回 `{transform: Transform3D, opacity: float}`；矩阵表示完整视觉根的世界变换，包含父节点与动作根。空采样器恢复记录模式。两端都校验采样结果，透明度限制为 0–1。

勾选「启用重力与平面碰撞」，在「物理轨迹与碰撞面」编辑初速度、随机速度范围、重力、半径、反弹系数、切向衰减及最多八个静态平面。支持反弹、滑动和命中消失。物理事件只支持 `card`／`world`；从整体跟随骨骼开启时自动切为 `card`，仍可绑定出生骨骼。连续剑痕与物理事件互斥。修改支持撤销、保存、重开和两端导出。

物理模式使用统一的点／矩形／椭圆／周边发射分布，替代原来各外观的程序化位置与环绕轨迹；保留外观、PNG、尺寸、颜色、透明度、寿命、分组、揭示和出生规则。旧速度、扩散及环绕参数不再控制物理位置，初速度由新字段明确设置，不自动继承发射器移动速度。没有周期出生的漂浮／粒子场仍从事件开始发射一次。

速度单位为卡宽／秒，重力为卡宽／秒²；Y 向上、Z 朝观察者。初速度和速度随机范围位于发射器局部空间，经图层、出生骨骼及出生根变换转换；重力、碰撞半径与平面使用所选卡牌／世界模拟空间。平面的可活动一侧为 `normalize(normal) · position >= distance + radius`；法线归一化不改变 `distance` 的卡宽单位。卡牌空间的平面随整卡显示，世界平面保持导出坐标，不会自动跟随游戏节点或每张卡的网格位置。

完整默认配置如下，位于事件的可选 `physics` 字段。格式严格校验，未知字段会报错：

```json
{
  "schema": "card-particle-physics/1",
  "velocity": [0, 0.35, 0],
  "spread": [0.25, 0.15, 0],
  "gravity": [0, -1.5, 0],
  "radius": 0.008,
  "restitution": 0.55,
  "friction": 0.15,
  "response": "bounce",
  "maxBounces": 8,
  "planes": [{ "id": "floor", "normal": [0, 1, 0], "distance": -0.6 }]
}
```

`velocity` 各轴为 −10–10，`spread` 为 0–10 的对称随机范围，`gravity` 各轴为 −20–20；`radius` 为 0–0.2，`restitution/friction` 为 0–1。`friction` 仅在碰撞时衰减切向速度，不是持续空气阻力。`maxBounces` 为 0–32 的整数，统计反弹或滑动响应次数，达到次数后下一次命中消失；0 表示首次命中消失。平面 ID 唯一、1–80 字符，法线各轴 −1–1 且长度至少 0.0001，距离 −10–10；可留空平面只使用重力。

两端解析计算匀加速度分段与扫掠平面的二次方程交点，按真实命中时刻响应，任意顺序定位不依赖渲染帧率。使用 `1e-6` 卡宽的接触间隙，法向速度不超过 `0.02` 时进入静止接触并去除朝平面内的重力；初始穿透最多八轮投影，无可行交集时移除粒子。每个渲染器／原生卡牌最多缓存 256 条纯数值路径，重建或销毁时清理，不缓存节点或纹理引用。

本阶段只支持编写在事件中的静态平面。编辑平面会从出生重新求解；不记录移动碰撞体的历史，也没有球体、场景网格、动态刚体或剑痕物理碰撞。动作音效现已接入时间轴和两端导出，见 [动作音效](action-audio.md)。当前粒子物理仍不等于完整场景物理特效系统。

WebGL 共享固定采样数组、剑痕边缘数组与一个顶点缓冲，各组依次绘制；PNG 纹理按源复用，缓存有上限并在销毁时释放。Godot 使用最多 16 组事件池；普通粒子使用 MultiMesh，剑痕复用节点、ArrayMesh 和材质，同档位逐帧更新顶点／UV／透明度缓冲。禁用粒子或每组预算为 0 时不新建事件节点，工程重建释放旧池。PNG 事件素材作为独立资源导出，同时进入远端依赖清单。

字段位于 `CharacterAction.particleEvents`，包含 `id/name/at/duration/boneId?/simulationSpace?/emissionDuration?/trail?/physics?/particles`。`simulationSpace` 省略时兼容旧工程，使用 `bone`；`card` 启用出生骨骼姿态采样，`world` 再冻结出生根变换。`emissionDuration` 省略时持续发射，设置时为事件内的截止秒数（0–duration）；`trail` 包含 `duration`（留痕秒数）与整数 `segments`（网格段数），且必须绑定有效骨骼。`at` 为 0–1 的动作相对时间，`duration` 为 0.08–12 秒；`particles` 使用完整 `card-particles/1` 配置。骨骼不存在、重复事件 ID、超过预算或无效粒子数据会在保存／导出前报错。隐藏或缺失的图层发射源暂停发射。

真实工坊另含「星屑坠落 · 平面碰撞」：世界空间星屑受重力下落，在地面与两侧墙反弹；可编辑平面并切换滑动或命中消失。`test_particle_physics.gd` 比较实际 MultiMesh 数据，覆盖地面／墙约束、移动游戏根、反向定位、响应切换、缓存上限和释放，成品 Godot 验收一并运行。

真实工坊新增「星痕巡游 · 世界空间」动作，可同时检查整卡运动、世界聚能、三维剑锋带与双通道星云。`npm run test:production-card` 会实际选择世界空间、保存重开并检查编辑器和独立播放器；`npm run test:production-godot` 还会移动游戏节点，检查暂停／反向定位、循环轮次、历史采样器、资源归属与清理。原生 Compatibility 的 MultiMesh 颜色使用 16 位存储，验收分别比较 CPU 合成透明度及后端打包后的数值，位置与剑痕网格仍保持原浮点误差门限。参照 [MultiMesh 存储精度](https://docs.godotengine.org/en/4.3/classes/class_multimesh.html)。新 `world` 字段和运行时模块需要配套本次 WebGL／Godot SDK。

验证入口：`npm test`，以及 `npm run test:production-card`；后者实际操作 Electron 保存／重开和导出，再打开导出的 HTTP 播放器。设置 `GODOT_BIN` 后运行 `npm run test:production-godot`，比较实际导出的 Godot GPU 网格及骨骼粒子位置，并检查暂停、打断和资源复用。详细产物位于 `qa/production-readiness/arcane-sentinel/last-run.json` 指向的目录。
