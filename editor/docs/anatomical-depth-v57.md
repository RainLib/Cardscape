# 人物部件景深 · 0.19.57

人物制作现在按真实遮挡与纵深规划后手臂、后腿、后翅膀、躯干、前肢体和衣料。前后指观察深度，左右指人物自身的解剖方向。没有纵深差异的部位不机械拆分。

## 制作入口

选中人物图层，进入 **属性 → 区域制作 · 拆层与锚点**：

1. 用智能选区或磁性套索选择部件，指定人物部件类型及左右方位。
2. 用“选区拆为前层 / 后层”抽取互补 Alpha；也可给已有拆层应用部件分类。
3. 设置空间角色和相对深度。先从主体 ±0.015–0.025 卡宽开始，根据真实隐藏补绘余量限制角度和深度。
4. 后层被抽走的胸甲、关节、内裙、腿部与翼根要真实补绘。“AI 补全后层缺口”使用当前素材和完整人物母版，候选就绪后按缺口应用。
5. 展开“人物深度检查”查看未分类、单人物表面和缺少隐藏补绘记录的提示，再在空间层级与效果预览中逐角度检查。

检查只核对元数据，补绘回执也不能证明隐藏像素足够。上下左右倾斜、四个组合角度、隐藏前层、框内/破框以及最大衣料摆动均需视觉验收。

## 运行时与 AI

- 手臂、手、腿、翼骨、头、躯干、武器和饰物使用刚性表面；手、护腕、握点和武器保持连续。只在实际遮挡需要时继续分武器。
- 刚性表面恒定深度，不使用根部逐顶点插值、衣料风摆或自定义几何形变。接缝靠真实隐藏重叠保持连接。旋转使用 pivot，流光和材质效果仍可使用。
- 披风、裙摆、发梢使用柔性网格和 root→tip 权重。翼骨需要刚性，羽毛末梢有柔动需求时另外制作柔性表面。
- WebGL 与 Godot 的刚性部件复用两个三角形的平面；柔性衣料才使用细分网格。每个部件仍有框内/破框两次绘制，不能据此宣称透明过绘或整机帧率已经达标。
- 客户端 AI 增加 `characterPart`、带 part/side 的 `splitLayer` 和 attachment.mode。上下文携带人物深度检查；选中人物时可附上已注册的完整人物母版 `character-master.png`。
- 仓库 Skill 与已安装的 Codex CLI Skill 同步。每次客户端制作任务实际携带新的 `references/anatomical-depth.md`，要求生成母版、拆层、真实隐藏补绘、刚性保护及角度验收。
