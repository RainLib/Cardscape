# 人物拆层、遮挡与生成约束 · 0.19.64

人物也需要内部景深。远侧手臂、腿和翅膀处于主体之后，近侧肢体与握持组处于主体之前；只移动背景不能形成这种关系。制作使用同一母版、同一镜头和注册画布，逐层补齐会在倾斜时露出的关节、内衣、翼根和衣料。

## 制作方式

每个角色先记录部件计划：名称、人物自身左右、观察近远、遮挡对象、连接点、刚性握持组、隐藏补绘、深度及允许角度。明显前伸的前臂、躯干之后的手臂、前后腿与前后翼分别处理；本构图不可见的部位无需为了层数额外生成。同深度的头和躯干可以保持连续。

先生成完整人物，再从实际可见像素拆出部件，使用当前部件及完整母版生成隐藏补绘。手、护腕、握点和武器保持刚性连续，披风、裙摆和发梢使用固定根部与渐变摆动。拆层不自动产生被遮住的内容，也不能复制完整人物充当后层。

客户端入口为 **选中人物 → 属性 → 区域制作 · 拆层与锚点**。指定部件和左右，用智能选区/套索选择，再拆为前层或后层。选择需要补绘的后层，使用“AI 补全后层缺口”。“人物深度检查”提供待检查项；“空间层级”的全图帮助查看隐藏连接，“效果预览”用于检查实际内外遮挡。

正面须恢复母版的比例与连续性；左右 ±20°、上下 ±12°以及四个组合角度要检查肢体相对移动、接缝、握点和底部。在最大衣料摆动下重新检查。支撑不足时继续补绘或收紧深度与角度。明显侧面转向需要侧面/3D 资产，平面 Z 不能生成新的侧面解剖。

## 本轮补强

- 制作 Skill 强制先写逐角色部件计划，进入实际图片子任务。
- 人物图片上下文携带 `visible`、`paintOrder` 和 `slotZ`。`paintOrder` 从后到前递增，`z` 表示连接限幅并加上 Slot 后的实际自由端深度；柔性根部仍固定。图层排序和相机深度分别判断。
- 深度检查按母版分别统计，避免两个平面角色互相掩盖问题。
- 新增“拆层但同深度”“统一相机未开启”“前后角色与含 Slot 的实际位置相反”提示。检查只读，不改变图片或自动重排图层。
- 仓库 Skill 与安装在 `~/.codex/skills/card-atelier` 的版本一致。

## 实际验证

证据：`outputs/stickers-v64/character-depth-verification.json`。

- 全部 306 项 Node 测试通过，187 个 JS 文件语法检查通过，两处 Skill 格式校验通过。
- 图片任务测试实际核对独立部件/完整母版 PNG、绘制顺序、可见性、Slot 深度、任务内 Skill 和重开后的契约；回显夹具不是 AI 生图验收。

- 只读扫描 187 个工程文件、578 条场景记录，其中 569 条含人物表面（按工程图层类型识别），读取错误为 0。包含历史和 QA 副本，不能作为独立成品数量。发现 492 条单人物表面、723 条未分类、144 条已有补绘待接缝检查、10 条缺少补绘记录。
