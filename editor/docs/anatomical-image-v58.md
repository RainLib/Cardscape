# 人物拆层与图片任务 · 0.19.58

前后手臂、腿、翅膀和衣料必须按实际遮挡与纵深规划；后层需要真正补齐被遮挡的胸甲、关节、内裙与翼根。手、护腕、握点和武器保持刚性连续。用户要求的这一约束适用于所有人物制作和细化，不按固定部件数机械切图。

## 本轮修复

- 独立图片任务也携带 `card-atelier` Skill。人物任务包含有界的 `characterContext`：部件类型、左右、前后角色、所属主体、统一相机及各表面深度。旧工程尚未启用统一空间时不编造实际深度。
- `input.png` 使用当前工作部件，完整 `character-master.png` 作为独立身份与姿势参考。AI 助手、直接图片编辑和独立 Codex CLI 图片任务使用同一关系。后层补绘更新工作图时保留拆层前完整母版参考。
- 修复 AI 的 `imageTask` 误用完整母版作为当前部件输入的问题；首次拆层时保留母版，防止后续拆层只剩部分人物参考。
- AI 图片工作台增加可折叠“人物参考与遮挡关系”，可同时查看完整人物和当前待编辑部件。当前部件明确标记，展示实际相对深度。
- 深度检查区分“缺少补绘记录”和“已有补绘、此接缝仍需检查”。父层一次补绘不能证明所有部件的隐藏支撑已完成。
- Skill 要求记录部件计划、隐藏补绘对象及接缝，使用极限组合角度和最大衣料摆幅验证支撑范围；支撑不足时继续补绘或收紧深度/摆幅。仓库及已安装 Skill 同步。
