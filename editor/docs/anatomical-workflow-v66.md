## 发现并修复的阻塞

从客户端 AI 助手发送星潮守卫的拆层任务时，服务返回“编辑器上下文超过 64 KB”。原因是绑定材质除了可编辑参数，还带有完整内部组件文档和渲染缓存，重复进入主编辑场景的 AI 上下文。

现在只传材质的可编辑参数与来源场景标识、名称、图层 ID 和图片存在标记。完整素材仍保留在工程与渲染器中；进入组件主编辑区时，组件本身的图层仍由编辑上下文提供。没有增大服务的输入上限、裁切当前人物契约、修改 CLI 模型或覆盖素材。失败后控件本来可以恢复，未额外修改按钮逻辑。

修复后实际客户端任务上下文为 **26009 个 UTF-8 字节**，成功启动 Codex CLI，沿用 **gpt-6.1-sol / xhigh**。第一阶段 `duplicateCard` 已由客户端原子应用，独立副本名称为“星潮守卫 · 肢体景深验证”；原卡保留。

新增两项回归：大材质文档压缩后保留配置和来源标识，源对象不变；真实服务子进程读取精简上下文，仍保留工程绑定与人物检查数据，并能正常返回。全部 **308 项 Node 测试**和 **187 个 JS 语法检查**通过。
