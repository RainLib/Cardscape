# 香蕉轮廓与局部运动校准 · 0.19.90

先检查官方 Character Mastery 展示短片再实现。参考为 `snap-gap-v89/official-customization.gif`，SHA-256 `4120a49fbed32da8db275adeb08174bf4f2c0f60497368ef2b3a03fbc5dcca86`，69 帧、4610 ms；只用于量测，不成为运行资产。

## 设计依据

第 12 帧左侧独立香蕉有约 55 × 20 px 的厚弯月轮廓，金黄主体、浅色内脊、深色端头和稀疏棕色斑点。当前 Shader 是较细的对称抛物线，没有足够的体积和插画细节。新实现保留程序化轮廓，增加主体厚度、短端头、内脊和固定斑点；不增加贴图和粒子类型索引。

用完整颜色连通区域检出外围香蕉，避免先裁 ROI 把完整香蕉切成碎片。只保留外围、合适尺寸、至少五帧的轨迹。PCA 角度有 180° 歧义，GIF 相机也在旋转；异常拟合和连接到卡框的部分不用于速度估计。可见香蕉有正反两种转向，并从局部位置向外短距离移动；当前每颗香蕉同向慢转、沿轮廓长时间行走的实现与此不符。

## 拟实现

- 每次出生选择一个轮廓位置，在淡出后换位。沿局部法线短程外移，并允许上浮、指定方向及自定义发射区域。
- 独立尺寸与角速度种子，部分顺时针、部分逆时针；出生时长大，随后稳定并淡出，避免整组同步呼吸。零速度停止位移和旋转。
- 可见外移范围由发射半径限制，粒子不会持续飞远。保留原正反面、卡背变换、批次预算、共享时钟与省电档。
- WebGL 与 Godot 共用完全相同的香蕉表面函数；两端采样、实际 GPU 像素、客户端预览、暂停和保存导出均验证。
- 新默认值只在重新应用预设时使用，不能覆盖已有项目的作者参数。

该短片尚不足以确认完整游戏循环、全部发射位置和遮挡关系。轮廓对照和短轨迹校准不得标为全卡 1:1 验收。气泡完整周期也继续保留待验证状态。

## 实现与验证

按上述设计实现了厚弯月、内脊、棕色端头与固定斑点。真实 GPU 检查曾发现轮廓阴影方向写反、主体过暗，已修正并重新采集。每次出生选定轮廓位置，淡出后换位；独立尺寸、正反旋转、短程外移和零速度停止位移／旋转在 Web 与 Godot 同步。负角度规范化也已修复。现有工程的作者参数不会被新预设覆盖。

先以第 6、12 帧做形状设计，再用同一短片两条各六帧轨迹做姿态匹配。未用于设计的十帧，轮廓 F1 平均从 0.648 提升到 0.776，前景 RGB MAE 从 71.87 降至 50.74；这些量测只评价对齐后的字形轮廓与颜色，不评价随机位置、总数量、整卡遮挡、游戏循环或全卡 1:1。第 6 帧右侧轮廓较完整，第 12 帧左侧靠近框体，两者都保留以显示差异。

短 GIF 中筛出十条局部运动轨迹；速度 P10/P50/P90 为 0.197/0.249/0.318 卡宽每秒，角速度绝对值为 0.279/1.881/3.159 rad/s。相机正在旋转，屏幕运动不能直接等同于卡片局部运动。新的数量 20、寿命 1.7 s 等默认值仍是待完整参考校准的制作参数。角度连续性回归使用可见区间的圆周差，香蕉的 1 ms 上限改为 0.0035 rad，以覆盖参考中约 3 rad/s 的转动；此前固定 0.001 rad 的假设对应旧慢转，不适用于本次设计。
