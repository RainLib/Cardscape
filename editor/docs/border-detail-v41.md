# 边框细节 v0.19.41

四种新增配方从 Snap.Fan 当前详情页的动态 WebP 取四帧和全尺寸图观察。只按预览中可见的轮廓、颜色和材质结构制作；仍为 prototype，未宣称完整游戏循环、各视角逐帧 1:1。

| 配方 | 参考 | 制作方式 |
| --- | --- | --- |
| 银色链环 | https://snap.fan/cosmetics/borders/MetalChains/ | 交替正面和侧面链环，透明孔隙，随视角变化的金属反光。宽 28，无额外光晕。 |
| 翡翠符文 | https://snap.fan/cosmetics/borders/GlyphsGreen/ | 固定符号与局部圆环、三角线，翡翠底色，绿色局部弱脉动；外延最多 0.075 卡宽。 |
| 幻彩折光 | https://snap.fan/cosmetics/borders/RefractionRainbow/ | 随视角变化的淡彩膜和白色亮芯，贴近框体的窄光晕。 |
| Overdrive 充能 | https://snap.fan/cosmetics/borders/Overloaded/ | 黄白色宽亮芯与橙色边缘，局部衰减光晕。公开短预览没有证明独立闪电瞬态，因此没有补画未经验证的电弧。 |

枚举在原 0–11 之后追加 chains=12、glyphs=13、refraction=14、overloaded=15。各款保持平直切角壳体；无新增纹理；有外发光的样式启用已有光晕带、增加一次绘制，链环不增加外光晕绘制，链环通过 shared rimCoverage 同步到 WebGL/Godot 的透明度。2D 链环缩略图也保留透明孔隙，2D 仍是静态示意，动态材质以 3D 为准。

静态链环、折光与充能不请求独立播放循环；符文的弱脉动随统一时钟运行，暂停与速度 0 均冻结。框体几何在时间播放和拖动视角时复用；不同宽度的组件仍各用自身导出网格。

新增 test_frame_detail.gd 在真实 GPU 中检查四种配方、孔隙、透明中心、静态拓扑、符文播放、暂停、零速、翻背隐藏正面光晕与网格复用。runner 按正式配方生成测试输入，并拒绝引擎或 Shader 错误。

Neon Nights 参考已观察，其中左右独立霓虹招牌与文字需要单独的可编辑部件；不以普通粉色霓虹预设冒充。金色链条的媒体请求失败，暂保留为缺失。

覆盖表仍存在 70 项缺失：43 边框、12 粒子、15 卡面材质。237 项均未标记 accepted_1_to_1；60 项原创设计也仍处在设计阶段。设备帧率、完整游戏循环与全部型号校准仍待后续验证。
