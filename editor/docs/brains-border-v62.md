# Brains 银白脑回边框 · 0.19.62

参考为 [Snap.Fan Brains](https://snap.fan/cosmetics/borders/BorderBrains/) 的公开动态素材，实际查看了 76 帧、2.28 秒、820×1100 的 WebP。框面呈银白色脑回、深色沟槽与局部白色反射。参考像素只用于 QA，产品材质没有引用参考图片。

## 实现与操作

在 **外观与等级 → 效果组件库** 搜索“Brains”，选择“Brains 银白脑回”，应用到当前卡片。配方 `frame-brains` 使用宽 72、切角 48、厚度 16、倒角 3 的平直框体。已有工程不会自动覆盖作者设置。

脑回使用沿框坐标中的固定曲线，解析曲面法线生成银色反射与沟槽；光线响应查看角度，并有低幅度的时间变化。没有额外光晕、粒子或新纹理。框体几何与轮廓不随时间弯曲，当前仍是框面材质，没有制作独立脑回雕刻几何。`animation=none` 表示不叠加通用框动画；播放速度控制材质自身变化，速度为零冻结。

WebGL 与 Godot 使用字节一致的程序函数；正式导出的 SDK Shader 与仓库文件一致。Godot 的矩阵构造使用列向量，实际导入与 GPU 编译通过。

## 实际验证

- 303 项 Node 测试通过，185 个 JS 文件语法检查通过。
- 11 帧实际 WebGL 输出均无 GL 错误。从 0 到 0.78 秒，可见 RGB 改变 283234 像素，其中超过 2 个 RGB 等级的为 27785 像素，Alpha 不变。改变查看角度时，可见 RGB 改变 319848 像素。速度零时，0 与 100 秒输出完全一致。可见 RGB 量测按 Alpha 加权，不计算透明像素中的隐藏颜色。
- 正式导出的隔离工程在 Godot 4.7.1 / OpenGL / AMD Radeon Pro 5500M 上通过 17 种边框 GPU 回归。Brains 的区域取样包含亮面 1078 像素、银色主体 7580 像素、沟槽 807 像素。运动、暂停、速度零、中央透明以及无虚构外光晕均通过。
- 客户端共用前端实际应用、播放、暂停定位至 0.780 秒、倾斜、翻背、返回正面、撤销。宽度变化会更新相关框网格，但编译计数保持 2、场景重置计数保持 1；没有测量整体 FPS。
- 验证发现并修复恢复记录保存调度：写入期间的新修改会合并到下一次写入，旧版本回执不会提前显示“已同步”。真实客户端中，恢复同步尚未结束时应用 Brains 并撤销；恢复文件最终为 revision 630 / refraction / width 32，刷新后从首页重开仍为同一状态。两个直接执行实际调度函数的回归测试也通过。
- 未保存或覆盖正式工程，未自动点击独立 Electron 桌面窗口。

证据位于 `outputs/brains-v62/`：`verification.json`、`region-comparison.json`、`reference-current-folds.png`、`gpu-frames.json`、`godot-frames.log`、`godot-captures/`、`client-evidence.json`、`client-recovery.json`、`client-front.png`、`client-tilt.png`、`client-back.png`、`client-reopened.png`。保存修复前两个测试失败的日志为 `session-before-fix.log`。

## 还原范围

固定原点 (35,90)、单一比例 744/1024，对 7 个时刻的无遮挡区域作比较，没有逐帧拟合位置或相位。两个实现迭代间，左侧区域平均 RGB 绝对误差从 78.867 降至 62.229，下段从 75.021 降至 64.127，顶部从 87.805 降至 61.700；通道范围为 0–255。参考卡片自身也在移动，该量测不能独立证明 Shader 动画一致。

脑回拓扑、位置、局部折叠和反射形态仍与参考不同，完整游戏循环与相位未验证。**`accepted_1_to_1=false`**。237 项效果目录现有 182 个原型、55 项缺失、0 项完整 1:1 验收，不将调色近似或同名配方计作还原完成。
