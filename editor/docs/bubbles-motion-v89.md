# Blue Bubbles：官方动图校准 · 0.19.89

先记录参考与设计目标，再修改生产实现。官方来源是 [Character Mastery](https://marvelsnap.com/new-feature-character-mastery/) 的 `Customized-Character-Image01.gif`，432 × 432，64 帧、4,270 ms。它显示 Jeff、Candy Cane 边框和蓝色气泡；另一个官方 GIF 显示 Hit-Monkey 与香蕉。本轮只调整气泡，香蕉素材留作后续校准。

参考图只留在 QA 输出目录，不能成为游戏导出的纹理或逐帧动画。

## 可见证据与设计

现有气泡是细环、很弱的填充与通用沿框漂移。官方气泡有明显的半透明蓝色球面、窄边缘反射和左下方局部高光，保持圆形；外侧可见的大气泡向上并向外移动，不沿整圈边框爬行。

独立测量排除人物、数字和边框，用外侧 cyan 分割保留连续运动轨迹。右侧一条可用轨迹在 24 帧、1.55 秒内移动；拟合速度为每秒 0.248 个卡宽，大气泡直径中位数为 0.145 个卡宽。归一基准卡宽估计为 202 ± 4 px。这里只有一条完整保留轨迹，不能推定全部粒子数量、生命周期、随机分布和发射点；记录中保留该限制，不称为 1:1 验收。

制作目标：

- 同一四边形批次内程序化绘制蓝色薄膜球面、细边和局部反射；使用普通 Alpha 混合，避免加法把暗蓝球面变白。
- 预设用卡面轮廓发射并上浮，保留作者指定的区域和方向。每次出生选取新的位置，淡出期间隐藏重置；上浮速度用卡宽单位。
- 大小具有差异，采用独立大小种子；不让所有气泡一起呼吸。反射方向固定在屏幕方向，不随边框切线旋转。
- 发射仍遵守正反面、卡背、变换和共享时钟；省电档保持原有预算。旧项目参数不被预设覆盖，只有重新应用预设时使用新默认值。
- WebGL 与 Godot 共用同一球面函数，两端运动采样、暂停、继续、第一帧和真实 GPU 输出都需要验证。

## 已完成的验证

55 项相关回归通过；构建与 204 个文件语法检查通过。新增四项回归覆盖上浮连续性、尺寸稳定、隐藏重置、速度零、方向、区域、预算和两端共用的球面函数。原有配方、素材发布与预览提交检查也通过。

真实 WebGL 页面使用生产 Shader、采样器和单个批次，保存 64 帧 GPU PNG。第 40 帧外侧气泡在匹配圆心与尺度后的 RGB MAE 从 48.71 降至 16.93，内部薄膜误差从 57.59 降至 10.62；同一轨迹的其余 23 帧未参与该外观调整，平均 RGB MAE 从 43.87 降至 20.94。这个尺度匹配只检查表面与轮廓；随机布局、密度、生命周期、全卡遮挡与全部角度没有获得 1:1 验收。留出帧也不等于独立游戏录屏。

真实 Godot GPU 运行通过：JS / SDK 的位置、尺寸、透明度和角度一致；包含指定方向、零半径、长时刻、暂停和固定批次。球面实际像素验证了蓝膜、局部高光、透明外缘和静态材质稳定性，Shader 错误为零。首次独立工程运行尚无类缓存；初始化后，测试沿用了星辉 QA 底座的 64 px 切角，与 JS 默认 48 px 不一致。换成相同中立底座后完整通过；没有因此改变生产几何或放宽断言。

客户端在独立 QA 工程中选择“透明气泡”，显示 12 个粒子、0.24 卡宽/秒、正常颜色混合和向上方向。“沿轮廓上浮”的标签与方向入口可见。正式保存、重开后参数保留，动画继续。暂停前后时刻都为 272.290 秒，继续后推进到 272.540 秒。真实客户端导出的 Web 播放器编译成功，暂停前后均为 27.210 秒，继续后为 27.460 秒；导出的 Shader 与生产源码相同。
