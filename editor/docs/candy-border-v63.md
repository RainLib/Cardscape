# Halloween 紫橙糖果边框 · 0.19.63

参考为 [Snap.Fan Halloween Candy Cane](https://snap.fan/cosmetics/borders/BorderCandyCane_Halloween/) 链接的公开动态素材，实际取得 76 帧、2.25 秒、820×1100 的 WebP，并抽取 7 个时刻查看。可见固定的紫橙斜条纹、窄浅色高光、深色条纹接缝与偏紫外光。参考卡片自身也有运动；这段短预览不能证明完整游戏循环。参考像素仅用于 QA，程序材质没有引用这些图片。

## 入口与实现

在 **外观与等级 → 效果组件库** 搜索“`Halloween`”，选择“`Halloween 紫橙糖果`”，应用到当前卡片。配方 `frame-candy-halloween` 默认宽 38、切角 48、厚度 16、倒角 3。可以独立发布卡框组件，并绑定到其他卡片；图层、Mask、独立卡背和已有组件美术仍保留。

新增材质索引 23，旧 `candy` 索引 6 与其他既有索引保持不变。斜条纹使用连续平面坐标，每卡宽约 6.85 个周期，橙色部分约占 64%；切角不会切换成另一套条纹。框体保持平直，圆柱感由跨框宽度的曲面法线和反射产生，没有弯曲整张卡片。左右边、上下边及切角使用各自的法线方向。亮面避免将橙色变成整段黄色，外光由贴边色与稍远的紫色光叠加。

没有为条纹增加沿框流动或闪烁。时间变化为零、视角变化改变反射，符合本轮短参考中可辨识的固定条纹；完整游戏动效仍未验收。作者可另行开启通用框动画。外光仅在框外绘制，在 0.085 卡宽之外截止；不向卡面中央添加光。

WebGL 与 Godot 的共享程序函数字节一致，正式导出的 SDK Shader 与仓库文件一致。框面和外光分别绘制，未新增纹理或粒子系统。

- 303 项 Node 测试通过，186 个 JS 文件语法检查通过。现有回归扩展到新配方，检查发布、绑定、JSON 重开、独立卡背及作者美术保留。
