# 银色链环局部校准 · 0.19.56

参考：[Snap.Fan Silver Chains](https://snap.fan/cosmetics/borders/MetalChains/)。媒体为此前取得并目视确认的 77 帧、2.31 秒公开动态 WebP，摘要在 `outputs/snap-reference-2026-10-11/MetalChains-metadata.json`。本轮比较第 26 帧的无遮挡顶边；参考像素仅用于 QA，没有进入产品素材或导出资源。

原实现的链环是单排圆线。新版改为两排交错的切角链节，较宽的金属面、窄内孔、斜置连接件和交叠压暗。反光随观察角度改变，链节拓扑与孔隙不会随时间漂移。新配方宽度为 40 母版像素；已有工程保存的宽度参数继续沿用。

| 局部量测 | 修正前 | 修正后 |
| --- | ---: | ---: |
| 1.5 像素容差轮廓 F1 | 0.657 | 0.872 |
| 二值 IoU | 0.246 | 0.376 |
| 可见金属像素（参考 2246） | 869 | 2107 |
| 区域平均 RGB 绝对误差 | 70.11 | 71.92 |

相机以 683 像素卡宽作统一投影，只允许一个链节内的横向相位对齐及上下 5 像素对齐；没有逐链节拉伸。参考仍有透视和光照差异。**轮廓改善，颜色误差未改善**；这个局部指标不是整卡还原度，更不是完整游戏动效验收。`accepted_1_to_1` 仍为 false。

WebGL 与 Godot 共用相同的过程函数，原枚举 chains=12 保持不变。没有额外纹理、光晕带或链节网格，沿用框体绘制；孔隙通过 Alpha Coverage 显露后方画面。没有增加播放请求，也未测量设备帧率。无 WebGL 的 Canvas 降级仍为旧的圆环静态示意，不代表新版实时材质。

验证：26 项相关 Node 测试、176 文件语法检查和差异空白检查通过。真实 WebGL 保存了 6 帧，GL 错误为 0；链框时间变化像素为 0，倾斜反光变化 116224 像素，倾斜时 Coverage 变化为 0。Godot 4.7.1 OpenGL Compatibility 的正式导出函数生成了一张隔离验证卡，并完成 15 种边框 GPU 回归；银链孔隙 2698 像素，透明中心、无额外光晕、暂停、零速与网格复用通过，无 Shader 错误。

客户端在浏览器共用前端中完成“卡框设置 → 浏览边框配方 → 银色链环 → 应用当前卡片”，验证宽度 40 / chains、正面、倾斜、独立卡背和撤销回原有宽度 42 / glow。正式验证工坊没有覆盖保存。此轮没有自动操作独立 Electron 窗口。

证据：`outputs/chains-v56/verification.json`、`region-comparison.json`、`godot.log`、`client-front.png`、`client-tilt.png`、`client-back.png`。GPU 探针和量测脚本分别为 `scripts/probe-chain-reference.cjs`、`scripts/compare-chain-regions.py`。
