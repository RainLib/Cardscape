# 绿金电路 · 局部校准设计

参考为已确认可见的 `Circuits-motion.webp`，75 帧、2250 ms，来源 https://snap.fan/cosmetics/split-effects/Circuits/ 。只使用无遮挡区域确认走线与反射，不把参考图片当产品贴图导出。

原实现把同一个短走线单元重复并随机翻转。参考可见区域则是长的平行走线：上方垂直总线、右上斜向总线、左侧横向总线、两侧向底部延伸的折线；端点带环形焊盘。宽的银青反射带经过这些固定图案，图案本身没有随时间滑动。

本轮先改为固定总线组、较细的金属刻线与暗侧、稀疏焊盘，保留频率和颜色参数。相机、时间只改变表面反射。全卡被人物遮住的线路仍不能从短预览可靠恢复，完成状态不得用局部轮廓指标代替。

采用有界解析距离函数，暂不增加运行时贴图、网格或绘制批次。固定线路运算有 GPU 成本，资源数不增加不等于帧率提高。WebGL 与 Godot 使用同一函数文本。

校准后检查：正面无遮挡区域的轮廓与颜色、时间及视角反射、暂停和速度零、背景替换与原图叠加、客户端应用与撤销、正式 Godot 导出。参考短片并非完整游戏周期，`accepted_1_to_1` 保持未通过，直到完整动态与角度证据足够。
