# 电路背景校准与人物分类入口 · 0.19.59

参考为 [Snap.Fan Circuits](https://snap.fan/cosmetics/split-effects/Circuits/) 的公开动态素材，75 帧、2.25 秒；短展示不能证明完整游戏循环或任意查看角度。参考像素只用于 QA，没有进入产品贴图或 Godot 导出。

## 最终变化

电路从随机重复的小单元改为固定的长平行总线、窄刻线和稀疏环形焊盘。倾斜和时间改变银青反射带，走线保持固定。取消第一版端点的同心圆回环，并调校反射带的位置和金属暗侧。WebGL 与 Godot 共享相同函数。

配方默认仅作用于背景并叠加原图。客户端合成时发现，整卡范围会把电路线路画在脸、衣物和字标上；因此调整新应用配方的默认范围。已保存卡片的手动范围保持其作者设置，可重新应用配方或在属性中改为“卡面背景”。

玻璃材质原先也调用电路函数；现保留其独立旧图案函数，避免电路校准改变另一种效果。使用实际瓦坎达玻璃配方的前后 GPU 对照，两个采样状态改变均为 0 像素。

不新增纹理、网格或绘制 pass。客户端切换配方时 Shader 编译次数维持 2，资源重置次数维持 1。解析走线增加片元运算成本；没有量测设备帧率，不能宣称性能提高。

## 人物制作入口修复

“区域制作 → 人物部件”不再把未分类层显示为“披风”。未分类明确显示为空；选择实际部件后才允许应用分类或将选区拆为前/后层。分类按当前真实图层恢复，撤销后同步恢复。

客户端验证后披风从未分类到 cape / rear / 相对 Z 0.020，AI 图片工作台同步展示分类、完整人物母版与当前工作部件。测试后撤销分类，没有重绘历史人物。制作约束见 [人物景深约定](../skills/card-atelier/references/anatomical-depth.md)；仓库和已安装 Skill 字节一致。
