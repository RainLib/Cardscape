# 组件工坊与游戏运行时

卡片是装配配方。框体（窗体）、承载底板、卡背、幻彩材质、卡内特效、卡后粒子是分别编辑和发布的组件。人物/武器/披风是连续卡面资产，图片字标按语言发布。工坊中的卡片保留素材与组件固定版本引用；修改组件发布新版本，旧卡不会自动换装。发布与应用分开，应用可选择一张或多张卡，全部可撤销。

卡面背景是卡片内的场景图层，随卡片编辑，不作为独立组件发布；卡背是翻面后的独立表面；底板是承载层。幻彩/全息是材质能力，不复制一张角色 PNG。卡后粒子是在卡体后方发射并向外扩散的独立组件，不混入人物的武器发光 Mask。图片组件可归为场景、纹理、箔面、图案、插画，调色保留组件默认与单卡覆盖。Snap 卡框仍为平直切角框体，倒角与厚度属于几何，框体不受披风形变影响。

编辑入口：工坊统一资产目录 → 卡背 / 组件 → 选中资产 → 独立编辑；新增从“＋卡背”或“＋组件 / 导入”进入。版本、批量应用、引用和默认预览统一位于资产详情，取消重复的共享资源页面。独立画布用于检查组件本身；组合预览用于装配到当前卡片。草稿与临时预览不写入源卡，发布版本也不自动替换。预览时可随时恢复卡片实际组件，设为默认预览只影响工坊比较视图。

导出整套会逐卡暂存合成/字标，再按摘要去重源图、Mask与 Shader。Godot 目录包含 addon、library.tres、源纹理、Godot spatial Shader 和可运行演示。Resource 显式依赖确保素材随 PCK 导出；不要求游戏读散落的 JSON。不将浏览器的 GLSL ES 包装直接塞入 Godot：只有纯数学函数体自动适配，WebGL 专有操作明确拒绝，游戏可使用真正的 Godot Shader 替换。

推荐边界：

| 工坊负责 | Godot / 游戏负责 |
|---|---|
| 原画、图层注册、精细抠图、Mask、双语图片字标 | 卡片放置、相机、拖拽、互动状态、语言选择 |
| 框体、背景、卡背、材质、粒子组件的美术默认值 | 按实例替换组件与固定版本、战斗费用/战力、品质档位 |
| 武器/盔甲/披风的基础动效与整卡动作预设 | 触发时机、游戏 AnimationPlayer / Tween、世界空间特效 |
| 检查连续人物与刚性武器、框内外遮挡 | 调整图层偏移/缩放/深度、Slot、Shader uniform / 自定义 Shader |

游戏覆盖存到游戏场景或 Resource；不回写美术源文件。需要制作新图像或修改 Mask 时回工坊。默认配置仍来自工坊，游戏承担装配与最终调节，避免两端各做一个 Mask 编辑器。SDK 单实例材质独立，图片/Shader共享；背景与卡背保持刚性，人物内外两次绘制共用连续网格。

验证范围：Godot 4.7.1 Compatibility 实际 GPU；五卡/九组件/49张去重纹理；Shader编译、两实例独立性、语言切换、组件替换、数值跨语言保留、进场取样、粒子。尚未做移动端 GPU/FPS 压测，也未宣称与 Marvel Snap 逐帧一致。背景远/中/近的多景素材与统一相机编辑方案另见 spatial-depth-design.md，本轮保持单 Overscan 背景。

## 独立卡背场景

`back` 共享组件既兼容旧 `{src, adjustments}`，也接受 `card-back/1`：`src` 为静态封面，`parallax` 为背面视差倍率，`material` 专用于反面，`layers` 保存各层图像、位置、缩放、深度、透明度和混合方式。卡片只保存组件 ID/固定版本或解除绑定后的 `backScene`；正面 `layers`、Mask 和空间层级不包含卡背。

背面层按自己的顺序叠放，深度产生相机视差，采用中性视角注册补偿；不挤出图像轮廓，不接受人物形变或正面 GLSL。WebGL/Godot 均按独立反面表面渲染，每层两片刚性三角形。背面编辑器可预览草稿，发布和应用分开；游戏只替换卡背组件，正面与其他实例保持原配置。

资产限 1–8 层；WebGL 缓存最多 16 张纹理，单图不超过 16 MP / 8192 px。导出后的各层纹理与封面去重，保留材质与空间设置。旧卡背仍用原单张平面，不强制迁移。
