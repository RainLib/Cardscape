# 圆点、磨损边框和棱镜细化（0.19.43）

## 这轮调整

- Krackle：每簇三颗圆点在近框区域交错出生、放大和淡出，整簇淡出后再选择新位置。去掉长期沿边框绕行；局部漂移始终受半径限制。硬边填充有独立明暗层次，窄光晕贴着圆周；大小与明暗不靠降低全部粒子的透明度混在一起。
- 磨损：暗色漆槽、破碎银白掉漆边、少量划痕与随角度改变的金属反射。纹理位置固定，无额外运动、外光晕或框体弯曲。新增灰、紫、粉、橙、金、绿六种独立可复用配方，蓝、红也使用同一细化函数。预设宽度为 40，可手动修改；静态倾斜素材不足以推断游戏中的准确厚度。
- 棱镜：适度放大三角切面，细化接缝，区分灰银、柔和彩色和局部饱和彩色。每个切面独立接收反射，视角和时间改变反光而不移动三角网格。新增“棱镜切面背景”作为完整替换预设；已有“彩虹棱镜”的叠加默认保留，原图可继续用于叠加。

图层图片、Mask、顺序和独立卡背保持完整。旧的粒子、材质与边框枚举索引不变。WebGL 和 Godot 使用同一表面函数，CPU 粒子位置、尺寸、透明度与朝向另做跨渲染器比对。
