# Cosmic 星云与流星

设计依据：2026-10-12 读取的 [Cosmic 公共参考](https://snap.fan/cosmetics/reveal-effects/Space/)，动画 77 帧、2.28 秒，820 × 1000。素材位于 `editor/outputs/snap-reference-2026-10-11/space-flare-reference.webp`；仅用于观察，不打包进游戏。

参考显示：紫蓝云气沿卡片四周分布，内部有很小的星点；彩色细流星斜向掠过，包括画幅内的部分。云气应位于人物、卡框后方，流星位于卡面前方。现有 `mixed` 的圆点与星芒不符合这些形状和遮挡关系。

先制作独立 Cosmic 外形与配方：约八成实例绘制缓慢变化的多尺度云气，其余实例绘制短流星。中心限定在发射轮廓附近，流星的行程受外浮范围约束。保留命名区域、图层变换、正背面和整体动画绑定，局部区域可以制作局部星云。

云气与流星复用同一个样本数组、顶点缓冲和粒子预算。为保证破框人物遮住云气，同时让流星覆盖卡面，需要前后两个绘制阶段；WebGL 不重复生成或上传缓冲，Godot 两个绘制节点引用同一个 MultiMesh。普通粒子继续一次绘制。成本增加的是一遍透明几何绘制，不增加粒子实例、纹理或每颗粒子的节点。

云气使用两层连续噪声、边缘柔化和稀疏星点；流星使用细核、短拖尾和彩色高光。默认不触发 Glimmer 揭示射线。参考中没有完整循环和相机拖动，初始速度、生命周期和密度仍需后续录屏标定。新增配方不代表通过完整 1:1 验收。

验收：保存和重新打开、预设切换、发射区域与图层绑定、正面/倾斜/翻背、播放暂停、低预算、长时间位置连续性；WebGL 实际着色器与 Godot 实际 GPU 均需通过。画面重点检查云气不覆盖破框披风、流星可以跨过背景但不无限向外漂移。

## 同轮的边框与背景校正

本地 `prism-reference.jpg` 中能看到原画明暗和小三角分面。棱镜配方默认改为叠加原图，分面增加稳定的光谱差异；显式“替换为效果底”继续可选。替换模式的强度此前被忽略：改为在基础底色与完整效果之间调整，保持全覆盖、不透回原画。

`neon-border-motion.jpg` 显示连续亮芯、窄色光晕。普通冰蓝／绯红霓虹配方改为连续亮芯，不默认增加沿框巡游高光；亮芯加白，外晕保留颜色。用户仍可手动选择流光。所有调整同步 WebGL 和 Godot，无新增贴图或绘制批次。以上仍需同角度、完整周期标定，未通过 1:1 验收。
