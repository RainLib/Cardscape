# Gold Diamonds / Neon Trails · 0.19.91

## 先设计再实现

参考是 MarvelSnap 官方 Character Mastery Walkthrough `https://www.youtube.com/watch?v=w2e4TfaTu60`，实际已下载、播放；原始文件位于 `outputs/snap-gap-v90/mastery-walkthrough.mp4`，720p/60 fps，SHA-256 `5cb799d64ad3c555c4f0551d70db6347530d3250e76b03d94f3f5a853d4700d8`。本轮用原始帧 181–186.5 s，先检查画面再修改生产实现。

Neon Trails 在选择外观后出现彩色长光束，181 s 已安静，181.5 s 更换边框又出现一次，随后拉长、淡出。不能以持续缓慢贴框的短条纹替代。拟实现约 1.4 s 的一次性放射长光束，白色细芯、彩色光晕、不同射向，结束后停止显示；提供重播入口。该时长是参考镜头的初次拟合，尚不是完整游戏周期验收。

Gold Diamonds 在 183.5 s 首次选择时有向外散开的晶体；184–186.5 s 转为贴框、短程移动的大小晶体。可见切面有亮金、淡金和棕金，形状随着旋转改变，不能以四分区平面菱形替代。拟用六顶点、八切面的低模双锥体在单个四边形内做解析投影：不同种子独立旋转，切面接受固定方向的光；在四秒内观察的生命周期不能被推断为精确寿命。预设同时保留一次散开和持续贴框两部分。

共用现有固定粒子批次和类型索引。揭示配置增加“光束 / 跟随粒子”的外形，以及“只播放揭示”的开关；旧工程缺少这两个字段时保留旧的光束揭示加待机行为。Gold Diamonds 使用跟随粒子的揭示，Neon Trails 只播放光束揭示；不新增纹理或额外粒子节点。

两端使用同一表面函数、同一采样算法、同一暂停时钟。零速度停止晶体旋转与位移，旋转相位在传入表面函数前规约以控制长时钟精度。新预设只在重新应用时改变参数；已有作者参数保留。真实 WebGL、客户端选择/重播/保存/重开/导出和 Godot GPU 需要验证，不把测试通过称为完整 1:1 还原。

第一次真实 GPU 检查：切面轮廓已有变化，但亮面明显比 184 s 官方帧暗；放射光束呈细针，181.5 s 官方帧的白芯更宽。下一步在同一切面光照中增加亮面与镜面反射，保留暗面；光束加宽白芯，缩短端部衰减，保留彩色外晕。调整前后分别采集，不把整体曝光提升代替切面明暗，也不改变粒子数量来掩盖外形问题。

导出运行补齐：播放器在所有图层和 Mask 就绪前冻结共享时钟，资源就绪后从零开始，避免一次性揭示在加载期间耗尽。仅有揭示效果时显示“重播揭示”，调用同一播放接口；暂停与继续仍沿用共享时钟。

## 本轮证据与界限

- 生产 WebGL 采集 16 张效果帧、10 张晶体独立帧。原平面晶体的时间差为零；当前晶体旋转后 8,301 个像素改变，其中 2,894 个透明覆盖像素改变。八秒旋转相位首尾一致，零速度在 0 / 86,400 秒输出一致。八秒是本实现的旋转相位，不是已证实的 Snap 周期。
- Gold Diamonds 的揭示阶段为 56 个晶体加 32 个待机晶体，0.7 秒后保留 32 个；Neon Trails 为 40 个一次性光束，1.4 秒后为零。正式客户端验证了对应控件、重播、暂停、保存、重新加载首页后打开工程、导出参数一致。两个时长仍是初次拟合。
- 实际 UI 导出的 Godot 工程通过 `test_particle_icons.gd` 和 `test_particle_reveal.gd` 的真实 GPU 检查。覆盖晶体形状变化、白芯、暂停、零速度、跨渲染器采样、发射区域和预算；没有脚本或 Shader 错误。
- 导出播放器验证了 40 个光束重播、暂停时间保持 0.267 秒、继续后为零粒子和零绘制提交、再次重播恢复 40 个。慢图片加载期间冻结时钟的回归也通过。
