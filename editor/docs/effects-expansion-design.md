# Cardscape 效果扩展设计

目标已提高为边框、粒子、背景材质每类至少 50 个，共至少 150 个。当前记录边框 21 个、粒子 20 个、背景材质 20 个，共 61 个设计；0.19.47 已实现并验证 F01、F02、P01、B05，共 4 个既有样例。F21 星辉能量正在按已认可的设计稿重新制作，尚未获用户还原验收；另有 56 项已记录但未实现，至少 89 项尚待设计。先完成 Snap 的形态与动效对标，再继续原创设计和实现。原创样例与 Snap 参考验收分别记录；原创配方不计入 Snap 1:1 还原。

统一构图：边框保持平直切角，画面主角、标题和数值保持清楚。粒子中心靠近发射轮廓，默认外浮 2%～6% 卡宽，少数轨迹可由作者主动扩大。背景支持替换与原图叠加，不会改变人物原图。卡背可独立使用这些效果。

## 制作与验收顺序

1. 为 Snap 每项效果建立来源、录屏时段、参考尺寸、相机角度、循环时长与状态。只有具备动态图、同角度截图和运动对照的项才能进入 1:1 验收。调色近似和同名配方均不算通过。
2. 制作背景 → 边框 → 粒子，组合检查标题和数值可读性；检查正面、上下左右倾斜、侧面、翻背及原图叠加 / 替换。
3. 每个原创设计先出实际动效样片，记录粒子数、纹理尺寸、透明覆盖面积和 Shader 计算量，再调整细节；上述周期属于原创设计值，不是 Snap 实測值。
4. 使用同一效果数据导出 WebGL 与 Godot，验证依赖资源、初始化、播放 / 暂停、切换、共享组件引用和多卡性能。源工程保存 / 重开、撤销和独立制作均需通过。
5. 所有效果与 SDK 验收完成后再进行编辑器整体性能和操作台整理，避免用界面改版替代视觉目标。
