# Adamantium：淡出与生命周期分离验证

## 源像素先于计数

0.19.84 对照中的圆边检测数量中位数为 10，参考为 7。这个检测只保留接近原色且圆弧拟合完整的图标，参考卡面有更多遮挡，因此不能直接将数量改到 7，也不能将检测轨迹时长当作寿命。

新增 `scripts/measure-emblem-envelope.py`，使用同一公开 WebP 的逐帧像素中位值估计静态背景。在已量测轨迹附近对黄色的混合系数作独立估计，并保存原像素裁图。外围轨迹 22、23 在圆边检测结束后仍然能看到逐渐变暗的完整图标：22 的估计系数从 0.72 秒的 0.94 降到 0.84 秒的 0.28；23 从 0.75 秒的 0.93 降到 0.90 秒的 0.11。当前实现的整个淡出区间只有 `0.4 × 0.18 = 0.072` 秒，明显更短。

观测保留 39 条原轨迹，没有删除异常轨迹降低误差。中位背景可能被动画与重叠污染，混合系数不等于游戏 Alpha；窗口外的中心和半径是有限外推，不能当作新增真实轨迹。证据为 `outputs/emblem-v85/source-envelope.json`、`source-envelope-strips.png`。源 WebP 哈希与既有量测一致。

## 独立设计候选

先比较两种独立 QA 配方，不改活跃卡片或生产预设：

| 候选 | 名义寿命 | 单实例寿命差异 | 渐隐起点 | 渐隐终点 |
|---|---:|---|---:|---:|
| constant-600 | 0.60 秒 | 无 | 生命阶段 0.60 | 1.00 |
| varied-600 | 0.60 秒 | 独立种子控制 ±10% | 生命阶段 0.60 | 1.00 |

二次成长曲线仍按原来 0.4 秒的实际成长时间运行，避免为了延长渐隐而同时减慢成长。径向速度权重、外扩界限、图标形状、数量、发射面与颜色保留；新一轮出生仍在渐隐完成后换位置。候选寿命来自新的实现设计，不是声称恢复了游戏引擎参数。

捕获全部 77 个相同时刻的实际 Godot GPU 帧，生产基线与两种候选使用同一渲染器、生产图形 Shader、相机和样本打包。除原有尺寸和轨迹量测外，单独比较渐隐段；不能以计数误差下降抵消更差的真实淡出节奏。正式采用前需要跨引擎运行时采样与区域、暂停、预算回归。

该项及全量目标仍未验收为 1:1。这里没有新增原创类型，也不改变已保存星辉卡框、费用或战力。

## 初轮实际 GPU 与第三个方案

三组 231 帧在同一 Godot GPU 上采集成功，实际生产基线首帧与上一轮有效采集逐像素相同。黄色像素的混合系数独立于圆边检测计算，不把输入表里的 Alpha 当作观测结果。39 条参考轨迹全部保留，12 条具备完整、连续、单调的 0.90→0.30 阈值段，其时长分位数为 0.08158 / 0.10760 / 0.12717 秒。其他轨迹的无法量测原因也保存在结果中。30 ms 帧间阈值采用线性插值，仍有时间分辨率限制。

基线淡出分位数误差 0.06546 秒，constant 为 0.01473 秒，varied 为 0.01023 秒；varied 的速度分位数误差从 0.002356 降到 0.001655。但尺寸误差从 0.000869 变为 0.001707，圆边检测的成长率与曲率误差增加，不能声称所有时序已经对齐。

在 varied 已观测点上进行下一次参数预测：512 个匹配点、44 条完整匹配轨迹，预测不模拟新尺寸造成的遮挡与检测变化，因此仅用于第三个独立候选的设计。`growth-prediction.json` 标记 `predictionOnly=true` / `gpuVerified=false`。rounded 候选 balanced-600 保留 varied 的寿命与渐隐，将可辨识组出生因子调为 0.36、成长幅度为 `0.20 + 0.86 × h^1.58`、成长参考时间 0.44 秒、统一尺寸因子 0.955。微小伴随图标保留原来的成长与大小，不用大图标预测改变它们。仍须重新采集全部 77 帧。

balanced 的真实尺寸误差为 0.001071，接近基线但仍略高；成长率与曲率的圆边统计仍变差，因此尚不采用。0.6 秒并未被观测证明是正确周期。第四个候选 varied-500 比较 0.5 秒名义周期、±20% 的独立寿命、生命阶段 0.5 开始渐隐。0.90→0.30 的理论淡出段仍接近新的源观测，但不延长完全不透明的阶段；成长保留原有 0.4 秒参考时间、出生与峰值参数。采用与否仍由新的 GPU 帧比较决定。

varied-500 的实测淡出误差为 0.005562 秒，可检测数量分位数为 5 / 7 / 9，参考为 4 / 7 / 9；可见时长误差从 0.038 降到 0.022 秒。尺寸整体略小，误差 0.000924，高于基线 0.000869。最后一组候选保留该周期与渐隐，只将可辨识组的尺寸统一乘以 1.02，微小伴随组不变；需再采集全部 77 帧核对，不用数值缩放替代真实像素。

## 0.19.85 采用与剩余差异

本轮共采集 462 帧真实 GPU PNG：生产基线以及五组候选各 77 帧。全部 GPU 任务无 Shader 错误，首帧非空；基线与上一轮有效 v84 首帧逐像素相同。最终采用 varied-500-final，证据为 `final-gpu.json`、`final-size.json`、`final-temporal.json`、`final-envelope.json`，对照裁图为 `final-comparison.png`，全部方案汇总为 `trial-summary.json`。

| 平均分位数误差 | v84 | 最终候选 | 改变 |
|---|---:|---:|---|
| 淡出段 0.90→0.30 / 秒 | 0.065465 | 0.005096 | 减少约 92.2% |
| 圆边半径 / 卡宽 | 0.000869 | 0.000512 | 减少约 41.1% |
| 圆边检测可见时长 / 秒 | 0.038000 | 0.017000 | 减少约 55.3% |
| 可检测数量 P10 / P50 / P90 | 7 / 10 / 13 | 5 / 7 / 9 | 参考为 4 / 7 / 9 |

52 条保留轨迹均向外，51 条的成长曲率为负。速度误差从 0.002356 增至 0.003998 卡宽/秒，成长比误差从 0.12366 增至 0.13582，增长率误差从 0.012806 增至 0.014458，曲率误差从 0.47669 增至 0.51912。这些统计没有改善，必须继续校准；保留全部轨迹，不删除重叠或异常轨迹降低误差。尺寸变化和较长的暗部可见期改变了检测保留的样本，因此不能把一个分位数吻合称作完整还原。

实现上，默认名义周期由 0.4 改为 0.5 秒，各实例使用独立 ±20% 周期差异；阶段 0.5 开始渐隐，阶段 1 完全透明后重选位置。成长仍为逐渐减速的曲线，参考时间为名义周期的 0.8 倍；可辨识组乘以 1.02，微小组不变。发射面、径向速度权重、边界、色彩和图标形状保留。WebGL 与 Godot 使用同一公式。已保存的名义寿命参数不改写；新曲线随当前运行版本生效。

真实生产采样与最终候选 GPU 输入逐项比较，77 帧 × 40 实例 × 10 值打包布局，所有字段最大差都为零，见 `production-sample-parity.json`。保持一个绘制批次、40 个默认实例和 61,440 字节固定缓冲区；没有新增纹理、Shader pass 或运行时图像处理依赖。

29 项粒子相关回归通过，包含长时钟、有界外扩、渐隐期间继续移动、错开的死亡时刻、低预算、来源区域、卡背映射与共享图形。出生时刻从实际尺寸复位位置搜索，不在测试中复制寿命随机公式。成长测试在完全可见区间检查继续成长且速度递减。构建与语法检查通过 200 文件。

使用当前 `exportGodot` 导出一张独立验证卡、零纹理、一份通用 Shader，导出的 SDK 核心文件与当前源文件逐字节相同。实际 GPU 运行 `test_particle_reveal.gd` 通过，Shader 错误为零，5.878 秒为测试任务耗时；覆盖 Godot 运行时与 JS 样本的尺寸、位置、Alpha、朝向、数量，Adamantium 三种发射区域及 0 / 0.7 / 100 / 86400 秒，以及暂停、正面限制和固定批次。日志为 `godot-runtime-parity.log`，截图为 `godot-runtime-captures/`，导出工程为 `godot-runtime/godot/`。第一次 QA 清单遗漏 `frameStyle` 被运行检查拒绝；失败日志保留为 `godot-incomplete-fixture-rejected.log`，随后用完整验证清单重新导出、实际运行，并非忽略错误当作通过。

本轮未修改活跃工坊、当前边框、费用或战力，没有重启独立 Electron 窗口。源码及构建为 0.19.85；当前页面或桌面是否已加载该版本不作为本轮已验证内容。全量 Snap 动效、每类至少 50 个原创和后续编辑器优化继续保持原范围，`accepted_1_to_1=false`。
