# 0.19.51：按可见轨迹修正 Adamantium

## 证据与差异

参考：https://snap.fan/cosmetics/reveal-effects/Wolverine/ 。对已确认可见的 77 帧、2310 ms WebP 做蓝色圆边 / 黄色面部的颜色分割、圆弧拟合及连续轨迹关联。QA 脚本为 `scripts/measure-emblem-motion.py`，依赖仅用于量测，不进入客户端或游戏运行时。

保留至少六帧连续检测的 39 条轨迹。它们全部向外运动，拟合扩散中心约为 (422.8, 528.3)，靠近 820 × 1000 图像中的卡片中心。可见速度 P10 / P50 / P90 约为 118 / 186 / 314 px/s；轨迹末端与起点半径比的中位数为 1.69，显示观察窗口内存在放大。

这些数值有明确边界：重叠、裁切、暗色、低分辨率会让检测断开；邻近关联不是引擎粒子身份；0.15–0.28 秒的可见窗口不是完整寿命；WebP 时间戳不能证明原游戏的时间倍率。不能由此标记 1:1 完成。原图上标注的轨迹及完整数据在 `outputs/emblem-v51-measurement/reference-tracks.png`、`reference-motion.json`。

## 修改

原先的面具粒子沿框缘缓慢切向漂移并往复变大变小，与上述可见运动不一致。现在从框内带状区域出生，沿卡片中心至出生位置的方向向外运动，在可见阶段逐步放大，外沿淡出后才重新选位置。外漂位置受卡框轮廓和外浮范围限制，避免持续飞远。

默认速度 0.35、寿命 0.75 s 是用于接近该短片行为的待校准配方，未宣称是原游戏参数。已有工程的速度、寿命与发射区域保持为其保存值；重新选择 Adamantium 配方可应用新默认值。

WebGL 与 Godot 同步运动公式。形状编号、图形 Shader、颜色、粒子容量、贴图和绘制批次均保持原有契约；花朵、爪印、披萨与原创粒子的运动不受此修正影响。
