# 0.19.52：面具粒子的尺寸分布与连续预览

公开短片的可见轨迹量测见 `emblem-motion-v51.md`。本轮继续比较圆边尺寸，不将检测统计当作完整游戏的 1:1 验收。

## 实际 GPU 帧比较

`scripts/probe-emblem-reference.cjs` 用生产采样函数、实例打包和粒子 Shader，在真实 WebGL 上绘制 77 帧。页面通过下载按钮导出 PNG 帧与配准参数。`scripts/compare-emblem-frames.py` 对这些帧和参考使用相同圆弧检测规则，按卡宽归一化尺寸；Python 依赖只用于 QA。

| 半径 / 卡宽 | P10 | P50 | P90 |
| --- | --- | --- | --- |
| 参考短片 | 0.02840 | 0.03996 | 0.05515 |
| v51 GPU | 0.01484 | 0.02685 | 0.05440 |
| v52 GPU | 0.02956 | 0.04122 | 0.05540 |

三个尺寸分位数的平均绝对误差从 0.009140 降至 0.000888。这里只量测尺寸分布：人物、背景、卡片比例、逐粒子身份和相机尚未完全配准，不能解读为整体还原度。检测到的圆边数量也不等于引擎实例数量。

## 修改与性能

尺寸随机种子与出生相位分离，避免全场粒子在相近时刻共同变大。每五个实例保留两个可辨识面具与三个微小背景面具，可辨识组优先进入低预算。两组均随生命周期放大。四个种子的一周期透明度加权面积最大/最小比均低于 1.8；种子 1 从原先 5.26 降至 1.72。

新预设寿命为 0.4 秒，是用于该短片的实验配方，未证明原游戏参数。已保存工程保留自己的参数，重新选择 Adamantium 预设才应用新的默认值。

WebGL 与 Godot 同步公式。仍为图形编号 25、40 个默认实例、一个绘制批次和 61,440 字节预分配实例缓冲区。没有新纹理、额外 Shader pass 或运行时图像处理依赖。
