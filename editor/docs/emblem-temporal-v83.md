# Adamantium：径向速度分布校准

## 参考与制作方案

使用 [SnapFan Adamantium](https://snap.fan/cosmetics/reveal-effects/Wolverine/) 的公开动画，原始文件为 `outputs/snap-reference-2026-10-11/reveal-Wolverine-motion.webp`。它有 77 帧、2.31 秒，表现为黄色面具圆片从框内向外扩散；这段素材不能证明完整游戏播放周期。

先用相同颜色检测、圆环拟合与连续轨迹匹配，比较参考和实际 WebGL 像素。卡宽归一后的速度 P10 / P50 / P90 为参考 `0.18179 / 0.28637 / 0.48334`，0.19.82 为 `0.22067 / 0.34493 / 0.44154`。中位速度约快 20%，慢速群过快、快速群偏慢。新采集的 77 帧与之前尺寸校准的生产结果一致。

保留面具造型、大小、寿命、数量、透明渐隐、每次出生的发射点和最大外扩边界。只把各粒子的速度权重从均匀线性分布改为偏向慢速、保留少量快速粒子的曲线：以同一个稳定随机数 `h`，候选权重为 `0.47 + 0.95 × h²`。这条曲线是依据量测提出的校准方案，采用前仍须以真实 GPU 画面验证改善，而不是以公式或单元测试代替视觉证据。

前景放置、卡背切换、区域绑定和一批次提交保持现有生产能力。WebGL 与 Godot 使用相同速度曲线。用户当前星辉边框卡片不用于替换粒子的验证；比较页和导出验证使用独立场景。

## 验收边界

- 新速度分位数误差应低于原误差 `0.04641`，并检查低速、中速、高速分组都有改善。
- 向外运动、外扩边界、固定暂停像素、前／后发射面与尺寸分布仍须成立。
- 尺寸和寿命参数不因可见轨迹时长而修改：参考原画有遮挡，短暂可见不等于寿命短。
- 参考卡宽约 650 px；最近邻匹配可能误认重叠粒子，WebP 帧时长也不证明游戏时钟。所有数据保留这些限制，`accepted_1_to_1` 仍为 `false`。

## 实际结果

修改前后分别通过比较页按钮捕获 77 帧真实 WebGL PNG。新速度 P10 / P50 / P90 为 `0.18225 / 0.28499 / 0.48065`；三个分组误差均下降，平均误差从 `0.04641` 降到 `0.001511`，减少约 96.74%。65 条保留轨迹全部向外。

尺寸参数没有修改，但位置变化会改变重叠和可检测样本。尺寸分位数平均误差从 `0.000888` 变为 `0.001071` 卡宽，中位半径仍比参考大约 4.3%。可检测数量中位数从 9 变为 10，参考为 7；可见轨迹时长和成长比误差没有改善。因此这次仅采用已得到证据支持的速度修正，不宣称密度、生命周期和整体效果已经还原。

27 项相关 Node 回归通过，覆盖长期有界外扩、出生渐隐、大小分组、低预算、区域／卡背绑定和版本发布。构建与语法检查通过 199 个文件，`git diff --check` 通过。

独立粒子场景经真实 `exportGodot` 导出，只有一张验证卡、零纹理，未修改活跃工坊。Godot 4.7.1 / OpenGL Compatibility / AMD Radeon Pro 5500M 的 `test_particle_reveal.gd` GPU 验证通过，Shader 错误为零。它逐项比较编辑器采样与实际 Godot MultiMesh 的位置、大小、透明度、朝向和批次，覆盖 Adamantium 的三种发射区域及 0 / 0.7 / 100 / 86400 秒，并检查暂停、正面限制与预算。36.76 秒是整项测试耗时，不是实时性能或 FPS 数据。

证据目录为 `outputs/emblem-v83/`：`before-gpu.json`、`after-gpu.json` 为浏览器下载的原始帧；`before-size.json`、`after-size.json`、`before-temporal.json`、`after-temporal.json` 为一致检测算法的结果；`godot-reveal.log`、`godot-captures/` 和 `fixture.json` 为导出证据；`webgl-after.jpg` 为 0.6 秒真实对照截图。比较脚本为 `scripts/compare-emblem-temporal.py`，页面生成器为 `scripts/probe-emblem-reference.cjs`。

全长游戏录屏、真实相机遮挡、可见密度、出生／消失曲线和其他随机种子的视觉统计仍需继续核对，`accepted_1_to_1` 保持 `false`。源代码版本为 0.19.83；用户当前独立桌面窗口未在本轮更新或重新启动。
