# 导出预设与缩放细节

点击顶部「导出」，选择使用场景后直接「导出 WebGL 与 Godot」。设置随工程保存，可撤销；整套工坊导出统一使用所选预设，各卡的图层规则独立保留。旧工程在未选择预设的情况下仍可通过原有导出接口输出。

| 预设 | 小图尺寸 | 高清尺寸 | 自动切换宽度 | 可编辑源工程默认 |
| --- | --- | --- | --- | --- |
| 原图保真 | 原始尺寸 | 原始尺寸、原始编码 | 默认关闭 | 附带 |
| 移动端列表 | 原尺寸的 1/4 | 原始尺寸 | 420 px | 不附带 |
| 移动端详情 | 原尺寸的 1/2 | 原始尺寸 | 360 px | 不附带 |
| 桌面端 | 原尺寸的 1/2 | 原始尺寸 | 280 px | 不附带 |

宽度指投影后的卡片像素宽度；浏览器计入最高 2 倍设备像素比，Godot 使用视口的实际投影。缩小时在阈值的 85% 切回，避免临界位置来回加载。关闭自动切换后，列表预设固定小图，其余固定高清。WebGL 播放器和 Godot 示例均有缩放滑块。

运行时预设的两档彩色图片使用无损 WebP；缩小先预乘 Alpha 再 Lanczos 采样，避免透明边缘变暗。原图保真保留输入图片字节。覆盖卡面图层、封面、图片字标、卡背和图片粒子；嵌入共享组件的独立源图片沿用原资源，效果开关随父卡。Mask 保持原始无损数据；不修改 UV、骨架、权重、逐骨骼绑定、FFD 或动作。

「效果与图层规则」默认收起。小图默认关闭粒子、复杂材质、光晕、流光、扫光及附加片元 Shader；基础图片和人物动画继续显示。可分别保留小图效果，并将图层设为「始终保留／仅放大显示／始终隐藏」。部件隐藏不删除骨骼依赖；高清恢复当前动画时刻的部件。所有颜色变体按内容摘要去重。两档图片均随包交付，运行时按需加载；小图并不意味着整个包含高清档的压缩包一定更小。

完整一档解码后才同时替换纹理与效果；加载期间保留上一档，失败保留已加载画面。切档不重建蒙皮网格，不重启动画。源工程可选附带，运行时预设默认排除可编辑图片备份。编辑器原工程仍需正常保存。

WebGL 播放器与多卡验收现在共用 `player-textures.js` 的配准逻辑：两档均按 `sourceWindow` 和原始 `sourceSize` 恢复母版位置，背景保留扩展画幅。完整导出与远端瘦客户端自动包含此模块；手动组合脚本的游戏可复用 `CardPlayerTextures.registered(layer, image, sourceSize)`，并保留图层 `asset` 与文档 `exportProfile`，让渲染器继续按原尺寸采样。实际大小档色标及本地／远端／缓存播放器连续缩放、暂停时钟回归已通过。

桌面 1／4／8／16 卡的实际发布贴图对照及验收页面入口见 [性能记录](performance-2026-11-03.md)。页面可单独选择小图保留特效，区分图片分辨率与特效降级；反复换档检查为独立选项。桌面结果不作为手机帧率承诺。

WebGL 从 `manifest.json` 的 `exportProfile` 读取设置和纹理，`frontAsset` 为封面入口。Godot 的 `library.tres` 使用 `texture_paths` 延迟加载彩色变体；Mask 和旧资源继续正常引用。打包 Godot 项目时选择 **Export all resources**，或在选择性导出时显式包含 `assets/` 下全部变体，确保动态路径图片进入 PCK。游戏中可设置 `CardscapeCard.detail_pixel_width`（正数为 UI 投影宽度，0 使用相机），用 `export_detail_state()` 读取当前档位与效果；Node3D 大小或相机距离变化会自动切档。

每包生成 `export-report.json`，列出预设、各档彩色纹理解码 RGBA 估算及保留策略。估算不包含 Mask、驱动开销、共享组件与帧缓冲，不能视为整卡 GPU 占用。

验证入口：`node --test editor/tests/export-profile.test.cjs editor/tests/preview-playback.test.cjs`；原生透明边缘及原图尺寸测试在 `editor/native/src/export_texture.rs`。真实 Spine 4.3.26 卡牌的 Godot 验证使用 `tests/test_export_detail.gd`，采样全部动作、实际纹理尺寸、图层恢复、粒子开关及网格和时钟连续性。浏览器与 Godot 的桌面 GPU 验证不替代手机真机的内存和帧率测试。
