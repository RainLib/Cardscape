# 火焰边框动态校准

2026-10-12。参考 Snap.Fan 的 Fire、FireBlue、FireGold、FireGreen、FirePink、FirePurple、FireRainbow、FireRed、FireWhite 详情页中的实际动态 WebP。九段均已查看，76～77 帧、2.28～2.31 秒；媒体、SHA-256 和接触表保存在本地参考目录，不进入产品或游戏导出。

## 观察与实现

框体是平直切角矩形。亮芯沿窄框连续分布，局部出现较亮的斑片；框外火舌沿画面的竖直方向向上翻动，顶部的火舌比底部更明显。火舌保持在框附近，不用远距离发射粒子表达。原有沿周长／横断面移动的噪声容易形成环绕流纹，需替换。

使用同一向上平移的二维场同时驱动框内热斑和框外火舌。外侧形态由切角轮廓距离及向上的轮廓法向控制：顶部允许较长火舌，侧边较短，底部收紧。细亮芯持续保留，火舌从亮根部渐变至有色尖端。沿用既有 16 三角面的外环，不增加纹理、粒子发射器或后处理。

九个配色逐项提供。彩虹参考主要是银白底和淡青／淡粉反光，追加独立 `fire-iridescent` 类型，仅改变局部反射色；不沿用无限边框的大幅全色谱环绕。已有火焰索引 10 保持不变，新增索引 11。图层、框饰、发射区域和卡背的独立设置保持可编辑。

WebGL 与 Godot 使用相同的距离、流场、颜色和火舌函数，效果时钟受播放、暂停、时间跳转及速度 0 控制。框体仍由刚性几何生成，不参与卡面弯曲。

## 验证要求

检查真实 GPU 编译、逐项切换、亮芯与外侧可见性、上行方向、同时间暂停稳定、速度 0 静止、外侧范围、框体平直；再经实际工坊保存／重开和客户端导出检查 Godot 的配方与源码一致性。粒子与背景叠加的整卡画面需另行查看。

短片只支持可见形态的校准，尚未证明完整游戏周期或所有角度的 1:1。所有条目仍保持未验收状态。

## 整卡协调

同轮对照 Prism 的公开动态片段：三角面有较明亮的中性色底和宽银白反射区，原来的暗色面过于均匀。棱镜叠加改为面色与原画的受控混合，银白反射随相机和时钟扫过；金／黑棱镜保持独立配方。替换与叠加仍分别处理，不改写源图。科技光环默认外浮从 10% 收紧到 7.5%、强度从 0.9 降到 0.8；已手动调整的旧文档不自动改写。
