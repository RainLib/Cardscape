# Glimmer：揭示与持续闪片

依据公开 Gold Glimmer 动图逐帧查看：0～0.09 s 有向外放射的细长光线，0.18 s 光线基本退去；0.30～2.28 s 是小型发光闪片和光点。该片段共 77 帧、2.31 s，只能用于校准这段表现，不能证明完整游戏循环或 1:1 验收。

参考：https://snap.fan/cosmetics/reveal-effects/GlimmerGold/

## 本轮实现

- 独立 `particles.reveal` 参数：启用、时长、数量、尺寸、行程、拉伸。第一帧即出现放射线，随后向外移动、缩短、消失；只在揭示时触发，不按粒子寿命重复。
- 持续阶段使用闪片外形和区域内漂浮，覆盖卡面与框缘。既有星芒外形保留供其他配方使用。
- 揭示线和持续闪片同一批次；低性能档按比例分配同一个总预算，固定 256 上限。既有七项粒子采样格式保留，批次另加外形覆盖值。
- 编辑器入口放在粒子面板：可启用/调整揭示，并点击“重播揭示”；预览下方既有暂停与动效时间可检查阶段。重播从预览 0 s 开始，不产生历史编辑记录。
- SDK 提供 `play_particle_reveal()`、`seek_particle_reveal(seconds)`；`enter` 动作触发揭示。组件跟随整卡揭示时钟，暂停后位置与随机序列保持不变。

本轮参考方向和初始参数属于待校准原型，不标记 1:1 完成。原有边框和金色材质改进继续保留。

## 持续阶段细化设计（v35）

公开片段 0.30～2.28 s 的框外也有闪片；框外左右窄区的金色连通区域中，尺寸中位数为 8×9 px，90 分位约 21×24 px（820×1000 的参考图，包含光晕，并非精确粒子尺寸）。参见 `../outputs/editor-v19.28/glimmer-margin-observations-v35.json`。因此不能只让所有粒子在内框的矩形里垂直移动。

- 新增可选择的「卡面与框缘漂浮」轨迹：覆盖发射区域内部，并向外扩展作者指定的 `radius`。以卡宽为单位约束范围，不随寿命无限扩散。矩形、椭圆和点区域均保持明确边界；图层变换及正反面绑定继续生效。
- 在边界附近淡出再回到另一侧，避免位置突然跳转。随机种子确定每片的速度和方向，暂停、重放、保存恢复后保持一致。
- 闪片含微小柔光点、普通薄片及少数大薄片；薄片独立慢转，角度不再全都沿运动方向。只改变闪片外形，不改变既有像素、叶片、半调点和大圆点。
- 默认参数作为初始标定：56 片、大小 0.018、拉伸 1.2、外浮 0.065、速度 0.055、寿命 2.8 s。这些是原型参数，不能作为 Snap 的实测周期。
- 新轨迹需要真实 UI、命名区域/变换、预算、两端采样和 GPU 验证；仍维持一个批次，无新增纹理或粒子节点。
