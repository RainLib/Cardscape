# 全息镭射

在「外观 → 效果组件库 → 镭射」选择配方并点击「应用」。也可以在「外观材质组件」直接选择「全息镭射」。「自动匹配原图」会分析底图的主色、点缀色与亮部，设置纹样、箔色和高光位置。

- 彩虹、烫金、扫光和闪粉可独立调节。箔色支持自动色温、金、冰银、紫金、玫瑰金、青洋红、余烬铜、黑铬及自定义颜色。
- 高光签名支持亮部星光、脉冲星芒与光环、横向光迹和关闭。漂浮粒子可跟随纹样，也可选光点、花瓣、雪花、余烬、火花、散景或关闭。已经绑定或制作的粒子可继续通过发射区域与动作时间轴编辑。
- 默认保护人物、拆层部件和文字。彩色反射会在受保护的区域减弱，白色扫光仍会经过。对单张合成图，点击「标注主体」，用相近颜色、智能选区、矩形选区或画笔建立 Mask。白笔增加保护，黑笔减弱保护。蒙版随工程、便携 WebGL 和 Godot 导出。
- 「叠加纹样」可加入三层，逐层选择图案和强度，和主纹样、独立粒子及装裱一起保存。组件库内的星云金缮、极光冰晶和霓虹碎镜可直接试叠加。碎玻璃按切面折射底图，霓虹故障错开颜色通道，两种效果都服从主体 Mask。
- 「卡面装裱」提供原图卡面、金属箔框、全图签名、画廊装裱和评级收藏。可调整缩放、平移以及卡名、题注、评级、编号和稀有度。装裱保存底图并同步裁切主体 Mask。「移除装裱」恢复底图和此前的框体。

纹样包括基础虹膜、宇宙泡纹、日冕放射、丝绸波纹、冰晶切面、淡彩光谱、金缮裂纹、樱花箔印、冰霜结晶、极光帘、碎玻璃、霓虹故障、熔火薄膜和电弧闪纹，以及衍射光栅、等高线箔和水银波纹。

在 3D 预览或便携播放器打开「展示与录制」，可选拖动、跟随指针、设备倾斜、自动悬浮和纯展示。手机倾斜需要浏览器允许读取传感器。纯展示可用 Esc 退出。

「录制内容」可选自动悬浮或所选动作，画面比例可选 2:3 或 9:16。自动悬浮默认导出一轮 3 秒、16 fps 的 GIF，或两轮 60 fps 的 MP4。录制动作会从时间轴起点采样一遍，默认 24 fps，并保留整卡位移、骨骼关键帧和动作粒子。循环接缝取决于关键帧和动效本身。GIF 全程采用共享调色板并无限循环，MP4 使用浏览器的 H.264 编码器。查看包含浮雕和同步雷斩的 [雷曜誓约示例](../examples/production-card/stormglass-oath/README.md)。

组合新预设可沿用现有纹样，在 [镭射配方](../renderer/workshop/laser-foil.ts) 中增加一行独立配方。增加新纹样时将 ID 追加到纹样表，在 [共享渲染代码](../renderer/rendering/laser-foil-glsl.ts) 和 [Godot 着色器](../../sdk/godot/addons/cardscape/laser_foil.gdshaderinc) 实现相同的图案，并同步 Godot 纹样顺序。已有编号随导出资源使用。
