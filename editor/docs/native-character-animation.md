# 自有人物动画

开发分支：`feature/native-character-animation`。使用自有数据、采样器和编辑工具，与现有 2.5D 卡片合成。第一期实现刚性骨骼；第二期已增加带权重网格、两节 IK、叠加表情形变，以及可视骨架和权重编辑。第三期补齐不规则拓扑、权重圆饼与联动编辑。第四期增加多节 IK、约束管理与 Spine JSON 子集适配，范围与验收见文末。以下保留此前各期的历史验证结果。

## 制作

1. 先拆分人物，补齐运动时会露出的关节和后层。为手、握点和武器保持连续的握持关系，检查动作的允许范围。
2. 打开右侧 **动画 → 人物关节与图层绑定**。新建根关节和子关节；新关节的位置来自当前图层的旋转中心。画布显示独立实心骨段、起点、末端及父子层级。
3. 设置关节名称、父节点和初始坐标。根节点使用 1024×1536 母版坐标，子关节使用父节点的局部坐标。初始姿势只定义转轴和关系，不移动原始图片。
4. 选中并解锁图片，点击 **绑定当前图层**。多个图片可绑定同一关节；未独立绑定的拆层衣料跟随母版，显式绑定优先。父子关系不改变图层排序与 Z。
5. 点击 **制作关节动画**，或在底部时间轴的 **动画目标** 选择关节。编辑水平／垂直位移、旋转、统一缩放和透明度。数值先临时预览，点击 **记录关键帧** 才保存；删除关键帧／清除轨道／撤销沿用现有操作。
6. 在右侧实际卡片预览检查运动、倾斜、破框和光效。左侧可切换初始拓扑或当前动作姿势，并显示图片透明轮廓；静态输出始终使用初始合成。保存重开后继续编辑，动态导出分别检查独立 WebGL 播放器和 Godot。

修改初始关节会改变已有动作的转轴和局部坐标关系，需重新检查动作。删除关节前先删除子关节；删除会同时清除其绑定及各动作中的对应轨道。删除图片会清理其绑定。绑定操作拒绝锁定图层。

## 原生契约

`document.characterRig.schema = card-character-rig/1`：

- `bones[]`：`id / name / parentId / x / y / rotation / scale`。父节点必须存在且无循环；允许多个独立人物根节点。可选 `tip: [x,y]` 定义骨骼自身局部末端（每分量 ±4096）；用于编辑器骨段及距离初绑，不改变运行时矩阵、关节、图片或 IK 末端。旧工程按子节点／IK 末端推断，叶节点默认长度 80。
- `bindings[]`：`layerId / boneId`。每张图片最多绑定一个关节，多个图片可以共用关节。
- `actions[].boneTracks[boneId]`：`x / y / rotation / scale / opacity` 的关键帧字典。关键帧沿用 `at ∈ [0,1] / value / ease`，支持 linear、smooth、hold。

坐标为源图像素，Y 向下，角度为顺时针度数。骨骼世界姿势按父子顺序计算，部件变换为 `posedWorld × inverse(restWorld)`，然后组合图层原有变换与旋转中心。因此默认姿势恢复原画，Mask 和 UV 跟随部件，刚性部件保持形状。整卡动作再作用于完整卡片。柔性拆层的根部连接继续使用现有连接权重。

上限：64 个关节、64 条绑定；每动作每关节每轨道 64 个关键帧，动作数量／时长沿用工程限制。旧工程缺少 `characterRig` 时保持原有行为。采样不改写工程，刚性动画只更新现有表面的变换／透明度，不重新生成纹理或网格。

WebGL 使用 `character-animation-model.js`，Godot 使用自有 `character_animation.gd`。两端按相同时间和插值契约采样；暂停定位可到达循环动作的结束关键帧。

## 导入适配

`character-animation-import.js` 提供注册式格式适配器。适配器由应用代码安装，不执行导入文件中的脚本：

```js
const registry = CardCharacterImport.createRegistry();
registry.register({
  id: 'example-format',
  convert(source, { document, layerMap }) {
    return {
      schema: 'card-character-animation-import/1',
      characterRig: nativeRig,
      actions: nativeActions,
      unsupported: []
    };
  }
});
const candidate = registry.convert('example-format', source, document, { layerMap });
```

转换结果必须通过原生绑定、轨道及完整运行时校验后原子应用；有不支持的能力时明确拒绝，不能静默丢弃。当前仅内置原生 JSON 导入／导出，交换文件不包含图片，需要匹配当前工程的图层 ID。导入替换绑定，替换同 ID 动作；其他动作的整卡轨道保留，旧人物轨道清除。

后续 Spine 导入流程为：读取 skeleton／atlas／图片，准备本机素材图层，映射骨骼与图层 ID，再转换为原生绑定和动作。带权重网格、IK、剪切或复杂约束的文件，须等自有系统具备对应能力后才能完整导入。Spine 导入尚未实现；接口不依赖 Spine 播放器或第三方运行时。

## 第二期：自有蒙皮、IK 与表情（2026-10-16）

只使用量子枪客的一张独立副本。源工程和图层 PNG 字节保持不变；实际编辑器保存可能重新编码 Mask PNG，其注册像素保持不变。9 张实际人物部件共用注册拓扑与连续权重场；手与枪为单骨骼区域。切口附近的深度回到主体平面，离开切口后保留各部件独立 Z，避免以压平整个人物掩盖接缝。衣摆保留末端运动。

### 第二期初版操作（第三期交互见后文）

- 骨架改为带深色描边的实心骨段、关节点、不同骨骼颜色、金色选中状态和避让标签；可暗化原画。圆点是关节位置，实心段表示父子连接；IK 末端另画到握点。
- 左侧提供骨架、网格、权重入口，画布上方显示对应工具和参数。骨架默认拖动试姿势，点击“记录姿势”写入当前时刻；“记录动画”模式松手直接写关键帧，一次拖动可一次撤销。初始绑定模式改变关节结构。选骨同步到时间轴目标，Esc／失焦取消当前拖动。
- 原图用于绑定和权重绘制；动作模式叠加当前骨架，实际网格变形在 3D 联动预览查看。原图不烘焙改写。
- 自有网格蒙皮面板支持规则网格创建、画布选点、精确顶点坐标和权重数值；权重热力图显示当前骨骼影响，全骨骼模式按骨骼颜色混合。颜色与骨架／权重列表对应。
- 画布笔刷提供增加、减少、替换、平滑，包含半径、强度和替换目标。权重锁定是当前编辑会话的工具状态，不写入运行时文件；刷涂和平滑保留被锁定骨骼的数值，每顶点始终至多 4 个影响且合计 100%。单骨骼 100% 没有其他接收骨骼时不能直接减少，应先给另一骨骼增加权重。
- 按距离初绑只使用列表中勾选的骨骼，按父子骨段距离给出初始分配；这是自有基础算法，不等同于 Spine 的拓扑自动权重算法。随后播放极限动作，用笔刷修正关节，保持手与武器一致。整个网格平滑使用三角形邻接，不跨越断开的网格岛。
- IK 面板编辑两节父子链、末端局部偏移、目标、弯曲侧和混合权重；时间轴可记录目标 X/Y 和权重。IK 已驱动的骨骼要用目标操作，或先将 IK 权重设为 0 再制作纯 FK。
- 表情控制器独立叠加，形变先于蒙皮。当前网格可用源像素中心／半径和偏移建立表情目标；“替换”会覆盖该网格该控制器的已有目标。控制器权重在时间轴制作动画。

交互参考 [Spine 官方 Weights 文档](https://en.esotericsoftware.com/spine-weights) 的可视权重、笔刷和平滑思路。实现不使用其源代码或运行时。

### 新增原生字段

`characterRig` 的版本仍为 `/1`，高级字段均可选；旧文件无需迁移：

```js
constraints: [{id, name, rootId, tipId, end: [x,y], target: [x,y], bend: 1, mix: 1}]
expressions: [{id, name, value: 0}]
meshes: [{
  layerId,
  vertices: [sourceX, sourceY, /* ... */],
  uv: [u, v, /* ... */],
  triangles: [a, b, c, /* ... */],
  weights: [[{boneId, weight}], /* one entry per vertex */],
  morphs: [{expressionId, deltas: [vertexIndex, dx, dy, /* ... */]}],
  depths: [relativeLayerZ, /* optional, one entry per vertex */]
}]
actions: [{
  // existing action fields ...
  ikTracks: {constraintId: {x: keyframes, y: keyframes, mix: keyframes}},
  expressionTracks: {expressionId: {value: keyframes}}
}]
```

IK 目标为注册卡片像素；顶点、UV、形变为源图注册坐标。两节 IK 使用自有解析解，保持骨长，不可达目标限制于可达环带，可选正反弯曲和 FK/IK 权重。LBS 使用每个骨骼的初始补偿矩阵，最多 4 骨骼混合。UV 和所有 Mask 保持固定；只有位置缓冲改变。Godot 共享原有内外表面网格并更新顶点区域，暂停时复用位置缓冲；WebGL 同样复用网格和暂停姿势。删除被权重或 IK 引用的骨骼会明确拒绝；删除图层会清理其网格。

上限：每网格 4096 顶点，整卡 16384 顶点，32 网格、16 个 IK 约束、32 个表情控制器；每顶点 1–4 权重。非法 ID、循环骨骼、退化三角形、异常数值、缺失引用和未归一化权重在保存前拒绝。原生导入／导出包含高级字段，导入清理被替换绑定的旧高级轨道；Spine 文件转换仍是后续适配工作。

## 第三期：拓扑、权重与图片的联动编辑

当前入口为左侧工具栏与画布上方的 **骨架／网格／权重** 工具。权重属于网格顶点；圆饼是权重的可视化。规则网格只保留为快速起步选项，默认使用透明轮廓和关节布点。

1. 选择人物图片，进入 **网格 → 网格结构与轮廓**。轮廓算法读取源 Alpha，保留透明边距与非透明细线，处理凹边、分离区域和自接触；内部使用疏密采样，关节与表情区域加密，三角化后优化内部边。透明孔洞使用原图透明像素保留。
2. 已有网格可重建，使用旧三角形的重心插值保留权重、深度及稀疏表情目标。同拓扑且注册变换相同的拆层可同步操作。共用表情形变可避免新采样点在接缝两侧得到不同形变；同名目标冲突会拒绝，不会覆盖独立表情，可关闭同步后分别编辑。
3. 初始拓扑工具支持加点、拖点、删除内部点，以及选择一条内部边的两个端点后翻转连边。拖点同步 UV；加点继承邻域属性，删除会闭合孔区并重排权重、深度和表情索引。拒绝翻转／退化三角形。边界点当前通过移动调整；还没有任意内部约束边绘制或删除边界点。
4. 切换 **权重**，点击或框选顶点，Shift／⌘／Ctrl 加选。圆饼扇区对应骨骼颜色，选中点放大且不因屏幕避让隐藏；关联线和骨骼圈指明实际影响骨骼，列表显示单点值或多点范围。点击扇区、列表骨骼或 Alt 点击画布骨骼会同步选择影响骨骼和时间轴目标。
5. 使用 **测试弯曲 20°** 或输入 ±90° 内的测试旋转。测试选中骨骼；若该骨骼受 IK 控制，预览中临时关闭对应 IK。姿势只用于预览，权重修改写入工程。2D 贴图、圆饼、选点和 3D 使用同一采样姿势；修改权重会改变实际网格。恢复姿势后继续制作当前动作。
6. 增加／减少／替换／平滑笔刷显示外圈范围和内圈满强度区，支持羽化与选区限制；按路径等距采样避免事件频率改变笔触密度。锁定和初绑参与骨骼按工程／网格在本机记忆。支持批量数值、复制粘贴、局部初绑／平滑及清理小于 1% 的权重。每笔只形成一次撤销，Esc 或失焦取消。
7. 青色图片轮廓显示当前选中图片的透明边界，并随同一个网格变形。切换骨架、拓扑或权重时显示对应工具状态，人物操作期间隐藏普通图片缩放框。骨骼实心段始终从自身起点指向自身末端，虚线表示父子层级。

2D 姿势视图用于几何编辑，完整 Z 遮挡、光效、破框和游戏效果仍在 3D 预览检查。轮廓、权重圆饼、笔刷、测试姿势均为编辑视图，不烘焙到静态图和导出动作。拓扑修改后 GPU 网格可重新建立；一般权重和动画预览继续复用缓冲。

### 人物编辑工作区与姿势操纵

左侧工具栏提供骨架、网格、权重入口；画布上方为对应的工具选项。当前关节与当前图片图层分别选择：骨骼决定操纵目标和权重影响，图层决定正在编辑哪张图片的网格。底部只保留可收起的动画时间轴；上方可直接播放动作。

- **记录姿势**把试姿势一次写入当前动作时刻，可一次撤销。先在时间轴选择动作与时刻，再试摆、记录。**记录动画**模式则在每次拖动松手时写当前帧，适合连续制作关键帧。改变时刻、播放动作、切换动作或修改骨架会清除临时姿势；权重编辑不会清除。
- **初始绑定**用于关节结构、父子关系、骨段末端与图层绑定。它修改初始骨架，不能代替动作关键帧。网格拓扑工具也在初始姿势中操作。

## 第四期：复杂 IK 链与约束管理（2026-10-16）

人物管理面板的 **IK** 页支持连续的 **1–16 节**骨骼链；起始骨骼到末节之间按父子关系自动包含全部关节。两节解析求解保留旧动作，多节 CCD 支持每关节的最小／最大角度。限制相对初始绑定姿势，`min=max=0` 可固定关节；不拉伸骨长。CCD 每次从当前 FK 关键帧重新求解，暂停定位、倒序查看与导出不依赖上一帧状态。

选择约束后，可修改名称、启停、默认混合权重、求解顺序、迭代上限（1–128）和容差（0.001–10 注册像素）。列表可直接启停及上移／下移；全部修改沿用工程校验、撤销与重做。新增约束时为旧约束补上其现有顺序。骨链在画布上高亮，粉色十字可拖动；临时试姿势可恢复或记录到时间轴。停用约束不会被拖动隐式启用。

目标空间可选 **卡片坐标** 或 **独立目标骨骼的局部偏移**。目标骨骼本身可以制作关键帧；此时 IK 的 X／Y 轨道及拖动写入局部偏移。拒绝目标位于被驱动子链、目标依赖循环或依赖顺序错误的配置。显式排序的重叠链允许依次求解，后面的约束可以覆盖前面的结果；诊断显示最终网格的残差，不能把中途命中目标当作最终成功。

原生约束保留 `rootId / tipId / end / target / bend / mix`，新增可选字段：

| 字段 | 含义 |
| --- | --- |
| `solver` | `analytic` 或 `ccd`；旧数据默认两节解析 |
| `enabled` / `order` | 默认启用；求解顺序，相同顺序按数组位置稳定排序 |
| `targetBoneId` | 缺省为卡片坐标；指定后 `target` 与 X／Y 轨道为目标骨骼局部偏移 |
| `iterations` / `tolerance` | CCD 默认 48 次、0.05 px；求解状态显示残差与迭代数 |
| `limits[]` | `{boneId,min,max}`，角度相对初始绑定；仅 CCD 使用 |

最多 16 个约束。没有顺序的旧约束仍拒绝相互包含的链。CCD 的 `bend` 用于打破共线奇异姿势的初始方向；非共线链从 FK 姿势求解，尚无极向量、拉伸或弹性约束。动作检查新增未收敛次数：满混合 CCD 残差超过容差时不会报告通过。WebGL 与导出 Godot 使用对应的自有求解器。

## Spine JSON 导入适配（2026-10-16）

入口为 **骨架 → 关节结构与图层绑定 → 导入 Spine JSON…**。选择文件，设置 Skin、缩放与注册原点，将 Slot 映射到已有图片，再检查后应用。每张图片可指定注册画布内的 UV 矩形；默认整个 1024×1536 画布。检查失败不会应用部分数据，检查后修改选项必须重新检查，工程版本变化也会拒绝旧检查结果。整次导入是一条可撤销操作。

当前实现支持 JSON **3.8、4.0–4.2 的可表达子集**，包括：普通继承及正向均匀缩放骨骼、选定 Skin 的 Region／普通或加权 Mesh、每顶点最多 4 骨骼、位移／旋转／均匀缩放动画、单节／两节 IK 与混合轨道。坐标与角度转换为自有的 Y 向下约定。目标骨骼转换成可动画的自有目标，Slot 绘制顺序转换为映射图层的遮挡顺序，未映射图层保留位置。

导入保留图片与 Mask；已有顶点深度按 UV 保留／插值，覆盖范围外取最近已有顶点。替换原骨架和人物动画，保留纯整卡动作。权重仍使用自有 LBS，同一顶点各骨骼的世界绑定位置差异超过 0.05 px 时会阻止导入；阈值内的量化差异按合成绑定点处理。标准平滑贝塞尔直接保留为原生 `smooth`，其他贝塞尔自适应转换为线性帧，检查容差为转换空间 0.02 单位，每轨仍限 64 帧；超限不会自动降精度。

尚不支持二进制 `.spine/.skel`、图集包图片装载、链接 Mesh、附件序列／切换、FFD、路径／变换／物理约束、动态绘制顺序、着色轨道、非均匀或负缩放、特殊继承及 IK 拉伸／软化。这些内容会在检查中列出或报出明确错误，不能把当前适配器视为完整 Spine 兼容运行时。

数据格式依据 [Spine JSON 文档](https://esotericsoftware.com/spine-json-format)，4.2 的字段与曲线通道布局参考其公开格式读取定义；没有集成或复制 Spine Runtime，转换后的播放、权重、编辑与导出均使用自有系统。

## Spine 4.3.26、图集与 FFD（2026-10-17）

这一阶段以 **Spine 4.3.26 Professional** 为实际验收版本，同时保留 3.8／4.0–4.2 子集。使用官方 Goblins `.spine` 源工程，由本机 4.3.26 命令行实际导出 `goblins-pro.json`，没有改写版本号或用自有数据冒充 Spine 导出。图集来自同一官方样例；通过本机 4.3.26 解包后，与自有加载器的 41 个区域逐字节比较 RGBA，全部一致，其中 16 个区域旋转了 90°。来源：[官方样例](https://github.com/EsotericSoftware/spine-runtimes/tree/4.2/examples/goblins)、[图集格式](https://esotericsoftware.com/spine-atlas-format)、[CLI](https://esotericsoftware.com/spine-command-line-interface)。第三方样例和本机验证产物位于忽略的 `outputs/`，未并入产品源码。

操作入口仍为 **人物管理 → 骨架 → 关节结构与图层绑定 → 导入 Spine JSON…**：

1. 选择 JSON，然后选择 Skin。
2. 点击 **加载图集与页图片…**，同时选择一个 `.atlas` 和全部 PNG／JPEG／WebP 页图片。支持多页、旧式 `xy/size/orig/offset`、新式 `bounds/offsets`、0／90／180／270° 旋转、透明裁边还原及 PMA 转直通 Alpha。只读取明确选择的本地文件，缺页、同名页歧义、越界或路径穿越会报错。
3. 图片映射选择“图集 · 新增独立图片”，或继续使用已有图片的 UV 矩形；点击 **适合卡片** 可根据源骨架边界填写缩放与原点。
4. **检查导入** 显示骨骼、网格、动作、IK 和 FFD 网格轨道数量，检查通过才可应用。图集图片、骨架、动作与遮挡顺序整次撤销／重做，导入失败不留部分图片。加载后工程版本变化会要求重新检查。
5. 在 **权重** 页选择图片及影响骨骼，可以修改权重、初始顶点位置；在 **骨架** 页试姿势并恢复，3D 区域选择动作播放或定位。FFD 随动作时刻求值。单骨骼顶点不能单独将总权重降低，面板会提示先给第二根骨骼分配权重。

FFD 支持旧版 `deform` 和 4.x 的 `attachments/skin/slot/attachment/deform`；稀疏 `offset` 按数值分量计数，允许奇数偏移，缺少的分量恢复为 0。普通网格的偏移在 Slot 骨骼空间，加权网格按每个骨骼影响分别应用；不是把所有影响合成一个公共顶点位移。不同骨骼的绑定点也分别保留，因此不再因量化或不同绑定位置拒绝可表示的加权网格。

原生契约新增：

- `mesh.binds[boneId] = [vertexIndex, dx, dy, ...]`：逐影响绑定偏移，使用图片原始局部像素；省略表示共享原始顶点。
- `action.deformTracks[layerId][boneId] = [{at,deltas,ease,curve?}, ...]`：同样的稀疏顶点偏移，在蒙皮前叠加；最多 256 帧，总 FFD／绑定偏移不超过 4M 数值。
- `binding.opacity` 和 `action.layerTracks[layerId].opacity`：所选 Skin 中的附件切换与空附件转换为独立图片可见性，不扩散到同骨骼的其他图片。
- 标量关键帧可选 `curve=[cx1,cy1,cx2,cy2]`：X 为当前区间归一化时间，Y 为原生轨道绝对值；FFD 的曲线 Y 为区间混合进度。两端自有播放器直接求贝塞尔，不再把真实工程的复杂曲线强行烘焙进 64 帧。

导入的 FFD／逐影响绑定网格支持手工加点、删除内部点、自动补网、笔刷与选区局部加密及保留动画重建。加点按重心坐标插值 UV、深度和权重，并按每根骨骼的权重条件插值绑定位置与全部动作的 FFD 向量；保留每帧时间、插值方式及贝塞尔曲线。删除同步重排绑定、权重、FFD、深度和表情索引，保留其余顶点的动画；被删除顶点独有的局部细节随之移除，不能保证删除后的曲面与原曲面完全一致。关键点和约束边端点需先解除标记或连接；边界点支持删除并自动重连，超出动画或轮廓误差阈值会取消整次操作。

导入网格的“保留动画重建”在原有网格域中执行，保留原顶点、动画采样点、用户关键点与约束边，按间距增补顶点并在原分片内重新调整连边；不把图集 UV 像素位置当作骨架初始位置，也不跨越原动画分片边界。它不会自动减少原动画顶点。手工重新描轮廓则会替换取样域，需要检查丢弃区域和动作保护结果。导入绑定网格移动顶点保留 UV，用于调整初始形状。初始姿势的 2D 图片、网格线与轮廓也通过实际网格映射绘制；仅 FFD 改变而骨骼不动时仍刷新图像缓存。

单顶点仍限制 4 根骨骼。如果新点邻域的有效影响合计超过 4 根，编辑明确报错并回滚，不静默裁剪权重。补网的动作保护回滚包括逐骨骼绑定与 FFD 数据，共享网格各自保留自己的轨道。仍未支持二进制、链接 Mesh、序列动画、动态 Slot 绘制顺序、路径／变换／物理约束、特殊继承、非均匀或负缩放及完整颜色轨道；检查会阻止这些内容，不代表完整的 Spine 4.3 功能兼容。

### 从误差选区修正并再次减面（2026-10-17）

在动画对比窗口展开“高误差区域修正”：定位需要检查的动作和时刻，设置“误差下限 px”，点击“选中当前帧高误差区”，或将画布工具切换为“框选高误差区”后拖框。Shift 追加选区，金色三角面显示选中的源区域。选区绑定源 UV，可随动作运动，关闭／重开及重新减面后保留；切换图层或误差指标时清除。低于 0.0002 px 的浮点噪声不会成为高误差选区。
