# 霓虹边框：框内光晕设计与验证

## 参考与设计边界

参考 [SnapFan Blue Neon](https://snap.fan/cosmetics/borders/NeonBlue/) 的公开渲染短序列，本地文件为 `outputs/snap-reference-2026-10-11/neon-border-motion.webp`。参考图右侧直边有亮芯、向外扩散的蓝色光晕，以及向画幅内扩散的青色光。原 0.19.81 实现只绘制框外光晕，窗口一侧直接断开。

这次保留已有 42 px 亮芯结构、切角和平直厚度；补充窗口边缘的窄光晕。内晕在 56 px 内衰减到透明，近边缘用较紧的高亮与较宽的低强度青光叠加。56 px 是依据参考画面的起始估计，参考内侧同时含原画颜色，不能把它当作已分离测得的原始 Bloom 半径。其他五种霓虹配色复用结构，仍需分别校准。

霓虹在已有公开短序列中没有得到独立自动脉冲的证据，因此保持静止发光与视角反射；不加入臆测的待机呼吸。星辉原创边框的四秒流动循环仍独立保留。

## 实现约束

- 仅霓虹扩展现有 aura 环面的内缘；保留 16 个三角形、一个 aura 绘制提交，无新增贴图。
- 框体、厚度与卡背几何保持原值。更换霓虹／普通框只更新 aura 网格；六种霓虹配色切换保持网格复用。
- WebGL、静态 2D 缩略图和 Godot 共用同一内晕函数。窗口中央保持透明，翻背隐藏正面光晕。
- 透明 WebGL 画布改用独立颜色／Alpha 混合因子；Alpha 按覆盖率合成，避免原 `SRC_ALPHA` 把光晕 Alpha 再乘一次。QA 使用与正式预览一致的预乘 Alpha 画布，并检查 RGB / Alpha 是否回到原始光色。
- 独立 QA 场景验证光晕与真实网格，不替换用户当前已保存的星辉边框卡片。

`accepted_1_to_1` 保持 `false`。完整游戏相机、全长待机录像、内晕的分离素材和其他配色对照仍是验收缺口。

## 验证结果

38 项相关回归通过，包括图片边框、静态缩略图、播放时钟、资源复用和效果预览提交。独立浏览器 QA 使用真实生产 `CardSurfaceRenderer`、`CardFrameRaster` 和 GLSL，窗口内侧距离 6 / 24 / 56 px 的光晕 Alpha 分别为 66 / 13 / 0；修复前均为 0。真实网格取样的 RGB / Alpha 与原始光色误差小于 0.03，避免透明画布重复相乘。

实际 Godot 4.7.1 OpenGL Compatibility、AMD Radeon Pro 5500M 验证六种配色：内晕衰减、中央不填充、倾斜反射、暂停稳定、待机静止、网格复用与翻背隐藏通过。冰蓝亮芯宽度／投影卡宽仍为 0.03372，内边增亮 0.25490，中段增亮 0.04314。运行无 Shader 错误。

证据：`outputs/neon-spill-v82/godot.log`、`godot-captures/`、`regression.log`；独立 QA 生成脚本为 `scripts/probe-neon-spill.cjs`。这是单独的框验证导出，不是用户当前卡片的新增保存或桌面窗口点击验证。
