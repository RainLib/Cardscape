# 0.19.50：Adamantium 面具粒子

## 参考与边界

参考页面：https://snap.fan/cosmetics/reveal-effects/Wolverine/ 。本地公开渲染序列为 `outputs/snap-reference-2026-10-11/reveal-Wolverine-motion.webp`，77 帧，2310 ms。可见蓝色圆边、黄色面部、黑色翼状面罩和白色眼睛；尺寸不同的图标覆盖卡面与近框区域。

当前序列不能证明游戏中的完整生命周期、出生位置随机分布、漂移速度和循环时序。该项保持 `accepted_1_to_1=false`，仍需视觉和动效校准。Doodlepool 的现有下载只有普通 Wasp 卡面，已明确标为无效参考，不用于替代其效果。

## 实现与操作

入口：右侧「粒子 / 发射区域」→「浏览粒子配方」→ `Adamantium 面具`。也可直接在粒子形状中选择该类型，调整数量、大小、发射区域和范围；配方可发布为工坊可复用粒子组件。

- `adamantium` 追加为粒子形状编号 25，旧编号不变。
- 程序化多色轮廓：蓝色圆边、黄色圆盘、曲面黑色面罩、白色眼睛。参考图片不会进入运行资源。
- 默认 40 个图标，普通透明混合，卡面前方发射；近框分布包含向内和向外的局部位置。
- 大小随生命周期变化，位置重选前完成淡出；角度轻摆，固定颜色保持稳定。当前生命周期 2.8 s 是待校准预设，不宣称来源于原游戏时序。
- 不新增粒子贴图或绘制批次，复用既有 256 粒子容量的 61,440 B 顶点缓冲区。低预算会裁减数量；单卡、卡背区域和图层区域使用既有绑定方式。
- WebGL 与 Godot 使用相同的图形函数与轨迹数据。帧索引和运动测试不能替代与原游戏逐帧对照。

本轮新增一个参考类型实现，不增加原创数量。原创仍为 4 / 60：卡框 2、粒子 1、材质 1。

- 最新页面通过真实候选预览、应用和撤销验证：视角保持 −18°，时间从 2867.592 秒继续至 2947.523 秒，主体网格 7、纹理 18、Shader 编译 2、场景重置 1 均未增加；撤销新增解码为 0。工具调用间隔包含操作时间，不能当作局部更新耗时。证据见 `outputs/emblem-v50/incremental-evidence.json` 与 `editor.png`。
