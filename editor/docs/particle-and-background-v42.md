# 粒子与背景细化 v0.19.42

以 Snap.Fan 的 Flowers、PawPrints、Pizza 动态 WebP 和 RaysRainbow 参考观察轮廓、色彩、范围及阶段变化。公开素材约 2.31 秒，只能作为短段参考；完整游戏循环、全部视角和逐帧 1:1 仍待校准。这些配方保留 prototype 状态。

| 配方 | 轮廓与合成 | 默认运动 |
| --- | --- | --- |
| 彩虹花朵 | 五个圆瓣、透明中心、纯色彩虹剪影 | 44 个实例，卡框附近与少量框内点位，大小错落、轻微旋转与淡入淡出 |
| 彩虹爪印 | 四个分离的趾垫和掌垫，透明间隙 | 32 个实例，轻微摆角和短距离漂移 |
| 披萨切片 | 弧形饼边、金黄色饼身、红色配料 | 24 个实例，大小变化、缓慢旋转，保留自身颜色 |

新增 flower=21、paw=22、pizza=23；原 0–20 保持稳定。新图形由同一套 GLSL 在 WebGL/Godot 绘制，不需要新增贴图。普通透明合成保持清晰边缘，避免加法混合把剪影洗成光团。Wakandan 长光束的顶点拉伸已明确限制在 visual=20，避免误拉长新剪影。

围框模式每次重生选择另一个有界点位。淡出隐藏位置重置，漂移范围受 radius 限制；spread 控制向框内延伸的距离。花朵和披萨的旋转角归一化到一圈内，避免长时间累加导致 Godot 实例属性的半精度存储误差。发射区域、层绑定、正背面、预算和暂停继续使用公共采样流程。非围框轨迹仍使用编辑器原有轨迹；运动参数属于当前标定起点，未由短参考证明为游戏内精确值。

背景替换此前按素材 UV 定位，素材缩放、位移可能改变特效中心和比例；现在使用卡片局部空间。WebGL/Godot 同步修复，原画叠加保留素材 UV。放射条纹同时提高默认密度、调整弧度，加入灰银底、分段淡彩反射和较弱的暗部细节，减少大面积平色条带。

三种粒子均为一个批次、固定 61,440 字节缓冲区；默认单次上传分别为 10,560 / 7,680 / 5,760 字节。背景修复不增加贴图、网格或绘制次数。这里没有将缓冲复用等同于设备帧率优化，实际帧率仍需专门测量。

入口：外观与等级 → 效果组件库，搜索“彩虹花朵”“彩虹爪印”“披萨切片”；可先在当前卡片预览，再应用或独立制作组件。粒子面板也可选择相应图形、发射区域和运动参数。

覆盖表还缺 67 项实现：43 边框、9 粒子、15 卡面材质；accepted_1_to_1 仍为 0。60 个原创方案尚未完成制作。Wolverine/Adamantium 的角色徽记参考已观察，未用普通符号替代它。
