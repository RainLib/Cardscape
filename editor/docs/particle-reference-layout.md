# 粒子的布置与形状

2026-10-12：先核对动态参考，再实现。参考来源为 Snap.Fan 的 PixelsBlue、Hearts 和 Leaves 展示；参考文件仅用于对照，不进入导出包。它们不是完整游戏播放周期，不能用片段时长宣称动效已经 1:1。

| 家族 | 观察 | 实现目标 | 布置 |
| --- | --- | --- | --- |
| Pixels | 清晰的纯色方块，大小有区别，经过画面内部 | 硬边方形、固定朝向，局部缓慢漂动 | 前景覆盖，可编辑矩形发射区域 |
| Hearts | 彩色填充、深色细轮廓，大小不同，轻微转动 | 完整心形轮廓，保留描边，局部漂动 | 前景覆盖；初始爆发尚待独立校准 |
| Leaves | 细小深绿叶片，翻转与侧向飘动 | 尖叶、叶脉、转动与宽度变化 | 前景覆盖，可编辑发射区域 |
| Krackle | 框边近距离的大、小圆点交叠 | 有限漂移、增长与淡出 | 卡后贴框，沿切角轮廓 |

布置作为粒子组件的属性，与粒子的图形、颜色和发射区域分开。旧项目默认“卡后”；“前景覆盖”经过人物前方，并使用自己的深度产生相机视差。它不改变人物、文字或卡框的图层顺序。普通卡片与卡背均可绑定粒子；单面效果由发射面的设置控制。

所有形状继续复用一个粒子批次。新增图形不创建独立节点或大贴图，Godot 使用同一个 MultiMesh。形状、时钟、参数、布置及旋转在 WebGL 与 Godot 中一起验证。
