# Penny Arcade 彩绘喷溅边框 · 0.19.61

参考为 [Snap.Fan Penny Arcade](https://snap.fan/cosmetics/borders/Pax2025/) 的公开动态素材，实际下载并查看了 76 帧、2.28 秒、820×1100 的 WebP。大块彩绘框带、白色留白笔画、固定位置的贴边喷溅，以及底部短滴漆与通用光晕不同。参考像素只存在 QA 目录，产品使用程序材质。

## 实现与入口

在 **外观与等级 → 效果组件库** 搜索“Penny Arcade 彩绘喷溅”，应用到当前卡片；卡框面板也可选择该材质。配方为 `frame-pax-2025`，保留平直切角壳体，宽 32、切角 48、厚度 16、倒角 3。既有项目没有自动覆盖作者参数。

框面使用固定彩块与白色留白；喷溅局限于数个框边区域，黄、橙、红粉色随时间变化。外部喷溅在距框 0.085 卡宽外截止，没有向卡面中央绘制。喷溅来自框光晕表面，不额外增加粒子系统或使用新纹理。材质自身运动由播放速度控制，速度零冻结；`animation=none` 表示没有叠加通用动画，不关闭材质自身运动。

WebGL 与 Godot 共用字节一致的程序函数，正式导出复制的 SDK Shader 与仓库版本一致。

## 实际验证

- 301 项 Node 测试通过，183 个 JS 文件语法检查通过。
- 27 个实际 WebGL 帧无 GL 错误，分开检查框面、喷溅和组合。从 0 到 0.78 秒，组合可见 RGB 改变 182159 像素，Alpha 改变 120132 像素；单独框面的 Alpha 不变。RGB 按 Alpha 加权，避免把透明像素的隐藏颜色计作可见运动。三种输出在速度零时，从 0 到 100 秒均改变 0 像素。
- 正式导出的隔离工程，在 Godot 4.7.1 / OpenGL / AMD Radeon Pro 5500M 上通过 16 种边框 GPU 回归。PAX 的外喷溅检测到 1398 像素；运动、暂停稳定、速度零和卡面中央透明通过。
- 客户端共用前端实际应用、播放、定位到 0.780 秒、倾斜、翻到独立卡背、回到正面及撤销。翻面后暂停时间保持；撤销恢复本次测试前的折光边框。
- 此次同宽框材质替换前后，编译计数为 2、场景重置计数为 1、相关网格计数为 7，没有重建整场景。没有测量整体 FPS，不据此宣称整机性能已优化。
- 未保存或覆盖正式卡片，也未自动点击独立 Electron 桌面窗口。
