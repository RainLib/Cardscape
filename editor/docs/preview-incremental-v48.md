# 0.19.48：替换组件时保留预览状态

同一卡片应用、替换、解除引用或撤销组件时，按资源差异更新预览。打开另一张卡片或切换渲染模式仍走完整加载。

- 主体、背景、图片字标与 Mask 按内容和裁切参数比较；未变化的素材保留。
- 卡框、材质、粒子和卡背复用内部渲染器。组件版本号变化不会触发销毁；只改参数时不解码图片。
- 新素材全部解码后再批量提交。准备期间显示上一个完整组件；过期的异步结果不会覆盖最新选择。
- 视角、播放时间、当前动作、自动旋转检查、选中图层和画布位置保持连续。拖入和候选预览不会强制翻面或回到正面。
- 图片解码缓存最多保留 8 个源，失败条目可重试。候选预览和正式应用复用解码结果；同一静态图片不重复上传 GPU。Canvas 和 Mask 仍支持内容更新。
- 相同 Shader 不重新编译，内容相同的连续网格不重建；批量 Mask 更新只重算一次顶点权重。结构变化时只更新有关网格。
- WebGL 导出包含增量更新依赖，Godot 的资产格式未变更。

验证使用隔离工坊和真实界面操作，证据保存在 `editor/outputs/preview-incremental-v48/evidence.json` 与 `editor.png`。

| 操作 | 结果 |
| --- | --- |
| 播放中拖入卡框 | 视角 −18° 保留，动作继续；新增解码 0，Shader 与资源重置计数不变 |
| 替换粒子 | 主体纹理、网格、Shader 不变；局部更新样本 62.9 ms |
| 卡背候选预览后应用 | 180° 视角和播放保留；新增解码、重复纹理上传均为 0，内部渲染器仍为 1 个实例；样本 62.4 ms |
| 360° 检查中换卡框 | 检查从 0.283 s 继续到 0.552 s；角度从 193° 连续到 205°，检查未重启 |
| 撤销、重做 | 视角和播放连续，未重置预览 |
| 错误或过期的组件解码 | 自动化验证旧场景保留，过期结果被丢弃 |

上述耗时是本机局部更新样本，不包含所有操作阶段，也不代表跨设备帧率。所有界面验证的 WebGL 错误码为 0。全量 267 项回归通过，新增的导出依赖检查也通过；5 项专项检查覆盖资源差异、组件复用、异步竞争、失败保留和导出完整性。语法检查通过 161 个文件。

Electron 0.19.48 以隔离目录完成后台启动检查，Rust 0.6.4 正常连接。本次交互证据来自与桌面共用的编辑器页面，没有声称自动点击了独立桌面窗口。
