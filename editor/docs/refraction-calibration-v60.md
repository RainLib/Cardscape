# 幻彩折光边框校准 · 0.19.60

参考为 [Snap.Fan Rainbow Refraction](https://snap.fan/cosmetics/borders/RefractionRainbow/) 的公开动态素材：77 帧、2.31 秒、820 × 1100。逐帧检查了无遮挡的左侧框带；参考像素只存放在 QA 输出目录，没有进入产品素材或 Godot 导出。

## 变化

原来是沿周长分布的静态彩色带，未随时间变化。现在使用固定的平行亮边、凹槽和框面，青蓝底上出现流动的白色高亮与窄幅幻彩；倾斜影响反射位置。运动只改变框面颜色，不改变轮廓、透明范围或框体几何。

新应用配方的宽度由 18 调为 32 母版像素，使用深蓝底色与冷白高光。既有项目保存的宽度、颜色等作者设置不会自动覆盖。外光晕更集中在框边。边框仍为平直切角壳体；没有额外弯曲或替换人物素材。

折光材质自身包含反射动画，因此 `animation=none` 仍允许其播放；此字段表示没有叠加通用的脉冲或流光。播放速度继续由 `animationSpeed` 控制，设为零会冻结反射。WebGL 与 Godot 使用字节一致的共享 GLSL 函数。

## 局部参考与运动量测

固定参考原点 (76, 118)，使用卡宽 680 / 1024 的单一比例，在 (76, 470)–(98, 990) 的左框无遮挡区域比较 7 个时刻。没有为每一帧寻找最优相位、颜色或位置。

该区域平均 RGB 绝对误差从 **97.042 降至 62.987**（0–255 通道范围）。这是近似相机注册后的局部指标；宽度调整也会影响结果，不能解释为全卡还原百分比。参考与候选的时间相位、复杂高亮形态和任意视角仍未完全对应。

20 个真实 WebGL 帧均无 GL 错误。当前配方从 0 到 0.78 秒改变 307917 个 RGB 像素，倾斜改变 292059 个 RGB 像素；两种变化均没有改变 Alpha。速度零时从 0 到 100 秒改变 0 像素。修正前的时间变化为 0 像素。

公开短循环不证明完整游戏周期；**`accepted_1_to_1=false`**。效果目录仍为 237 项、180 个原型、57 项缺失、0 项完整 1:1 验收。

## 实际验证

- 301 项 Node 测试通过，182 个 JS 文件语法检查通过。
- 正式导出函数生成隔离 Godot 工程，完成首次资源导入后，在 Godot 4.7.1 / OpenGL / AMD Radeon Pro 5500M 上通过 15 种边框 GPU 回归，耗时约 16.1 秒，Shader 错误为 0。折光的时间变化、暂停稳定、速度零、倾斜与中心透明均通过；链环孔隙、无外光晕和霓虹字牌回归也通过。
- 客户端共用前端 0.19.60 已实际应用配方、播放、暂停、正面、倾斜、翻到独立卡背及撤销。播放时间实际推进至 12.489 秒；暂停后翻面再回来仍停在 0.780 秒。
- 配方应用与撤销的 Shader 编译次数均为 2、场景资源重置次数均为 1。宽度变化使相关网格构建计数从 7 到 11，没有重建整场景。没有量测设备帧率或宣称整体性能提升。
- 未覆盖保存正式卡片；没有自动点击独立 Electron 窗口。验证后撤销测试配方，恢复原有霓虹边框。
