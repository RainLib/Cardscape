# 节点 Shader 与发射面设计（0.19.54）

使用 MIT 的 LiteGraph.js 0.7.18 core 作为拖动、连线、选择、缩放与序列化的编辑层，不引入其音频、网络或执行代码节点。白名单类型节点生成现有几何／材质函数，沿用 GLSL 编译、Mask、作用图层、撤销、工程保存和 Godot 导出。图不在每帧执行，只有编辑时生成代码。

两种编辑方式：节点和 GLSL。节点保留原始图数据，GLSL 可查看和修改生成代码；任意手写 GLSL 不能可靠地反推节点，切回节点时使用保存的图，应用前保留当前已编译效果。两阶段分别编辑，草稿编译失败不替换当前材质。工作台默认实时编译，可关闭，操作按次撤销。

粒子绑定源、显示面与深度必须分开。卡背源的 UV、发射区域和偏移随卡背变换：卡背翻到面前时同一发射区域位于观看者前方。绑定卡背的偏移以卡背外法线为准，不能因屏幕前景选项而绕过正面卡遮挡。前／背显示过滤沿用整卡方向，源区域可分别设计。普通粒子与 Cosmic 的前层彗星仍保留原绘制批次，但都应接受实体卡深度遮挡。

验收：真实拖动与连线、类型／循环错误、实时与手动编译、GLSL 切换、撤销恢复图与代码、保存重开、正式导出；发射点在正面／90°／背面与上下倾斜下的坐标和实际遮挡，WebGL 与 Godot 一致，替换不重建预览。


## 使用入口

右侧「Shader · 节点 / GLSL」→「节点」打开工作台，分别选择材质／几何阶段。拖动节点标题移动，输出端口拖到输入端口连接；选中节点在右侧调数值、颜色或 Mask 通道，也可用目标节点／端口的下拉控件连接。滚轮／＋／− 缩放，「适合节点」看全图，「扩大工作台」展开。支持 Delete、撤销／重做。模板先作为草稿载入，点击编译才替换效果；开启实时预览后编辑操作延迟 250 ms 编译。

「查看生成 GLSL」把当前阶段的代码放入代码编辑器，手写后再编译。保存的节点图仍保留；任意手写代码不能自动反推为节点图。作用图层、限制 Mask 和强度由两种模式共享。当前节点覆盖输入、数值／颜色、四个 Mask 通道、向量分量、数学运算、发光／混色／透明度、顶点偏移／弯曲和输出，不包含任意纹理采样或完整粒子行为图。

粒子面板 → 发射源选「卡背」会默认使用「发射面外侧」和正背面显示；显示面的过滤可再单独选择。绑定源区域时区域 UV 及源图层位置随源组件变化，偏移沿源的外法线。卡背翻到观看者一侧后发射点跟着翻转。独立卡背编辑时使用卡背自身的正向编辑坐标，组合预览时才做反向映射。

节点图仅在编辑时生成函数，不运行每帧图解释器；相同函数复用当前 Shader。图位置变化只保存元数据，相同配置重复编译不新增历史。关闭工作台停止 LiteGraph 绘制循环。类型与循环错误保留最后成功效果。所有依赖本地打包，MIT 文本位于 `licenses/litegraph-MIT.txt`。
