# 2D 边框与实时材质一致性（0.19.45）

2D 编辑画布、图层全图、组件缩略图以前只画金属渐变，霓虹字牌、磨损、链环缺口及火焰外侧区域没有完整呈现。本版新增静态 GPU 栅格服务，直接使用实时 WebGL 的整段材质函数；卡框轮廓、内孔与材质索引保持原契约。

## 显示与导出

- 2D 画布按母版坐标绘制完整边框；有框外效果时使用四周 88 像素的额外区域。Neon Nights 的左右字牌、近框光晕完整显示。字牌不再染到低权重的厚度侧面，避免翻到独立卡背后露出粉色细线。
- 图层“全图”与组件缩略图按完整区域缩放。空间诊断中的立体框仍为结构示意；查看动画使用“效果预览”。
- 2D 栅格固定正面、时间 0。它不跟随动画时间轴播放，也不代表完整整卡动态效果。
- 原有 `front.png`、每层 PNG 和母版 UV 继续采用 1024 × 1536。新增 `manifest.framePreview` 提供单独的完整边框预览 PNG、母版坐标 `bounds` 和静态时刻 `time: 0`；有外侧区域时为 1200 × 1712。工坊导出按内容摘要去重。Godot 动态边框使用原有几何和 Shader；SDK 不加载静态边框预览和程序生成的边框 PNG，减少重复纹理常驻。用户导入的源图仍保留。
- GPU 不可用时回退到原有 2D 画法；只有实时预览可验证完整运动与视角反射。

## 性能

只创建一个离屏 WebGL 上下文和一个程序，参数不变时直接复用 Canvas 栅格，不启动额外播放循环，不逐帧读取 GPU 像素。缓存限制为 4 项、34 MiB；样式名称不影响缓存，几何或材质参数变化会失效。上下文丢失会清空缓存，恢复后重新编译。限制针对静态栅格缓存，不能当作整应用显存或帧率指标。

## 验证边界

真实浏览器 GPU 已验证全部 19 个边框材质：透明内孔、框外范围、Neon Nights 字牌、参数失效、重复命中和缓存上限。进一步的客户端 2D、图层、保存／重开／正式导出与 Godot 验证记录见 `outputs/editor-v19.28/verification-v45.json`。本版没有新增对照配方，也没有宣称完成全部 Snap 特效的 1:1 验收。
