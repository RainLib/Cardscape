# Snap 外观与组件制作（0.19.27）

按官方的等级、Finish、Flare 分类组织编辑器：[官方说明](https://marvelsnap.com/fntyspltlglpg/)。当前是对应类别的可编辑实现，尚未对固定参考卡的录屏逐帧校准，不声称 1:1 复制。

## 制作入口

右侧「外观与等级」设置卡片默认等级、材质预设、粒子预设、边框来源和性能档位。顶部「预览升级等级」仅临时比较，不修改图层、Mask 或共享资源。默认等级随卡片保存并在动态播放器 / Godot 导出中生效。

普通 → 不凡（破框）→ 稀有（统一相机视差）→ 史诗（人物 / 武器动态）→ 传说（字标扫光）→ 超稀有（边框流光）→ 无限（幻彩边框）。低等级关闭相关能力，原始素材保持完整，便于再次升级。边框始终是平直切角矩形，允许调宽度、厚度、倒角和颜色。

Finish 和 Flare 独立选择，不依赖当前升级等级。幻彩箔面、棱镜箔面和金底默认作用于背景；黑白默认作用于背景、人物与字标，保留边框等级色。需要整个正面都变黑白时，在材质组件作用范围选择「整张正面（含边框）」。

## 可复用外观组件

「外观与等级 → ＋独立材质组件」或「工坊 → ＋组件 → 外观材质 → 独立制作」进入同一主编辑区。

1. 选择材质样式、作用范围、强度、速度、密度与颜色。背景合成可选「保留原图并叠加」或「替换为效果底」。替换仅影响显示，原背景仍保存在卡片里，可切回。
2. 若需要图片纹理，用「导入图像 → 叠加图层」加入透明图；其位置、缩放、透明度、普通 / 发光混合、动画、深度可在主编辑区调整。背景图层的「仅作预览参考」勾选后，只在组件独立编辑中显示，不参与组合。
3. 发布版本，返回正面，从组件库组合预览或应用到当前卡 / 多张卡。固定版本独立于源卡；编辑本地覆盖不会修改已发布资源。
4. 材质图片放在背景与人物之间，不遮住人物和字标；各图片层保留有界的相对深度。需要位于人物前面的装饰，使用「卡内特效」组件或卡片普通图层。

卡背保持独立资产与外观。正面的材质不会自动更改独立卡背；要处理卡背，进入卡背主编辑区设置自身材质。背景原画属于卡片本地，不新增共享背景分类。

## 粒子与发射区域

右侧「粒子 / 发射区域」提供柔光点、星尘、星芒、克拉克大光点、霓虹条纹 / 拖尾、余烬；配色可用单色、金色或彩虹。

先选卡片、卡框、卡背或图层作为发射源，再选已有命名区域，或使用点 / 矩形 / 椭圆 / 四周边缘。点击「源发射区域」在相应组件里定位、拖框。命名区域跟随源组件更新，丢失区域时隐藏粒子并显示原因。发射显示面可独立选正面、背面或两面。

可单独制作粒子组件，发布后应用到多张卡。预设改变外形与速度等参数，保留发射绑定；修改任一参数后自动转为手动设置，避免预设覆盖编辑值。可通过客户端 AI 使用 material / cosmetics / particles / emissionRegion / publish / shared 操作，参数与手动编辑共用校验。

## 性能边界

| 档位 | 单卡粒子上限 | 分辨率倍率上限 | 预览刷新上限 |
|---|---:|---:|---:|
| 省电 | 48 | 1 | 24 fps |
| 均衡 | 128 | 1.5 | 30 fps |
| 精细 | 256 | 1.75 | 30 fps |

帧率为调度上限，不是硬件上的实测保证。每个发射器一批绘制，复用 54 KiB 顶点缓冲区；使用程序化形状或发射器共享 PNG，不为每颗粒子建立节点或纹理。暂停时保留当前效果，隐藏预览 / 后台窗口停止自动刷新。静态卡和静态共享组件停止持续重绘。游戏中的 Godot 实例通过 particle_budget 设置实际预算；多卡场景应由游戏分配总预算。尚未完成多卡同屏 GPU 压力基准。

## 素材与后续支撑

等级预览不会生成缺失素材。人物透明层、真实遮挡背后的补画、框内 / 破框 Mask、运动 / 刚性保护、武器发光 / Phase、盔甲 Foil、独立语言图片字标仍需制作。当前「素材检查」检查登记情况，不判定遮罩是否全黑或轮廓是否正确。

进一步提速需要：语义 Mask 有效性检查与批量生成、粒子预设缩略动画和批量对照、多卡总预算 / 网格 LOD / GPU 时间统计，以及按固定 Snap 参考录屏标定反射宽度、粒子节奏和破框构图。复杂折射和折光素材应使用单独 Shader / 纹理，不用堆叠大量透明图层模拟。

静态 front.png 是 2D 合成；真实角度反射、等级动态与粒子以 WebGL 播放器 / Godot SDK 为准。Godot 材质组件的图片层目前映射位置、透明度、有界深度与标准材质；独立组件时间轴、Slot 和自定义 Shader 仍需要补齐 SDK 映射。Godot 使用独立的 spatial Shader，当前测试覆盖导入、参数、素材引用与实例预算；不能据此推断每种 GPU 上与 WebGL 像素相同。

## 0.19.26 参考资料与配方库

右侧「外观与等级 → 效果组件库」提供 13 个材质配方和 10 个粒子配方。缩略图是配方示意；选中后，主画布显示实际卡片的临时组合。关闭恢复原设置，应用写入一个可撤销的编辑步骤。使用「独立制作组件」进入同一主编辑区，发布后可拖拽应用到多张卡。原画背景仍为卡片本地内容。

新增铜 / 银金属、金 / 黑棱镜、宇宙星云、磨砂玻璃、火焰、水面波纹与放射光束；扩展雪花、纸屑、钻石和气泡粒子。程序化实现便于调整颜色、速度和性能，并非原游戏 Shader 的提取或逐帧复制。

「粒子 / 发射区域 → 自定义 PNG 粒子」导入透明 PNG（最长边 512px，文件不超过 1MB），同一发射器共享一张纹理，沿用点、矩形、椭圆、切角周边或命名区域。可选择正常颜色 / 发光叠加，以及保留 PNG 原色 / 配色着色。仍复用 54 KiB 批次缓冲区与单卡预算，未增加每粒子的节点。当前不支持动画图集 / GIF 粒子序列。

客户端 AI 可调用 `particleSprite(jobId,reuse?,tint?)`，消费真实 READY 图片任务；过大图片在本地等比缩至最长边 512px。接着使用 `particles` 设置大小、混合与发射区域，发布成版本化组件。该入口已经过操作校验与产出注册测试，本轮没有另行调用付费生图。

Snap 官方本地参考位于 `editor/outputs/snap-reference-2026-10-11/`：两个动态 GIF（气泡与形状粒子）、两张官方外观展示图，以及来源、帧数、时长与 SHA-256 清单。原始媒体只用于本地观察，不进入游戏导出。官方视频保留播放链接，未下载视频文件。

观察结果：粒子在框外也保持稀疏的运动，透明气泡依赖边缘与小块高光，形状粒子使用自身色彩；背景特效位于人物后方。背景替换与原画叠加需要独立选择，灰度范围与粒子配色也应分别控制。官方参考：[动态 GIF 来源](https://marvelsnap.com/new-feature-character-mastery/)；[Character Mastery 视频](https://www.youtube.com/watch?v=w2e4TfaTu60)；[2026 年更新分类](https://marvelsnap.com/patch-notes-september-15-2026/)。

## 0.19.27 贴框轨迹与饱满圆点

根据官方 GIF 中贴近框沿的分布，新增「纯色大圆点」「圆点与星芒」，共 12 个粒子配方。大圆点保留自身颜色，小星芒使用柔光与亮芯；大小、速度、生命周期错开，部分沿框顺向、部分逆向移动，形成交叉。全尺寸四周轨迹跟随切角外形，粒子位于卡片后方，卡片和框体可遮住其内侧部分。这个运动方案来自观察后的实现选择，不是原游戏算法提取。

入口：**外观与等级 → 效果组件库 → 圆点与星芒 / 纯色大圆点**，选择后实际预览并应用。**粒子 / 发射区域 → 轨迹** 可切换「贴框环绕」「向外发射」。贴框模式的速度控制沿路径移动，寿命控制淡入与淡出；「外浮范围」限定粒子中心到源轮廓的最大距离，单位为卡片宽度比例，默认约 4%～6%。粒子自身的大小可延伸到这个中心范围外。点发射源变成围绕点的小范围浮动，矩形 / 椭圆 / 命名区域围绕自身轮廓；图层绑定继续跟随源图层变换。方向 / 角度仅在向外发射模式显示。

已有手动粒子和 PNG 组件继续保留原来的向外轨迹；点击 **贴框柔光** 可转为轻柔的贴框设置，保留 PNG、颜色和发射源绑定，支持撤销。新配方采用贴框模式。无需增加发射器，混合外形仍为同一批绘制、同一 54 KiB 缓冲区和相同单卡预算。

验证：213 项 Node 测试、144 文件语法检查通过；覆盖高速、长寿命与 24 小时采样下的中心范围、切角路径闭合、组件发布 / 重开和 AI 参数校验。Godot 4.7.1 OpenGL Compatibility 实际渲染验证新外形、固定 MultiMesh 复用、强度和高速贴框边界；headless 不具备 GPU 回读，因此该边界检查在实际渲染测试中执行。具体设备的多卡帧率仍未测量。

## 0.19.28 材质与边框细化

效果组件库现在有 21 个材质、5 个边框、12 个粒子配方。入口分别在「外观与等级 → 效果组件库」「卡框设置 → 浏览边框配方」「粒子 / 发射区域 → 浏览粒子配方」。缩略图仍为示意，点选后使用实际卡片预览；关闭恢复，应用可撤销，独立制作与版本发布复用主编辑区。

金属改为宽反射、细高光和微颗粒；棱镜使用三角分面；水面使用多尺度焦散；星云使用低频云团、细节和错位星点；磨砂玻璃使用细颗粒与柔和反射。新增云彩折光、迷幻流纹、幻彩金属、鎏金金属、鎏金棱镜、玻璃电路、瓦坎达玻璃与银河风暴。样式切换设置匹配的默认颜色，避免星云或水面误沿用金属颜色。原图叠加 / 效果底替换与作用范围可继续编辑。

边框配方为银色金属、金色金属、冰蓝霓虹、绯红霓虹与无限幻彩。保持刚性切角平面，18px 细框、16px 厚度、3px 倒角；细亮边、宽金属反射与连续沿框高光在正背面组合中使用同一算法。制作人员可继续调整几何尺寸。替换配方保留已有框饰图层与命名发射区域，预览和应用同步其独立组件文档。

克拉克光点由空心环修正为实心柔边圆，与气泡环分开；大小错开，贴近框沿，使用正常颜色混合保持金色、黑色等自身色彩。混合星芒的默认外浮缩至 3.5% 卡宽，沿框速度降低。已有手动设置不会自动重写。

WebGL 与 Godot 共用相同的材质 / 框沿函数，按相机相对卡片的角度驱动反射；材质枚举保留旧索引。仍无全屏后处理、每粒子节点或每粒子纹理。Shader 噪声计算有所增加，具体设备的多卡 GPU 帧率需要后续实测。

完整目标的跟踪文件为 [Snap 参考清单](snap-effect-reference.json) 和 [每类 20 个原创设计](effects-expansion-design.md)。参考清单是官方列出的分类快照，尚未证明覆盖所有限时边框；原创 60 项当前处于设计阶段。现有程序化配方经过渲染验证，仍没有逐项、同角度、同周期的 1:1 动效验收，不能用配方数量代替还原度。

## 0.19.30 参考原型与独立组件导出

目前效果库包含 28 个材质 / 背景配方、37 个边框配方、56 个粒子配方。这些是颜色、等级和机制的组合，不代表同等数量的独立算法，更不代表已完成 1:1。官方分类快照的 107 个条目均有原型映射，`accepted` 仍全部为 false。补充资料库还有 92 个边框条目（与官方快照重叠），其中 46 项可见静态图片；未证明这个索引覆盖当前全部游戏版本，也没有全部动效录屏。

边框共用刚性切角框体，增加宇宙闪晶、磨损、蛛网、糖果、冰晶、雪花、包装纸、火纹与哑光。沿框光的路径改为按真实切角周长计算，长边和角部采用连续位置；不让框体弯曲。新增颜色和七个升级等级可分别预览。

粒子增加科技六角符号和香蕉轮廓，配合柔光、星尘、星芒、克拉克的八种配色。黑色粒子采用正常混合，黑色星芒保持暗色亮芯。科技 / 香蕉自转独立于发射边线方向，越过切角时不会突然改变朝向。Godot 的粒子改为面向相机，与 WebGL 一致，倾斜卡片时不压成椭圆。彩虹配色同步到两端相同的光谱函数。

背景补上六种放射配色与香蕉纹样，继续支持保留原图叠加、替换效果底、卡面内容灰度及局部表面反射。素材仍保留在源工程中。

Godot 支持完整的独立卡背 / 卡框文档：各自的图层、深度、Mask、Slot、字标、数学 Shader 与材质复用卡片渲染器。卡背的样式不再错误继承正面框沿；整卡位置、缩放、旋转和透明度统一作用于组合。组合共享效果时钟和粒子预算。运行资源中的原图备份和 Base64 转为去重纹理引用，真实工坊的 `library.tres` 由约 60 MB 降至约 2.6 MiB，源工坊保持可编辑。底板和独立材质图片的复杂组件时间轴仍需进一步映射。

验证使用实际 GPU，不把“脚本打印通过”当作足够证据；遇到 Shader / Script / Engine ERROR、超时或非零退出码均失败。当前 220 项 Node 测试通过，24 种材质样式、11 种框沿机制和 13 种程序化粒子形状通过 Godot GPU 检查，独立卡背 / 卡框与 16 粒子组合预算测试通过。真实工坊从客户端导出后，正面、倾斜、卡背截图验证通过。尚未进行全效果同角度、同周期的动态参考对照，原创每类 20 个仍为设计阶段，编辑器性能和工作区全面优化尚未完成。

## 0.19.31 动态参考细化

从 Snap.Fan 的详情页下载了真实可播放的 WebP 渲染，逐帧查看了蓝色 Krackle、蓝色宇宙框、蓝色霓虹框与棱镜底。各片段约 2.31～2.34 秒，77～78 帧；文件循环不代表已确认游戏效果的完整周期。Space / Fluid 的下载图中仍显示原背景，未能确认所命名材质的视觉，不能据此进行对应效果的 1:1 验收。来源、帧数和可见性保存在参考 manifest；参考图像不会放入游戏导出资源。

- Krackle 改成 72 个交错光点，三颗一组，分级尺寸和明暗，2.4 秒的生长消退参数，小范围沿框移动；这个周期是实现参数，不是游戏周期的实测结论。正常混合保留遮叠层次，倾斜时仍面向相机。
- 霓虹增加框外柔光，宇宙框增加外侧微型星芒。使用 16 个三角面的窄外环，卡面中心没有透明覆盖；普通金属框不提交这个绘制。框体维持刚性，不随卡画弯曲。
- 棱镜细分为更小的三角面，降低随机色块饱和度，增加宽反射带；反射跟随视角，材质预设的时间变化加快。叠加 / 替换方式继续独立设置。

本轮源测试 222 项通过；后续着色调整再通过 19 项相关检查。Godot 实际 GPU 通过 24 种材质、11 种边框机制、13 种程序粒子及新增光环的编译 / 可见性检查，未出现 Shader 错误。已保存新组合并重新打开，恢复副本同步正常。全量 Snap 的动态还原仍待逐项校准，原创每类 20 项仍处于设计阶段。


## 0.19.32：区域内粒子与前景布置

动态对照补充了 PixelsBlue、Hearts、Leaves。参考证明了这些形状经过画面内部；它们不能全部用“卡后贴框圆点”代替。新增 `placement: behind | front`，默认保留旧项目卡后效果；前景覆盖使用单个批次在人物前方绘制。新增 `trajectory: float`，在可编辑区域内连续漂浮，避免无限远漂移，支持正背面限制、源图层与命名区域。`z` 现在可在 -0.5～0.5 之间调整，与布置一起导出。

像素固定朝向；心形保留暗描边并轻微转动；叶片增加尖叶、叶脉和宽度翻转。配方补齐铜、银、青、橙和粉色。它们均为待校准的参考原型：心形初始爆发、各家族完整运动周期及精确颜色尚不能宣称 1:1。雾、Fluid 和 Space 的参考文件没有明确展示对应效果，因此不据此标记完成。

验证：223 项 Node 测试通过，Godot 的 24 种材质、11 种框体机制、16 种程序粒子形状通过实际 GPU 检查。前景区域在长时间运行中保持边界，卡后旧数据保持兼容；网页切换布置和翻到卡背时，正面粒子消失且无 WebGL 错误。原创新效果仍需在核心对齐之后实现。

## 0.19.33：网点、金色底与金属边框校准

新增公开动态参考的 Tone、Gold、Metallic Gold、Gold Glimmer 观察，详见 [逐项记录](reference-refinement-v33.md)。Tone 改为沿框分布的半调网点片，固定 22 个实例，共用原有一次绘制；编辑器的图案比例修正为圆点。Gold 默认以背景明暗映射金色，保留建筑、光影和背景结构。金属框增加亮脊、暗槽和视角反射，保留刚性切角平面。

这些仍属于待校准效果。Glimmer 的揭示闪光阶段没有完成，约 2.3 秒的参考片段不能作为完整循环一致性的证据；1:1 验收仍为零。

## Glimmer 揭示阶段（0.19.34）

粒子面板 → 配方选择 Glimmer 闪片 → “揭示闪光”可设置一次性放射线 → “重播揭示”。预览下方暂停、时间条或“动效时刻秒”输入框用于检查阶段。普通动效时间与时间轴动作时间分别同步，拖动时间条不会移动人物图层。

`particles.reveal` 保存 `{enabled,duration,count,size,travel,stretch}`；关闭后只剩持续粒子。揭示数量和持续数量共同受性能档的总预算限制，两种外形仍是一个批次；WebGL 固定顶点缓冲 61,440 字节，不生成逐粒子节点。

Gold Glimmer 的公开 2.31 秒参考片段显示开场放射线退去后留下闪片。本轮参数是据此细化的原型，完整循环和全部外观的 1:1 验收尚未完成。设计依据见 `glimmer-phase-design.md`。


## 0.19.35：卡面与框缘漂浮

粒子面板 → 轨迹选择「卡面与框缘漂浮」→「外浮范围」控制区域外扩展（按卡宽计算）。0 表示不外扩；默认 Glimmer 为 0.065。每片在边界淡出、循环，寿命不会扩大范围。命名发射区域和图层变换保持生效。闪片混合小柔光点、普通片和少量较大片，独立自转；其他粒子外形保持既有行为。


## 0.19.36：星云、霓虹和棱镜

粒子配方 → **宇宙星云与流星**：紫蓝云气位于卡后，细流星掠过卡面；可修改区域、颜色、范围、方向与速度。默认 72 个实例，无 Glimmer 揭示射线。前后两次绘制共用缓冲、采样和预算；Godot 复用同一个 MultiMesh。普通粒子继续一次绘制。流星使用宽度可见的连续亮芯，避免亚像素断点。当前固定 WebGL 缓冲为 61,440 字节（60 KiB）。

效果组件库 → **冰蓝霓虹 / 绯红霓虹**：连续亮芯和窄色光晕，默认无巡游高光。边框设置仍可手动开启流光。框体保持平直切角。

效果组件库 → **彩虹棱镜**：默认保留原画叠加，三角分面与反光随视角变化。外观材质 → **背景合成**可切到全覆盖效果底；强度现在同时影响替换模式的效果，调低时趋向基础底色，不透回原图。数字输入即时预览。

设计和参考见 [Cosmic 及同轮校正](cosmic-flare-design.md)。这一轮只细化这些家族，全量外观和完整周期的 1:1 验收仍未完成。

## 紫色科技光环（0.19.37）

在「外观与等级 → 效果组件库」搜索“科技光环”，或在「粒子 → 预设」选择“紫色科技光环”。新配方将交错六角轮廓、细光线和小节点放在卡边，默认单批次 64 个实例。可调整尺寸、半径、生命周期和发射区域，仍受多卡共享预算约束。原有通用科技符号保留。参考 2.31 秒可见片段，不代表完整游戏周期已校准；见 [制作依据](wakandan-tech-design.md)。

## 0.19.38：火焰边框与组合协调

效果组件库搜索“火焰”，提供橙、蓝、金、绿、粉、紫、红、白、银白幻彩九款。框内热斑与框外火舌共用向上移动的流场；顶部较长，底部收紧，框体仍平直。银白幻彩只使用轻微彩色反光，可与等级边框的无限幻彩分别制作。卡框设置中可调整颜色、速度与流光。

彩虹棱镜增加中性色三角面和宽银白反射带，缓和原画、边框、粒子之间的杂乱感。科技光环默认外浮范围改为 7.5%、强度 0.8；手动参数继续保留。两端函数相同，仍使用原有窄外环与固定粒子批次，没有新增效果贴图。

240 项源测试与实际客户端／Godot GPU 验证通过，完整校准边界和入口见 [本轮设计及验证](fire-border-design.md)。全系列、完整周期与所有角度的 1:1 验收尚未完成。

## 0.19.39：三类效果细化与背景层恢复

效果组件库搜索「共生蛛网」可选择黑、红、紫、绿纹、白、黄六款；颜色对应底和纹路两部分，绿纹默认红底、白款使用深纹。纹路固定，拖动和播放改变缎面反射。默认替换原背景；可切回叠加，原画始终保留。替换现在只有一个背景承载面，避免远／中／近景重复纹样和透明区被最近景填满；关闭或叠加恢复原有三层。

火焰外浮进一步收窄，顶部仍比侧边和底部明显。科技光环默认 52 个实例、尺寸 0.06、范围 0.06，轮廓独立布置，细光线有斜向角度，小节点适度放大；手动工程保留已有数值，重新应用配方可取得新默认值。两端共享纹路、时钟及粒子采样，仍为一批科技粒子、同一平直切角框体，无新增效果贴图。

完整的设计、实测和未完成边界见 [三类细化记录](visual-refinement-v39.md)。全系列逐帧 1:1 对照仍未完成。
