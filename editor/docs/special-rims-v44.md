# 铜绿、幻彩磨损与霓虹字牌（0.19.44）

参考来源：Snap.Fan 的 DistressedCopperPatina、DistressedRainbow、NeonNights 详情页及其动态 WebP。三段公开渲染长度分别为 2.25、2.28、2.31 秒；仅用于研究，没有进入产品纹理。它们不能证明完整游戏循环、全部角度或像素级 1:1。CosmicPurple 的公开文件包含无关编辑器画面，Prism 色彩变体只显示原画，这些项继续保留缺失状态。

## 三个独立组件

| 组件 | 观察到的结构 | 实现 |
| --- | --- | --- |
| 铜绿磨损 | 铜色底，内外边缘不规则青绿氧化层，暗色槽 | 固定噪声控制磨损与氧化层，金属反射由视角控制。默认宽度 28，可调整。 |
| 幻彩磨损 | 蓝、青、紫、粉的局部反射，银白亮边，磨损纹理 | 与铜绿复用磨损函数，增加固定位置的彩色膜层；反射随视角变化，纹理不沿边框漂移。 |
| Neon Nights | 深蓝金属框，局部黄铜段，左右大小不同的粉色霓虹字牌 | 手写距离场生成“東京”及“2099”字形、边线和灯管，不增加字体或参考纹理；亮度轻微变化，扫描条只改变局部亮度。 |

边框材质索引 0–15 保持不变，新增 16–18。字牌复用原有平面外侧区域，不弯曲边框；铜绿和幻彩磨损不创建外侧效果。原画、图层顺序、Mask、卡背资源及绑定保持完整。Neon Nights 在没有其他动画时也能请求播放；速度 0 停止自身动画。

## 入口与边界

外观与等级 → 效果组件库，搜索“铜绿磨损”“幻彩磨损”“Neon Nights”。先预览，再应用当前卡片或独立制作组件。卡框设置可编辑颜色、宽度、倒角与动画速度。当前字牌字样由材质定义，尚无自定义字牌内容入口；0.19.45 起，2D 画布、图层全图与组件缩略图也使用共享材质绘制字牌；静态图为正面时间 0，动态变化仍通过效果预览查看。详见 shared-frame-raster-v45.md。

WebGL 与 Godot 使用逐字相同的表面函数和同一几何数据。新增字牌不增加产品纹理或后处理，复用原有外侧网格；原来没有外側区域的边框切换到 Neon Nights 会启用这个网格。稳定帧率尚需设备持续测量，不能由批次数量代替。
