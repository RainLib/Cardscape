# Halloween 绿光贴纸边框 · 0.19.64

> 时钟勘误：本轮解码漏计首帧 30 ms。实际总长 2.25 秒；旧时间配准和量测保留供追溯，准确时钟下重新捕获的结果见 [v70 校准记录](sticker-calibration-v70.md)。

根据已查看的 75 帧、2.22 秒公开短预览，增加绿色切角框与贴边的月牙、蜘蛛、蝙蝠、骨头和小菱形轮廓。使用程序 Shader，参考像素用于检查，未放入产品素材。

配方：`frame-halloween-stickers`；材质枚举新增在末尾（24），旧枚举位置保留。图形沿边移动并局部转向，可暂停或将速度设为零。外侧表面扩至 144 源像素，以容纳蜘蛛腿和月牙；缓存键包含这个范围，替换边框时更新框体几何，保留其余场景资源。
