# 月牙亮面、转向与绿色框面校准 · 0.19.68

> 时钟勘误：本轮解码漏计首帧 30 ms。实际总长 2.25 秒；旧时间配准和量测保留供追溯，准确时钟下重新捕获的结果见 [v70 校准记录](sticker-calibration-v70.md)。

继续校准 `frame-halloween-stickers`，使用同一份 75 帧、2.22 秒公开短预览、同一注册和七个时刻。没有新增样式枚举，也没有把参考像素作为产品素材。

月牙以带符号的角度逐渐转向，后续可以翻到背面；亮面随局部转向移动，保留暗部和窄边反光。仍使用程序轮廓、单次绘制和 144 源像素外围范围，无额外纹理或粒子节点。这是短预览的校准，不是任意视角的真实立体月牙。

旧比较只在参考亮区计算颜色误差，不能惩罚多出来的亮区。本轮增加同一颜色阈值下的缺失、多余像素及合并亮区 IoU。前后均使用原点 `(70,124)`、卡宽 690 px；没有逐帧对位置、颜色或姿态重新配准。

七个左侧月牙局部窗口合并后的亮区 IoU 从 **0.482209 → 0.543774**，多余亮像素从 **10,695 → 7,566**；缺失像素同时从 **1,849 → 2,059**。参考亮区 RGB 误差从 **37.409 → 42.729**，即颜色指标有回退；共同不透明区域颜色误差也从 **28.857 → 30.430** 回退。共同区域是当前两版本及参考的交集，不能直接与 v65 使用的另一交集统计比较。

绿色框面收窄黑色侧沿、保留较宽的亮绿正面，并降低大颗粒反光。新增固定框面窗口 `(70,510)-(91,570)`，七帧全窗口 RGB 误差从 **35.983 → 27.919**；它没有分离前景遮挡和参考颗粒，不能代表整个边框的材质还原度。最终结果和第二轮月牙候选均保留，不能只选改善的指标宣布通过。

这些数值只描述局部亮区，不能视作轮廓、材质或整框验收。顶部种类、寿命、轨迹、精确轮廓、金属法线与完整游戏循环仍未对齐。第一轮较暗候选的实测更差，保存在 `iteration-1-*`，未选用。

证据为 `outputs/stickers-v68/verification.json`、`region-comparison.json` 和 `reference-before-after-left.png`。313 项 Node 测试、187 个 JS 文件语法检查通过；11 帧真实 WebGL 输出均无错误，中部透明、外围未超过 144 px，速度为零时两帧像素一致。共享函数在 WebGL、Godot SDK 和实际夹具导出中逐字节一致，摘要为 `259066b1c0997b0aebfb900fc577a8462245f5401f90d0ecf7cfdf26de16276e`。

Godot 4.7.1 / OpenGL / Intel UHD 630 实际通过 19 种边框回归，贴纸外侧有 3,477 个亮色像素，播放有变化，暂停与零速稳定，无 Shader 错误。夹具为 1 卡、0 贴图、1 Shader，只验证动态边框，不是新人物素材验收。
