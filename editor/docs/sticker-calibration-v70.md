# 顶部蝙蝠轮廓与连续时钟校准 · 0.19.70

`frame-halloween-stickers` 的顶部蝙蝠改为宽翼、连续凹弧和窄身轮廓。外轮廓距离直接来自四边形，消除两个三角形拼接造成的内部斜线。顶部中央蝙蝠采用有限的上下轨迹，第三只修正翻转相位，亮面随翼面角度和纵向位置变化。改动限定于顶部；月牙、左右和底部配方不变。仍为单次程序绘制、零贴图，没有增加图层或粒子数量。

## 参考时钟勘误

发现旧解码脚本在首帧 `load()` 之前读取 WebP 的 duration，漏掉首帧 30 ms。此预览实际为 **75 帧，每帧 30 ms，总长 2.25 秒**；第 74 帧开始于 2.22 秒。七个正确比较时刻为 `0 / .36 / .72 / 1.08 / 1.44 / 1.80 / 2.22`。

v64–v69 所写的 2.22 秒总时长及其旧时间配准需要按此勘误理解。旧输出保留用于追溯，不能和新时钟量测直接混合。本轮把 v69 基线与 v70 候选都在准确时钟下重新进行真实 GPU 捕获，固定注册原点 `(70,124)`、卡宽 690 px，未逐帧修正位置或颜色。参考 SHA-256：`241d43cd30055ac34d900eee00dc1d239851632024115f34abb1768c4996b9a0`。参考图只用于离线核对，没有进入产品运行时。

## 连续帧证据

固定顶部窗口 `(375,48)-(620,108)` 的结果：

|---|---:|---:|---:|---:|

| 除轨迹拟合帧 0、12、24 的 72 帧 | .175782 | .281833 | 52.392 | 45.011 |

75 帧参考亮区加权 RGB 误差从 86.813 降至 61.185，缺失亮像素从 111,919 降至 69,164，多余亮像素从 289,321 降至 252,386。第 56–63 帧，即 1.68–1.89 秒，IoU 仍有回退；七点的 1.80 秒也回退。72 帧只是未用于中央蝙蝠轨迹拟合的内部检查，不是新的独立游戏录屏。

这些指标合并了蝙蝠、蜘蛛、骨头等亮区，也受到压缩、游戏前景遮挡影响。它们不能证明各贴纸轮廓、材质、完整边框或完整游戏循环已 1:1 对齐。顶部仍存在明显数量、尺寸、遮挡、转动和消失节奏差异。

## 运行回归

每个版本捕获 75 帧顶部区域，以及 12 帧完整画面，包含七个参考时刻、正反倾斜、零速度 0/100 秒和运行 60 秒。全部 GL 错误码为 0；新版 12 帧中心透明，外围未超出 144 源像素，零速度两个时刻像素一致。

完整帧的非顶部区域每帧有 1–8 个像素发生单通道 1/255 差异，不能宣称逐字节相同。左月牙同一窗口 IoU 两版均为 .561347，框面 RGB 误差两版均为 27.920。连续帧顶部 PNG 是完整 GPU 输出的无损裁剪，侧边、底部及透明范围由另存的完整 PNG 检查。

共享 Shader 在 WebGL、Godot SDK、实际导出夹具中逐字节一致，SHA-256 为 `2d8e3776e34e3b35de924bb359defca5790ab441aeb77566bee2efae6ecb369e`，51,696 字节。夹具为 1 卡、0 纹理、1 Shader。Godot 4.7.1 / OpenGL 实际通过 19 种边框回归：播放产生变化、暂停与零速稳定、无 Shader 错误。313 项 Node 测试和 188 个 JS 文件语法检查通过。以上没有测量运行帧率或宣称性能总目标完成。

新增 `scripts/probe-sticker-sequence.cjs`，支持上一帧、下一帧、指定帧及真实捕获；`scripts/compare-sticker-sequence.py` 校验参考时钟、逐帧数据与完整画面范围。首轮大数据导出遇到工具传输限制，截断内容保存为 `.incomplete`，未用于量测；最终有效文件为 `outputs/stickers-v70/sequence-top-gpu-frames.json` 与 `full-{before,after}-gpu-frames.json`。
