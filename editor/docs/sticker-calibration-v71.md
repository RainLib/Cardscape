# 蜘蛛弧腿、受光与前后遮挡 · 0.19.71

继续校准 `frame-halloween-stickers` 的顶部蜘蛛。参考为 [公开边框展示](https://marvelsnapzone.com/borders/BorderStickerHalloween/) 对应的既有 WebP，75 帧、2.25 秒；沿用 v70 修正后的首帧时长、七个时刻、固定注册原点 `(70,124)` 与卡宽 690 px。没有参考像素进入运行时，也没有逐帧调整位置或颜色。

## 最终变化

- 顶部蜘蛛的八条腿改为二次曲线的三段近似，腹部与头部合并，并增加头部尖角。侧边、底部蜘蛛不变。
- 横移从 `.44 + t*.08` 改为 `.525 + t*.038`，依据所查看的后段位置，降低横移速度。
- 顶部蜘蛛以同一个角度 `2.2*t - 3.96` 驱动图形投影压缩、正反朝向及上下轨迹。靠近卡框的部分更亮，背面受光减弱。
- 该角度的余弦为负时，将蜘蛛画在其他顶部饰件后面；为正时画在前面，避免黑色背面固定挡在蝙蝠前。

这是一套可继续校准的程序投影和局部合成关系。它没有新增真实蜘蛛 3D 网格，不能据此宣称贴纸的全部三维遮挡或完整游戏运动已还原。反面受光与轨迹关系是从短预览推断的模型，仍需更长的游戏录屏验证。

单次程序绘制、零贴图、饰件数量及 144 源像素外围范围保持不变。弧腿仍使用十二次线段距离计算；头部增加一次三角形距离，前后排序只改变现有合成顺序，不增加纹理、粒子节点或绘制提交。没有用这些结构性变化来宣称已测得帧率改善。

| 全部 75 帧亮区 IoU | .289259 | .300373 |
| 全部 75 帧平均 RGB 误差 | 44.516 | 43.130 |
| 参考亮区加权 RGB 误差 | 61.185 | 58.313 |
| 缺失亮像素 | 69,164 | 67,991 |
| 多余亮像素 | 252,386 | 239,551 |
| 七个检查帧亮区 IoU | .300294 | .315860 |

第 `3、4、5、6、12、19、22、27、65、66、67` 帧 IoU 仍回退，不能以平均改善宣布逐帧通过。第 56–63 帧本轮均改善，但其他回退仍需继续处理。

视觉检查用到每六帧的画面与最后一帧，记录于 `calibration-frames.json`。其余 61 帧的 IoU 为 `.291078 → .302003`，RGB 误差为 `44.442 → 43.072`。这些帧的数值结果也参与了迭代判断，所以不能称为盲测或独立留出集；工具将它们命名为 `visualReviewComplement`。它们均来自同一短预览。

亮区指标混合多个物种，受到压缩、参考卡画、费用/战力图标遮挡影响；没有隔离为蜘蛛轮廓验收。整体贴纸排列、其他物种的轨迹和反光、完整出现/消失循环仍未对齐。

## 候选与回归

1. 弧腿与离框照明：IoU .289515，参考亮区 RGB 误差 58.524。
2. 加入较慢横移：IoU .294515，参考亮区 RGB 误差 57.215。
3. 统一转角、轨迹与正面受光：IoU .271039。黑色反面仍固定遮挡蝙蝠，撤回该合成结果。
4. 在候选 3 基础上按前后关系合成：IoU .300373，保留为最终版本。参考亮区 RGB 误差高于候选 2；全窗口误差、多余亮像素、整体重合度与实际遮挡有所改善，不能声称各指标全优。

前三个候选的代码、捕获帧与量测均保存在 `outputs/stickers-v71/iteration-{1,2,3}-*`。最终代码为 `selected-shared.glsl`，数值证据为 `verification.json`。
