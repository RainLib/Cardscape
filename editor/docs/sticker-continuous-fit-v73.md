# 连续轨迹参数量测 · 0.19.73

本轮继续校准 `frame-halloween-stickers` 的顶部中央蝙蝠。沿用已核对外形的公开 WebP，75 帧、每帧 30 ms、总长 2.25 秒，配准原点 `(70,124)`、卡宽 690 px、固定窗口 `(375,48)-(620,108)`。这是局部原型校准，完整 1:1 仍未验收。

## 变化与依据

增加 QA 工具 `scripts/probe-sticker-fit.cjs`，对 14 个已声明观察帧，以真实 WebGL 绘制量测六个有边界的参数：轨道中心、半径、速度、相位、自转速度和尖角扫光。三轮坐标搜索共检查 90 个候选，完整记录保存在 `outputs/stickers-v73/continuous-fit.json`。

搜索用 `.7*(1-IoU)+.3*RGBError/255` 比较候选；最终从已量测候选中选择相对基线同时满足轮廓重合度不下降、两项 RGB 误差不增加的候选。最终选择与单一综合分数的最优候选均保留，不隐去取舍。直接 ROI 绘制与原分辨率缩放有采样差异，选择后必须再用原始分辨率捕获全部 75 帧。

最终中央蝙蝠仍由同一套连续函数驱动：

```glsl
center = .023 + .140 * cos(localTime * .855 + .893);
spin = localTime * 2.6125 + cell;
sweep = .15 * pow(max(0., -cos(spin)), 6.);
```

扫光只作用于中央蝙蝠，使其接近卡框时中央尖角稍亮。侧边、底部与顶部两端蝙蝠保留原有轨迹和照明。没有逐帧写入位置、没有参考像素进入运行时，也没有新增贴图、绘制提交或饰件数量。没有据此宣称测得了帧率提升。

仅移动轨迹的手工候选使全帧 IoU 降到 `.250521`；较大扫光的另一候选为 `.279301`，均撤回。搜索综合分数最优候选的全帧 IoU 达 `.306328`，但两项颜色误差回退，也未保留。失败候选保存在本轮输出目录。
