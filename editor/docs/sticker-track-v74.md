# 右上蝙蝠连续轨迹 · 0.19.74

继续校准 `frame-halloween-stickers`。公开参考为同一段 75 帧、每帧 30 ms、总长 2.25 秒的 WebP。右上固定窗口 `(540,5)-(695,115)`，原点 `(70,124)`、卡宽 690 px。它是局部原型校准，尚未完整 1:1 验收。

## 变化

旧版右上蝙蝠基本停在同一框外位置；参考在短片中有移出、再出现和上下位置变化。本轮以真实 WebGL 量测九个有边界的连续参数，14 个声明观察帧、137 个候选。搜索记录、选择与未采用的综合分数最优候选均保存在 `outputs/stickers-v74/right-top-bat-fit.json`。

```glsl
float orbit = localTime * 4.4 + .9;
center = .035 + .05 * cos(orbit);
spin = localTime * 2. + cell;
along = mod(.7725 + .0175 * sin(orbit) - .0075 * localTime + .30, 1.60) - .30;
sweep = .20 * pow(max(0., -cos(spin)), 6.);
```

横向回绕发生在卡外，以免长期单向漂移后永远不再出现。最初未回绕的量测保存在 `*-unwrapped.html/json`；随后用带相同回绕的实际 Shader 重跑 137 个候选，选定参数一致，再复验最终源代码全部 75 帧。这是从短片推定的有界轨迹，不代表测得游戏真实三维路径或完整循环。

直接 ROI 绘制的 IoU 为 `.209170 → .395365`。最终判断使用原始分辨率捕获后按同一比例配准的全部帧，不能以小窗口搜索值替代完整捕获值。
