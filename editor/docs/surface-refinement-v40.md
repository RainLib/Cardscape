## 表现与合成

- 电路：固定的水平、垂直和 45 度转折走线，端点有细环。光照变化而走线不移动。默认叠加原画，可调整为只作用于背景，或替换背景。
- 瓦坎达玻璃：固定的斜向刻线与紫蓝反射，替换之前的同心轮廓。默认叠加卡面内容，保留角色细节与原始图层。
- 磨砂：固定的细颗粒与不均匀扩散。保留原图的模式使用原始采样加四个轴向采样，按 Alpha 加权 RGB，不扩大透明轮廓，采样限制在源图裁切范围。替换模式显示独立磨砂色场。
- 放射：黑底上的固定旋涡状宽窄色带，视角和时间只改变反射。紫、粉、黑白、红、蓝、绿、橙、幻彩可独立应用，幻彩降低饱和度并增加银白反光。
- 蛛网边框：平直切角框，细分支绕框缘连接。黑、红、粉三款独立配方，保持空心中心，不添加框外浮光。

旧材质编号 0～24 保持不变，新编号为 25 `circuits`、26 `frosted`、27 `raysrainbow`。框体 `web` 继续使用编号 5。配方应用、组件发布、保存、重开和导出均保留原素材、独立卡背和已有粒子发射绑定。

## 验证边界

通过真实 WebGL 与正式客户端导出的 Godot GPU 验证时间／视角、暂停／零速、两种合成模式、固定图案和源像素扩散。Godot 首次实际编译发现整型样式与浮点阈值比较问题，修复源 SDK 后重新导出和验证，旧失败导出不作为成功证据。
