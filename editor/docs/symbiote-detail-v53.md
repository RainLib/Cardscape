# 共生蛛网局部轮廓校准（0.19.53）

## 修改前设计

依据已确认可见的 `SymbioteWebBlack-motion.webp`（77 帧、2310 ms），参考第 26 帧检查无遮挡区域。原实现保留了三组连接节点，但主体为直线，节点位置和粗细与参考仍有明显差异。

本轮目标为弧形拉丝、连接处扩宽、分支所在区域与银灰底的明暗关系。使用卡框内窗约 (104,100) 至 (736,980) 做局部归一化；此配准只用于正面可见段，不能代替完整相机标定。人物、标题及数值遮挡的部分不能从这一帧恢复为可靠原资产。

- 四组主节点和长线按照可见参考重新布置，弧度固定在材质空间。
- 丝线在节点附近变宽，弧形中段保持较细，末端略有连接扩宽。
- 时间和视角只改变银灰反射；没有证据支持让蛛网纹路持续漂移。
- 六款颜色共用轮廓。独立组件、背景替换和原图叠加保持现有契约。
- 优先使用固定数量解析弧线，限制每条弧线的最近点迭代，避免无界追踪。新增贴图或增加绘制批次必须有明确必要性。

## 验收边界

用实际 GPU 绘制修改前后相同配方，比较选定无遮挡区域的白丝宽度和位置；检查暂停、速度零、时间、相机、配方切换与正式导出。参考配准和检测只支持局部改进，完整游戏循环、全部相机角度和整体 1:1 仍未验收。

## 实现与量测

将直线与纹路扰动改为 21 条固定弧线，每条只做一次最近点修正。起点扩宽、末端轻微扩宽，银灰反射由时间和视角驱动。没有增加纹理、网格或绘制批次；解析弧线的 GPU 运算量需单独评估，不能由资源数不变推断 GPU 更快。

参考第 26 帧的两个无遮挡连接区，与实际 WebGL 输出在约定内窗中配准。白丝检测对参考与生产采用不同亮度阈值，允许 4 像素误差；以下结果只衡量这些区域的轮廓，不代表整张卡的还原比例。

| 区域 | 原版局部 F1 | 新版局部 F1 | 新版双向平均轮廓距离 |
|---|---:|---:|---:|
| 左连接 (113,545)–(160,620) | 0 | 0.754 | 2.44 px |
| 右连接 (665,392)–(736,510) | 0 | 0.816 | 2.30 px |

银灰高光区域的平均 RGB 绝对误差从 124.06 降至 9.80。左上暗区误差从 12.70 增至 15.40，右下暗区从 30.85 降至 25.47：暗部颜色仍需继续校准。六帧真实 WebGL 绘制均无 GL 错误，时间和查看角度改变反射，纹路保持固定。

## 客户端与正式导出验证

在隔离验证工坊中从金色叠加材质切换到黑色共生蛛网，再应用和保存。查看停在 1.40 秒、俯仰 10.99°；资源计数保持网格 7、纹理 18、编译 2、重置 1。替换模式只由原远景背景绘制效果底，其余原图数据保留，人物、文字和粒子设置未重建。翻转到独立紫金秘典卡背时保持 1.40 秒，GL 错误为 0。

从界面“导出整套 + Godot SDK”生成 `runtime/cosmetics-v25-qa/exports/workshop-1791782144779-a3d0f9be/godot`，三份核心渲染文件与源文件字节一致。Godot 4.7.1 / AMD Radeon Pro 5500M 实际 GPU 通过六色蛛网的时间、暂停、速度零、角度、替换覆盖原图、叠加保留原图检查；另通过 12 个既有材质配方回归。没有 Shader / Script 错误。

全量 Node 测试 280 项通过，语法检查 167 文件通过。证据保存于 `../outputs/surface-v53/verification.json`、`region-comparison.json`、`client-resource-evidence.json`，并有客户端正背面、参考对照和 Godot 六色截图。桌面原生窗口未被自动操作，客户端证据来自共用前端的浏览器运行。

完整游戏相机、循环时序、遮挡后的纹路和暗部色彩仍未验收，`accepted_1_to_1` 保持 false。
