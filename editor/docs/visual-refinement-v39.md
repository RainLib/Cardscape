# 粒子、边框与背景的第二轮细化

2026-10-12。以已有 FireBlue、Purple Wakandan Tech、Prism 动态文件和六种 Symbiote Web 详情页的实际媒体为依据。参考文件仅用于观察，不随工程或 SDK 导出。短片无法证明完整游戏周期和全部角度一致，继续保留未验收状态。

## 可见问题与处理

- 火焰：整卡显示中火舌外浮过宽，侧边形成较粗的亮团。缩短外浮，增加从窄亮根部到尖端的透明度衰减；沿用向上流场、平直切角框体与既有窄外环。
- 科技光环：三颗一组的轮廓叠得过密，细光线全部竖直，小实体节点太小。改为独立位置，减少默认数量和尺寸，光线增加有限的斜向角度，适度放大小节点。所有图形继续面向相机、单次批量绘制，位置和范围仍由源组件的发射区域控制。已有工程保留手动数值。
- 共生蛛网背景：参考中的大块不规则连接纹路、局部宽接头和缎面反射需要单独表达。新增 `symbiote` 材质，固定拓扑，不以网格滚动代替反射。使用固定 28 段连接纹路与渐变接头宽度；视角和时间只改变银白／有色反光，不改变纹路或人物几何。

替换合成另有一处修复：原先远、中、近景均执行替换并填满 Alpha，纹样重复且最近景盖住其余层。现在替换只选择可见的原始背景层（或远景，再退回首个背景面）作为承载，保留底板和材质图片叠加；切回叠加／关闭效果时恢复原背景层。该选择仅用于渲染，不改写源图或图层可见性。

## 六种配色

黑：深灰底／银白纹路；红：暗红底／银白纹路；紫：灰紫底／银白纹路；绿：暗红底／绿色纹路；白：白灰底／深灰纹路；黄：金黄底／暗红纹路。各项均独立配方，不能简单把背景底色统一换成该名称的颜色。

配方默认替换背景，保留原背景素材；可改为叠加原画。作用范围、强度、速度、密度与两种颜色继续可编辑。卡背的材质和正面独立，组合预览不隐式继承。旧材质索引 0～23 不变，新材质追加到 24。

## 验证

需检查实际 WebGL／Godot GPU 编译、六款可见色彩差异、视角／时间反射、暂停与速度零、替换不透原图、叠加保留原图，以及保存／重开／正式客户端导出。科技粒子的采样位置、尺寸、透明度和角度需跨渲染器比对；火焰需继续验证顶部大于底部、窄外浮和中心透明。

性能保持原来的批次、顶点缓存和纹理数量；新背景仅在选中该材质时执行固定 28 段距离计算，无循环增长、额外贴图或后处理。实际帧率仍需硬件测量，不能用算法边界代替性能实测。
