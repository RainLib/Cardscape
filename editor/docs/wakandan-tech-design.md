## 可见特征与制作方案

参考包含沿卡边密集交错的细六角轮廓、较少的实心小节点、竖向细光线和紫色边缘辉光。原有 `tech` 是带中轴线的单六角图形，数量少、轮廓偏小，不能表达这个家族。新增独立 `wakanda` 外观，保留通用科技符号及历史索引。

同一确定性粒子池内按 seed 分为轮廓、光线和节点三类。轮廓沿相同边缘成组排列，保持竖直，仅做短距离上移和淡入淡出；光线用窄而长的 billboard，节点保持小尺寸。形状、白紫亮线和局部辉光在同一次绘制中完成。默认 64 个实例，向外扩展的范围限制在卡边附近，人物和字标保持优先。

新外观索引追加在 Cosmic 之后，已有 sprite=9、shard=18、cosmic=19 不变。WebGL 与 Godot 使用同一图形函数和采样参数。沿用 7 值采样、10 值顶点、61,440 字节固定缓冲；不新增纹理或每粒子节点。命名区域、组件实例、前背面和多卡预算继续生效。

## 验证与边界

验证三种形态的尺寸／角度、移动连续性、局部区域及预算、保存恢复、实际导出渲染和同源采样。2.31 秒参考不覆盖完整待机／揭示周期，当前仍不标记 1:1 验收。

`Wakanda`、`WakandaGold` 与 `Flannel` 的公开渲染只显示基础卡面，不能作为对应家族的视觉证据。DiamondGold / Purple / Silver 媒体返回 403；记录可用性，保留未校准状态。
