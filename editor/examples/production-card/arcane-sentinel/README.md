# 星炉哨卫 · 制作与粒子验收样卡

在 Cardscape 首页打开同目录的 `星炉哨卫.cardworkshop`。角色由九个独立部件组成，配有九骨骼、双节 IK、披风 FFD、双窗异形铜框、可编辑标题和数值、独立背景与卡背。

动作包括：守望呼吸、横斩抬腿、双节 IK 施法、唤醒进场、翻面、休眠退场，以及星痕巡游世界空间、星屑坠落平面碰撞，共八个动作。施法同时播放跟随掌心的聚能与保留出生姿态的爆发；剑锋粒子出生后留在卡牌空间，另有连续连接的剑锋带；掌心聚能可提前停止发射并自然消散，进退场保留独立散光。可在动画时间轴的「动作粒子事件」中编辑、导入 PNG、选择预设和重播。「星痕巡游」让整卡移动、转动、缩放和淡出，世界粒子与三维剑痕保持出生位置；「星屑坠落」使用重力、地面与两侧墙反弹，在事件物理面板可切换滑动／命中消失并编辑平面；不包含球体／动态场景碰撞、完整状态机或多动作叠加。音效时间轴可编辑裁剪、音量、变速和循环；先点击「启用音效试听」，或在导出播放器点击「启用音效」。世界空间的历史记录及游戏接入边界见 [动作粒子](../../../docs/action-particles.md)。

`parts-atlas.png` 是保留透明通道的九部件源图，`background.png` 与 `back.png` 为独立原画。三张源图使用内置图像生成工具生成，准确提示词与生成记录在 `generation.json`。装配仅裁出各部件的源区域，再通过统一缩放、旋转、平移注册到画幅，没有补画关节或复制人物到隐藏层。

从 `editor` 目录运行：

```powershell
npm run test:production-card
$env:GODOT_BIN='C:\Users\housh\Godot_v4.7.1-stable_win64.exe'
npm run test:production-godot
```

第一条命令重新装配样卡，校验全部动作，实际操作制作控件、保存、重开和导出，再运行独立播放器；同时更新本目录工坊。验收的封面、逐动作九视角帧、隐藏部件帧、部件注册表、原图 SHA-256 与数值参考保存在独立 QA 目录。第二条使用真实 Godot GPU 检查同一个导出包。目录索引：`editor/qa/production-readiness/arcane-sentinel/last-run.json`。

桌面功能验证不能替代移动设备多卡性能验收；轮廓画布与曲线已有桌面验证，复杂布尔与异形边饰已有桌面验证；完整剩余项按 `editor/docs/production-readiness.md` 跟进。

原创风切、聚能、冲击音效在 `audio/`，与横斩、施法、世界空间和碰撞动作同步。声音由 `scripts/production-audio-fixture.mts` 确定性合成，没有使用外部录音；`audio/generation.json` 保留 PCM16 WAV 的参数与字节摘要。实际制作器／独立播放器检查声音信号，Godot 成品验收检查实际混音、暂停静音、96 个事件采样点、预算和释放。完整字段及回放边界见 [动作音效](../../../docs/action-audio.md)。
