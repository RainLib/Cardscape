# 雷曜誓约 · Stormglass Oath

在 Cardscape 首页选择「示例工程 → 雷曜誓约」，即可打开可编辑副本并播放循环。也可以手动打开 [工坊文件](stormglass-oath.cardworkshop)。把时间轴停在 `0 s`（正面）、`1 s`（左倾）、`2.04 s`（雷斩）、`3.04 s`（右倾）检查细节。[完整动效清单](../../../../README.md#demo-animation-effects)

人物分为后层裙摆、卡窗内的身体与持剑手臂，以及可越过鸢尾框的虹晶刃。裙摆的固定边跟随腰甲与腿部，长摆向后退入景深。屈膝、肩膀、前臂和手腕留在卡窗内，护手与刃片沿同一轴线并随同一骨骼移动。远景天文台、中景云台、近景晶片和花瓣以及雷斩各有自己的图层。

在「网格结构与轮廓 → 深度图浮雕」使用 `0.25` 幅度重新导入 1024 × 1536 的灰度图。[身体与刃片深度图](knight-depth.png) · [后层裙摆深度图](skirt-depth.png)

在「展示与录制」选择「所选动作」、`9:16` 和 `24 fps`，录制一轮 4 秒共 96 帧的 GIF 或 MP4。示例在输出边缘保留了倾斜和刀锋破框的空间。GIF 使用共享调色板和 Floyd–Steinberg 抖动。

动效节奏参考第 3 段视频。人物、云海、鸢尾花边和景深附加素材使用 ImageGen 生成的原创素材，刀刃、符印和斩光使用程序绘制。[素材说明](generation.md) · [动效参考](https://x.com/DeepBlueX0/status/2124148150525128836/video/3)
