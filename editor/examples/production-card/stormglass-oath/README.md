# 雷曜誓约 · Stormglass Oath

在 Cardscape 首页选择「示例工程 → 雷曜誓约」，即可打开可编辑副本并播放循环。也可以手动打开 [工坊文件](stormglass-oath.cardworkshop)。把时间轴停在 `0 s`（正面）、`1 s`（左倾）、`2.03 s`（雷斩）、`3 s`（右倾）检查细节。背景、人物、虹晶刃、鸢尾框、符印、冲击波和两层闪粉各有自己的图层。

人物和刀锋采用同一注册画布上的独立网格。手甲附近的浮雕 Z 接到刀柄，刀尖的 Z 沿刃身递增。可分别选中人物与刀锋，打开「网格结构与轮廓」下的「深度图浮雕」，用 [人物灰度图](knight-depth.png)（幅度 `0.13`）和 [刀锋灰度图](blade-depth.png)（幅度 `0.148`）重新导入。灰度图与 1024 × 1536 的素材位置对齐。

在「展示与录制」选择「所选动作」、`9:16` 和 `24 fps`，录制一轮 4 秒共 96 帧的 GIF 或 MP4。示例在输出边缘保留了倾斜和刀锋破框的空间。GIF 使用共享调色板和 Floyd–Steinberg 抖动。

动效节奏参考第 3 段视频。人物、云海、鸢尾花边使用内置 ImageGen 生成的原创素材，刀刃、符印和斩光使用程序绘制。生成提示见 [素材说明](generation.md)。[动效参考](https://x.com/DeepBlueX0/status/2124148150525128836/video/3)
