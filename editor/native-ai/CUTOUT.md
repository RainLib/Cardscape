# 本地抠图处理

入口：图层选中 → 一键抠图 → 三栏候选预览 → 新图层 / 人物 Coverage / 主体选区。

模型来自 [rembg 官方发布](https://github.com/danielgatis/rembg)，对应算法 [U2Net](https://github.com/xuebinqin/U-2-Net)、[ISNet / DIS](https://github.com/xuebinqin/DIS)。下载 URL 与 MD5 校验来自其公开会话实现。项目固定 ONNX Runtime / NumPy / Pillow 版本，在独立虚拟环境中使用公开模型的 RGB 归一化与输出归一化方式。

模型只有本地 CPU 执行路径；处理函数无网络调用。安装步骤下载模型。最多保留一个模型会话，4 个推理线程、1 个调度线程；切换档位释放前一个模型。U2NetP / U2Net 输入 320 × 320，ISNet 输入 1024 × 1024，输出恢复到源尺寸。Rust 将源 Alpha 与预测 Mask 相乘一次，已有透明像素保持透明。

编辑器对当前图层在卡牌画布中的注册区域（1024 × 1536）生成候选。原始扩图文件与原图图层保留；这不是对任意尺寸原始照片的无损重排。新结果保留位置、缩放、Slot 与调整设置，灰度 Mask 内嵌到该新图层，素材导出时写为独立 PNG。人物 Coverage 模式保持原图层身份与其他动作 Mask。所有应用都检查工程 ID、修订号和选中图层，关闭 / 取消预览不修改原图。

自动主体分割具有质量边界：快速与标准模型可能漏掉大幅披风；细节模型更适合本轮卡图，但复杂边缘仍需检查。智能选区、选区羽化 / 扩张 / 收缩和人物 Coverage 画笔用于精修；没有宣称自动结果达到逐像素人工验收。
