# 人物遮挡、肢体与纵深

人物景深是所有新卡和现有卡细化的制作约束。不能用整个人物一张平面，再让背景移动，来宣称人物已立体化。这里制作的是有遮挡和补绘的 2.5D 表面；没有真实侧面资产时不能宣称支持任意角度的完整 3D 人物。

## 先做部件计划

检查完整母版和实际合成图，列出每个可见部件的名称、所属人物左右、前后关系、遮挡对象、连接位置、刚性/柔性、待补绘区域和允许查看角度。例如：

| 部件 | 前后关系 | 处理 |
|---|---|---|
| 后手臂 / 后腿 | 躯干或衣物后方 | rear，补齐被躯干遮住的上臂、腿甲与关节 |
| 同一手臂的远侧上臂 / 近侧前臂 | 肘部跨越主体、存在明显前伸 | 按实际遮挡分为独立刚性表面，补齐肘部连接；同深度时仍保持连续 |
| 后翅膀 | 身体后方 | rear，补齐翼根和被前翼挡住的部分 |
| 躯干 / 头 | 人物主体 | body，补齐被抽走前臂、前衣角遮住的胸甲或内衣 |
| 前手臂 + 护腕 + 手 + 所握武器 | 躯干前方的握持组 | front，刚性整体；只有真实遮挡确实需要时再分武器，并验证握点 |
| 前腿 / 前翅膀 | 主体前方 | front，补齐上部连接，轮廓不拉伸 |
| 后披风 / 前裙摆 | 随画面遮挡关系 | rear/front，柔性根部固定、末端渐强 |

前/后指实际观察深度，不等于左/右或画面上下。左右指人物自身解剖方向。一个部件全部同深度、没有遮挡时无需机械拆分；存在清楚的前后手臂、腿、翅膀则必须分别处理。身体多个角色分别规划，不把所有部件揉成一个人物层，也不复制全人物当后层。

计划写入本阶段的制作说明，至少注明“母版 → 后翼/后肢体 → 躯干 → 前肢体/握持组 → 前衣料”的实际遮挡关系、每层隐藏补绘对象及接缝位置；顺序按画面调整。例如握持组经过胸前时，后层需胸甲；前腿跨在后腿前时，后腿需补腿甲与膝关节；前翼遮住后翼时，后翼需补翼根和被遮的翼面。先证明一个部件为何独立，再生成它，不按名称盲目切碎。关节或布料同一连接点周围允许保留真实隐藏重叠，但正面可见像素归属唯一。

以人物自身左右标注部件，再单独标注近/远和遮挡对象。例如左前臂可以是近景，右手臂可以处于后景；不能把“左”固定等同于“前”。近腿、远腿、前翼、后翼分别保留连接点。身体重叠不代表部件应黏在同一个 Z，部件分开也不代表应拉开很大距离；先恢复正面原画，再验证倾斜时的局部相对位移。

每个角色分别使用这份部件记录，作为实际生图和拆层的依据：`部件名称 / 人物左右 / 观察近远 / 遮挡谁或被谁遮挡 / 所属母版 / 刚性握持组 / 连接点 / 隐藏补绘对象 / 深度与允许角度`。没有可见后腿或后翼的构图注明“本构图不可见”，不要为凑层数生成额外肢体。头、躯干等同属一个深度的部分可以保留在主体；一个前臂向镜头伸出、另一条手臂在躯干之后时，必须在计划里分别处理。

部件计划必须在母版生成提示词和拆层任务中保持一致。可用下表记录实际角色，不把它当作固定层数模板：

| 部件或组合 | 人物左右 / 近远 | 遮挡关系 | 连接与隐藏补绘 | 运行方式 |
|---|---|---|---|---|
| 近侧前臂、手、护腕、长柄武器 | 按当前姿势填写 | 在胸甲前方 | 肩/肘连接留支撑；胸甲补被抽走的区域 | 同一刚性握持表面或受约束的刚性组 |
| 远侧手臂 | 按当前姿势填写 | 在躯干之后 | 补肩根、上臂、肘部 | 独立后景刚性表面 |
| 近腿 / 远腿 | 分别填写 | 记录腿甲、裙摆、另一条腿的遮挡 | 分别补髋根和隐藏腿甲，裙摆后补内裙/腿 | 独立前/后刚性表面 |
| 近翼 / 远翼 | 分别填写 | 记录翼面与身体的交叠 | 补翼根和被挡翼面，不能镜像前翼 | 翼骨刚性；需要柔动的羽梢另拆 |
| 前衣料 / 后披风 | 按实际遮挡填写 | 可以一部分框内、一部分框外 | 肩/腰根固定，后层补足最大摆幅支撑 | 柔性根部权重，内外共用几何 |

透明补洞和前后拆层是两个不同阶段：先抽取实际可见区域，再真实补绘后层。各层沿用同一母版、画布与光向；只设置灰度深度图或整体人物位移不能替代前后肢体的独立表面。手臂分成上臂与前臂时，接缝藏在真实关节或护甲遮挡处，保留完整手指、握点和武器比例。

母版生图时先使近远关系可读：前侧肢体具有合理缩短透视，远侧关节和翼根有稳定遮挡；完整披风、裙摆和肢体留出拆层及隐藏连接余量。拆层后的倾斜不能产生原画中不存在的新视角解剖；需要看到明显侧面或体积转向时，缩小允许角度，或制作真实侧面/3D 资产，不能继续加大平面 Z。

## 生成顺序与隐藏补绘

1. 首先真实生成解剖、脸部、服装、握持关系连续的完整人物母版。保留母版，不能先分别生成随机姿势的手臂和腿再拼接。提示词要求前后肢体与遮挡关系清楚，四边有余量，底部有连续衣物/腿部收口。
2. 本地抠图并逐项检查 Alpha：发丝、羽毛、翼缘、细武器、手指、裙摆不能误删。人物与所有颜色/Mask 采用当前工程的同一源画布与注册坐标（默认 1024×1536）；不要裁边后各自缩放再拼，也不要将不同工程尺寸强制缩成默认尺寸。
3. 根据部件计划，在实际源图用智能选区或轮廓选择，splitLayer 从当前 foreground 抽取互补可见 Alpha。羽化只处理边缘；每个像素有明确归属，不重复叠加肩甲、护腕或衣料。
4. **抽出可见像素不等于完成后层。** 后手臂需要完整关节连接；被前臂遮住的胸甲需要真正补绘；前翅膀背后需要后翅膀；前裙摆后需要内裙/腿部；背景需要恢复被人物/建筑挡住的内容。只加深度会暴露原画缺口。
5. imageTask(edit/inpaint) 必须沿用当前部件/人物母版作参考，要求补全指定隐藏解剖或衣物，保留身份、服饰、镜头、比例、光向和注册位置。候选 READY 后 repairLayer 仅补当前透明缺口，禁止 asset 覆盖人物和已拆子层。补绘需保留真实生成任务回执；不能镜像、拉伸、复制前景充当隐藏后层。
6. 在肩甲、腰带、胸甲、翼根等稳定遮挡处保留必要重叠。后层不是全人物不透明副本，不能把后披风整个覆盖掉。repairRegion 可收窄实际补绘支撑；原画和完整候选必须可恢复。
7. 新生成的独立部件同样需要保留“可见区 + 隐藏连接区”，而非紧贴可见轮廓裁切。若当前契约不能表达所需导入/关联，先报告具体缺少的能力，不捏造未支持指令。

母版构图要让近侧前臂、远侧手臂、近/远腿或翼面具有可辨认的遮挡关系与缩短透视。拆出的素材沿用母版的同一镜头；不要单独生成一个新的侧视手臂，也不要预先把倾斜相机的变化烘焙进部件。材质高光、阴影与表面绘画起伏仍来自一致的原画；实际查看视差由注册后的 Z 和统一相机产生。

图片子任务也会实际携带本 Skill。读取 `characterContext` 中当前部件、角色、统一相机及各表面相对深度；`spatialEnabled=false` 时深度尚未定义，由主制作助手先建立空间层级，不按旧素材默认值推断真实距离；`input.png` 为待编辑的工作图，`character-master.png` 为拆层前完整身份/姿势参考。已有后层补绘不会改变母版参考的角色身份。根据 operation 和用户要求生成完整母版或修补当前后层；不要从完整参考重新抠一个整个人物覆盖当前部件。子任务只产出 PNG/清单，提问与下一阶段拆层由主制作助手负责。

新任务中表面的 `visible` 指是否参与当前合成；隐藏前层只能帮助检查，不能算作已补绘。`paintOrder` 从后向前递增，表示图层绘制先后；`z` 为连接限幅并加上 `slotZ` 后相对卡框的实际自由端深度，柔性根部仍由 attachment 固定。同一个部件的框内/破框通道共用几何，不能把两次绘制当成两个解剖部件。旧任务缺少这些字段时读取当前契约，不猜原来的排序或 Slot。

补绘提示词例（须替换为实际部件与选区）：

> 以当前完整人物为唯一身份与构图参考，重建被前侧握持组遮挡的胸甲和内衣、肩部连接与后上臂。保持原有可见脸、手、武器和衣物的像素与位置，只补选区内隐藏内容。保持源画布和透明外轮廓，不复制前侧护腕、手或武器；新增连接余量覆盖允许相机倾斜时可能露出的区域。

## 客户端约束与指令

以最新 contract.editorCommands 为准。本版本支持：

- splitLayer(layerId,newLayerId,name,role,polygon 或 selectionMask,feather?,z?,part?,side?)。role 为 rear/front；part 为 arm/forearm/hand/leg/wing/head/torso/weapon/accessory/cape/skirt/hair；side 为 left/right/center。
- characterPart(layerId,part,side?) 为已有的人物表面设置分类。刚性部件自动 attachment.mode=rigid、motion=0；披风/裙摆/发梢使用 cloth。
- attachment 设置深度差上限与连接参数。刚性层不使用逐顶点根部渐变，整层恒定 Z，关节靠真实隐藏重叠连接。柔性衣料才使用 root→tip 渐变和局部摆动。刚性部件需要旋转中心时用 pivot；不能用 motionAnchor 让手臂或翅膀主体软化。
- spatial 设置前后角色与相对卡框深度。开始用主体 ±.015–.025 卡宽，明确的离体翅膀可依真实补绘余量增加；数值上限不是建议值。以允许角度暴露的真实支撑范围决定最大深度。
- group 组织人物、握持组、翅膀与衣物。图层排序决定绘制遮挡；真实 Z 决定视差，两者都要核对。角色切换不是图层排序的替代。
- 查看 context.document.characterDepth：single-character-plane 表示仍只有人物一张表面；unclassified 表示部件类型未标记；hidden-support-unverified 表示部件或主体尚无补绘记录；hidden-support-review 表示有补绘记录但当前接缝与角度仍需检查。父层有一次补绘不代表其他所有肢体已补齐。它只核对元数据，**不能证明隐藏像素足够或所有场景已修复**。
- 检查按 `characters` 中每个母版分别进行：coplanar-character-parts 表示虽已拆层但实际深度相同；character-camera-disabled 表示统一相机未开启；depth-role-conflict 表示 front/rear 与包含 Slot 的实际前后位置相反。先依据部件计划修正再预览，不自动重排用户图层，也不因缺少检查项自行宣布通过。
- `characters.partFamilies` 按手臂、腿、翼和衣料列出当前可见表面，`hiddenSurfaceIds` 列出隐藏部件，仅用于对照部件计划。空分类不等于缺少解剖，例如本构图没有翼；握持组标记为 weapon 时，仍须在部件计划注明其中的手与前臂。不能凭这些元数据自动补出额外肢体。
- `occlusionPairs` 给出依据人物父子关系预期的 frontId/backId：`painterMatches=false`（审计为 painter-role-conflict）表示前层在列表中反而先于后层绘制；`depthDelta` 表示两者相对深度，正值向观众，未启用相机时为 null。图片任务中的 `active=false` 表示至少一个部件隐藏，仅用于检查补绘。核对实际像素后分别修正 reorder 和 spatial/Slot；不要只改其中一个，也不要把遮挡冲突用大深度或变形掩盖。此关系只覆盖拆层父子，不替代前腿与前臂等同级表面的实际交叠检查。旧任务没有该字段时仍按实际层序、Z 和母版判断。
- 契约有 characterMaster 时读取对应 PNG：这是保留的完整参考，不是已完成的隐藏补绘。先检查 input.png 当前实际部件，再结合母版、合成与 Mask 规划操作。
- 聊天选中已拆出的人物图片（包括临时隐藏的部件）时，同样携带人物母版与实际 Mask 附图。`maskImages.scope=document-character-masks` 表示共享源画布上的全局区域，可能包含别的肢体或衣料；查看每个 PNG，并与当前 input 的 Alpha/ownership 相交，不能把整个 motion Mask 当作该部件范围。刚性手臂、腿甲、翼骨和握持组即使邻近共享运动区域，也保持 rigid/motion=0。旧任务只有统计或没有附图时明确待验，不以统计代替像素检查。

躯干若仍包含可动衣物，不应直接分类 torso 锁住整层后宣称衣物会动；先把需要摆动的区域独立拆出。手、护腕、握点与武器在刚性层内可以正常流光和箔面，不能发生网格拉扯。翅膀的羽毛末端若需要柔动，应另外拆出真实柔性末梢；翼骨主体保持刚性。

## 验收矩阵与性能

逐张卡、逐个带人物的组件验收，不只检查最新示例：

处理整套场景时，为每张卡记录部件计划、实际生成/补绘回执、极限角度证据与待修项；复用人物组件应检查每个实际组合的框内外遮挡。不能因为公共渲染器已支持拆层，就把未拆肢体或未补绘的旧卡标为通过。

- 正面：重新组合与母版对齐，没有重复肢体、增厚护腕、裁坏中心或人物与背景断层。
- 左右 ±20°、上下 ±12°及四个组合角度：前后肢体/翼有可见的相对移动；连接有隐藏支撑，不出现透明洞、底部断层、肩点/握点漂移。侧面只检查卡体，不声称绘画平面能表现人物真正侧面。
- 同时播放最大衣料摆动与武器流光：刚性肢体比例不变，柔性根部稳定；框内/破框来自同一部件的两次裁剪，不是两张重复人物。
- 单独检查近侧与远侧手臂、腿、翼：倾斜时相对移动方向随相机变化，前层仍遮住正确的后层；正面看不出拼接，隐藏前层时能看见真实补绘。只有背景产生移动、人物部件仍同深度的卡不能记为人物景深完成。
- 临时隐藏前层：后层需要的补绘真实存在；显示前层时重叠区域自然。空间层级“全图”检查隐藏连接，“效果预览”检查实际遮挡。没有预览证据则标记待验，不能自行填通过。
- 先以小深度验证，再逐步扩大到所需角度；根据每条接缝在极限组合角度的真实投影差，确认后层支撑范围覆盖位移、衣料最大摆幅及羽化带。范围不足时继续补绘或收紧该层的深度/摆幅，不能拿统一 maxOffset 上限当合格结论。
- 翻面、进入、暂停、恢复、撤销、保存重开、Godot：保持部件类型、连接方式、深度、所属组、Mask 与隐藏补绘。

只拆对视差有贡献的表面。刚性肢体复用平面/网格数据和材质函数，不为每块护甲生成网格；柔性衣料才细分。n 个人物表面有 2n 次框内/破框绘制，估算大 PNG 和 Mask 显存与透明过绘。原画完整母版属于编辑源，不额外在运行时绘制。性能不足时降低非编辑卡和远景质量，不能通过省略必要后层冒充人物景深完成。
