# 素材、图层和效果约定

## 素材与构图

- 新卡使用空白 `newCard`；变体才复制已有卡。已有其他卡片保持完整。
- 背景留视差余量，典型源图 1216×1824，对应 1024×1536 卡面，使用中心 `sourceWindow`，倾斜时不能露空边。
- 人物、披风、手、护腕和武器先生成完整母版。一次真实 `imageTask` 一个明确用途；收到 READY 后导入并检查。人物用本地 ISNet 等抠图，保留母版，检查发丝、羽毛、武器细线与去底色边缘。
- 真实 PNG 已产出但透明预留区仅残留 Alpha 1–4 时，不反复生图。检查 `context.failedAssets`，单独提交 `recoverImage(jobId,threshold:4)`，客户端保留原始候选并经 Rust 清理、验证后给出 READY 回执；下一批再导入。超过阈值的真实内容仍保留，恢复失败必须报告原因。
- 人物按真实遮挡与纵深拆层，参照 [人物景深约定](anatomical-depth.md)。前后手臂、腿、翅膀在不同深度时分别制作；手、护腕、握点和所属武器保持一个刚性握持组，禁止复制护腕制造加厚壳层。先保留完整母版，再互补拆层与真实隐藏补绘，不能只切出可见像素就完成。
- 默认平直、有切角的 Snap 卡框。框体刚性，不用弯曲卡框制造立体感；通过纵深、倒角、人物遮挡和视差建立空间感。底部不新增说明内容框，若用户明确另有要求则遵从。
- 上方费用、战力是独立可编辑徽章图层，不能烘进原画或混入底部字标。共用背景、底板、卡背和效果从当前工坊资源选择，不能编造资源 ID。

## 注册 Mask

颜色、Alpha 与 Mask 统一注册到 1024×1536 源图坐标，图层变换一起作用。先确认真实附图，不把照片灰度当运动权重。需要时用 MobileSAM 正负提示或人工轮廓多边形，羽化只平滑边缘。

| 通道 | 白色含义 | 关键检查 |
|---|---|---|
| coverage | 可见 | 来源于真实透明轮廓，不能误删身体或披风 |
| rigid | 刚性保护 | 脸、双手、护腕、握点、完整武器；运动与刚性不得重叠 |
| motion | 最大局部运动 | 披风和发梢；根部固定、末端渐强，避免手和武器变形 |
| inset | 留在框内 | 同一人物先画框内，再画框，再画破框；仅裁外层，不裁框内人物本身 |
| emission | 可发光 | 武器刻槽或明确能量源，不覆盖皮肤 |
| phase | 流动顺序 0–1 | 与 emission 配合沿路径流动，不能代替覆盖轮廓 |
| foil | 材质反光 | 只覆盖选定金属盔甲，保护脸、布料与背景 |

让披风上沿/侧边自然出框，部分根部/衣物保持框内；默认底部封闭。检查正面、上下及左右倾斜时底部无断层、中心不被 inset 误裁透明。局部运动应由 motion 权重约束，不能用整张深度图把硬武器拉弯。

## 图片字标与效果

- 用户要求美术字时生成真实透明 PNG，不以字体栅格化冒充 AI 字标。中文/英文分别生成，允许每个英雄独特的字形、花饰、象形符号。
- `titleVariant` 绑定不同语言的 READY PNG，文字字段保留语义/回退内容。共享 `titleSweep` 控制慢扫光，按各图片实际字形 Alpha 与横向范围归一化，使不同语言效果一致。
- 保留图片字标的移动、缩放、图层选择和撤销能力。切换语言检查字形、裁切、扫光、位置和比例。
- 披风轻摆、刻槽能量流与盔甲周期反光分别限定对应 Mask。自定义 GLSL 仅提交函数体，材质签名为 `vec4 surfaceEffect(vec4 color, vec2 uv, float time, vec4 mask)`，mask.x/y/z/w 分别为 motion/inset/emission/phase；需要能量强度时读 `mask.z`，不能把 vec4 mask 赋给 float。`fragmentMask` 已对选区做最终门控；编译成功后才应用，局部发光不要修改人物 Alpha。
- 几何弯曲默认 0，保护刚性区域；共享卡背翻转和整卡进场属于整个卡片的动作，与人物局部动画区分。使用已有动作 ID，验证起点、过程与结束状态。
- `action(actionId)` 只播放；用 `actionSettings(actionId,bend:0)` 编辑已有动作的属性，必要时编辑受限关键帧 `tracks`。检查 `context.actions` 的真实参数，翻面与进场默认 bend=0。`view(mode:"space")` 打开空间层级检查，完成后回执决定是否成功。

## 完成证据

至少核对用户请求对应的真实任务 READY/应用回执、素材注册、Mask 有效像素和作用范围、GLSL 编译回执、动画配置。对可观察的预览检查暂停/播放、正面/倾斜/卡背、语言切换和图层操作。保存再打开验证持久化；导出仅在用户要求时执行并报告实际文件与适配边界。


最小武器流光函数体（Alpha 保留，绑定 foreground / emission）：

```glsl
float wave = pow(0.5 + 0.5 * sin(mask.w * 18.0 - time * 1.4), 6.0);
vec3 glow = vec3(0.05, 0.6, 1.0) * wave * mask.z;
return vec4(color.rgb + glow, color.a);
```
